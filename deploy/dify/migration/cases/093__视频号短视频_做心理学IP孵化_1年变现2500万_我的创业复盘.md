我先做个自我介绍。我是源头智慧的联创，主要负责新媒体板块。我们从去年12月开始，在视频号上做了一些事情，核心是心理学的IP孵化。我们通过一年的时间，跑通了心理学的线上加线下模型。从营收角度来讲，基本上一年完成了2500万的营收。接下来，我会把我们如何完成这个业务模式的过程分享出来。

在这之前，我曾在字节跳动团队负责抖音的直播业务。大家知道“双减”政策，当时我们属于教育行业，“双减”一来，教育行业迎来了暴击。即便在那样的背景下，我们当年还是完成了3个亿的GMV，产品是大力智能学习灯。但“双减”之后，这个业务就基本没法继续了，所以我选择了离开，开始自己创业。再往前，我在宝尊负责内容营销部门，当时和清华一起做了最早的图生文项目。大家都知道，在内容领域，要么卷质量，要么卷数量。

在2018年之前，我们就已经开始做数量的部分了。因为很多品牌有很多SKU，但他们没有足够的预算去支撑这么多SKU的内容营销。比如说像Nike、ZARA、复星这些品牌，我们会帮助他们的SKU做内容的AI生成，帮助他们拿到流量。以往，可能每一个季度的营销预算只有100万，其实只能花在几个核心的SKU上。现在通过这种方式，你可以把预算分配到几千个甚至几万个SKU上面。所以在最早的图生文领域，我们其实取得了一些不错的成绩。

我今天的分享主要有两部分：

第一块是如何打造差异化的产品体系；

第二块是视频号的算法，以及如何做千万级流量的内容。

# 一、如何打造差异化的产品体系

一年变现2500万，我的商业模式是怎样的？

其实和传统大多数教培行业，也就是知识付费行业一样，它是有一个“低升高”的逻辑存在的。

也就是说，如果今天大家只卖100块钱或者几百块钱的课，你想想，要做到2000万，需要多少用户？这个用户量的空间是非常大的。所以，我们做的其实是“低转高”的生意模式。

具体来说，从前端的无门槛，甚至低门槛产品开始。低门槛产品只有几块钱，甚至十几块钱，主要用于获取线索。

然后是百元品。百元品的定义是什么？它其实更多是“地图”。也就是说，用户进来之后，你要清晰地告诉用户他要到哪里去，如何去完成后续的学习，或者让他知道遇到问题时，在这个“地图”里应该去哪里，通过什么方式去。这就是百元品的定位。

至于千元品，其实更多的是我们IP的一些方法论。设计千元品时，要考虑用户愿不愿意学习，感不感兴趣，他的痛点是不是需要解决。

理论上来讲，我们还搭载了线下的体验课。也就是说，我们并不只做线上，也做线下。线下课价格基本上已经到了3000块钱，甚至还有更高的万元品。所以，要完成一个将近2000万的盘子，只靠几百元的课是没办法实现的，必须要完成“低转高”。

我相信大家在这块上，可能很多同行基本上也是按照这个路数来的。

那我们的差异化是什么呢？线上，我们做习惯养成，做头脑层面的认知；线下，我们做知行合一，做体验部分。

这里面有一个底层的认知：大家今天来上课，其实更多是用脑子来接受信息。但问题是，我们并不只有脑子，还有身体的感受、听觉、视觉等等所谓的感官体验。这些部分虽然也会参与，但核心还是脑子在接受信息。

我们也看到了一些趋势。比如在美国，身心创伤的疗愈会被纳入医保，而纯粹的精神分析则会被剔除医保。这说明什么现象呢？如果你要做创伤修复，在美国会更推荐你从身体层面去进行疗愈。但在国内，我们发现传统的精神分析更多的是帮你理清楚事情的来龙去脉，但你可能还是会感到痛苦，并不能从本质上解决问题。

所以，我们把线上和线下做了迭代：线上去做头脑层面的知识和体系的养成，线下去做体验部分。

我们的业务链路大概是这样：通过IP引流，到课程转化，比如21天重启营。大家其实也知道，21天可以养成一个习惯。在训练营里，你可以和用户深度建立连接。在线下课里，你会带他体验一些新的东西，交一些朋友。我们的用户基本上是带着痛苦进来，带着笑脸离开线下课的。所以，这里面也要给到他们一些情绪价值。

其实这个商业模式，我是花了一些时间去设计的。

首先，我们会从市场现象入手。做一件事情之前，我们要看它值不值得做。

我们看到的数据是，心理学行业每年的增速现在可以达到30%多，是一个非常高效增长的行业。现在为数不多的高增速行业，比如宠物经济、养老行业，或者心理学行业。其他很多行业，大家可以看一下，是不是在下滑？当然还有像芯片这些行业也在增长，但它的门槛太高了。对于我们来讲，要看到自己可以覆盖的品类和市场现象。

其次，我们切入的是国民的情绪健康问题。比如说，抑郁的人越来越多，焦虑的人也越来越多。尤其是现在，你会发现年轻人也开始“躺平”了，不生孩子，不结婚。大家反而更希望在这样的环境下，能够更好地做自己。

这里面还有一个现象是什么呢？就是心理咨询、芳香疗愈、音波疗愈等等各种疗法开始慢慢都出来了。这说明什么？用户知道自己很痛苦，但他并不知道具体的解决方案是什么，他会用自己的方式去尝试。以上提到的芳香疗愈或者音钵疗愈，可能都是用户在不自觉中找到的解决方案，他觉得这个东西很好，对自己有用。但底层逻辑上，我们还是要看到用户的痛点在哪里，用户的行为习惯在哪里。

这里分享一个比较核心的点：我们所看到的这些，比如心理学增长也好，焦虑现象也好，其实都是“相”，所谓的“相”就是结果。我们要看到这个结果背后的原因是什么，也就是要去找原因，而不是只看结果。

我们会去分析，为什么会有这么多人抑郁，这么多人焦虑？是不是跟经济问题有关系？是不是跟社会大环境有关系？是不是还有其他类似的因素？我们要先看到这些问题，再去下结论。

找到一个需求之后，我们还要对这个需求进行预判：这个市场会有多大？它的空间在哪里？

这部分，我们利用了一个概念叫“等级扩散”。比如说，一些趋势在一二线城市流行起来，等过了一两年甚至三五年，三五线城市才开始发展起来。这里面就有一个时间差，在我们看来，这个时间差就是机会。

哪怕今天抖音、视频号这类内容平台已经非常普及，几乎所有人都在刷，但你会发现，你刷到的视频和妈妈或者家里七大姑八大姨刷到的视频是完全不一样的。所以，虽然信息在传播，但传播到不同层级的人群，其本质内容还是会有一些区别的。这就像我们之前玩的一个游戏，不同的人传话，传到最后一个人，意思可能已经完全不一样了。

还有就是消费能力与基础设施的差异。其实，前两年心理咨询的收费标准，主流还是 1000 元一小时、2000 元一小时。但最近一两年，大家会发现，三五百块钱一小时的咨询也开始慢慢多起来了。对于之前那种高价位，一二线城市的消费者可能更容易承受，因为他们的消费能力摆在那里。而现在，两三百块钱的咨询，对于下沉市场的用户来说，他们也开始有机会去尝试和体验了。

人才观念的流动性。举个例子，马上大家要回家过年了，你想想，你跟七大姑八大姨聊的东西，认知层面能完全一样吗？肯定不一样。这里面其实就蕴藏着一定的机会。

基于这些市场现象和它可能的扩散方向，我们需要进一步明确目标用户人群到底是谁，他们面临什么样的痛点。我们主要关注的是30 岁到 45 岁的女性群体。用比较现实的话来说，她们很多人除了是“妈妈”、“妻子”、“女儿”这些身份标签之外，往往不知道“自己是谁”，感觉完全是在为家里人而活，这样内心其实会很痛苦，自我价值感也会变得很低。

这让我想到早几年前大家常说的一句话：“北上广深容不下肉身，三四线城市容不下灵魂。” 这句话其实反映了有相当一部分人，他们所在的环境让他们感到不适应，甚至是压抑。

造成这种现象的背景是什么呢？我认为有一部分原因来自代际传递。

比如说，我们上一辈的人，如果我的爷爷没有好好爱过我的爸爸妈妈，那么这份爱的能力可能就难以传递下来。如果我的爸爸从小是在被指责的环境中长大的，他很可能会把这种相处模式再传递给我。我们会发现，越下沉的城市，这种不良的代际传递现象反而可能越发严重。

同时，今天我们接收到的信息越来越多，很多人的价值观也因此发生了动摇。不少人开始非常在意自己的原生家庭，甚至已经出现了反抗和抵触的行为。我们调研的数据显示，一些 20 岁到 25 岁的年轻人，他们与父母的链接已经非常差，甚至到了反目的地步。为什么会这样？其实父母也并非不愿意给，而是他们可能本身就没有从他们的父母那里学到如何去爱、如何去沟通。当我们通过视频等渠道看到一些好的家庭模式、相处方式时，就会产生巨大的心理落差。

还有一些现象，比如“心灵留守”，孩子们在无声的课堂里，或者作为留守儿童，还要面临家庭和学校的“混合双打”，连释放自己情绪的空间都没有。这无疑是不利于他们成长的。

我们还可以从离婚率这个表象来看。每年离婚率的增加，只是一个结果。我们更应该关注的是，有多少人正在走向离婚的路上？从开始冷战、吵架、冲突，到冷静期，再到最终离婚，每个阶段的人群比例是否在增加？如果这些人群的比例在增加，这对我们而言是不是就是市场机会？

所以，看数据不能只看表象，要看更多维度，看它停留在哪个阶段，那个阶段是否有我们可以介入和验证的机会。

当我们有了这些信息之后，就会思考：如何设计我们的产品体系？

我们当时签约的 IP，内容上其实偏情感会多一点。但对于用户来讲，无论是心理还是情感问题，他们要的都是解决方案。用哪种方式解决，他们其实是不排斥的。在我们看来，心理和情感是不分家的，关键在于两者的配比问题——内容中要包含多少情感疏导，多少心理专业知识，侧重点不同，解释也就不一样。

另外一个点是，现在互联网上，像心灵鸡汤这类内容的流量池非常大，但相应的监管也比较严格。如果我们把情感问题带到心理学的框架下去解读和解决，其实一样可以达到效果，而且还能有效地规避平台的监管风险。基于这些考虑，我们也在不断完善自己的内容体系。

我们的内容和产品核心会围绕几种关系展开：与自己的关系、与亲密关系（这里我们主要侧重伴侣关系和情感议题）、与情绪的关系，以及与财富的关系。

很多人容易做冲动的决定，事后又后悔，其实就是情绪在影响判断。所以，如何管理和释放情绪是非常关键的内容。

至于财富关系，很多人都在追求财富，但可能没有想过，自己是真的很想赚钱，还是内心深处对赚钱有抗拒？有些同学赚得多花得也多，存不下钱，这其实可能和他的性格、底层信念以及原生家庭都有一定的关系。

现在竞争很激烈，最缺的是创造差异化。我们做内容做产品，需要完成自我价值的构建。

这个价值构建的公式大概是：重构价值 = 发现市场需求（行业现象 + 发展预判） + 明确服务人群 + 整合跨界需求。

回到心理学这个领域，我们看到的现象是：心理学行业在高速增长、百花齐放，但国民心理健康状况也令人担忧。发展预判是什么呢？我们认为，心理咨询服务会从一二线城市慢慢渗透到三五线城市，这个过程我们判断还有 1 到 2 年的红利期。这个红利期足够大，能让我们去跑通很多模式。

人群矛盾方面，比如三四线城市的人群，在认知方法、教育孩子的观念上，可能缺乏好的指引和答案。他们并非没有问题，只是不知道如何寻找解决方式。而且，用户的问题往往不是单一的，而是多个问题交织在一起。那么，我们在解决问题时，是不是可以顺便解决他们底层的根本问题。

因此，我们的课程后期也会加入情感、冥想、国学等元素。也就是说，在用户需求层面，我们是否能提供更高阶、更系统的方法，引导他们持续成长。这大概就是我们看到的价值重构公式和方法，大家可以参考一下。

# 二、如何利用视频号的算法，打造千万级的爆款内容

我们在视频号上确实做出了一些小小的成绩，无论是几百万曝光还是千万曝光，在我们看来，其实是有方法可循的。

在过去的一年中，我们视频号的内容其实已经获得了几亿的流量。在这个过程中，我们已经把 IP 打造这件事情完全跑通了。也就是说，今天心理学内容在我们的打造下，是有机会成为现象级 IP 的。我们会帮助 IP 设计完整的变现路径。基本上一年的时间，像“冷爱”这个 IP，已经做到了全网几百万粉丝；“伍叶”相对弱一点，全网大概几十万粉丝的规模。

讲到这里，大家可能会更关注如何做 IP。毕竟，做新媒体、打造 IP 是很多人都想尝试的，它能帮助个人事业成长，帮助公司业务拓展，降低运营成本。

## 1、IP定位公式

关于如何做一个 IP，我们这里有一个公式：我（IP）是谁？要在什么领域，为哪些人解决什么问题？

比如说，我们给“冷爱”的人群定向是：情感领域深耕 20 年的作家、心理咨询师，同时也是心理学行业的专家。他专注的领域就是心理学和情感，面对的人群主要是 30 岁左右、面临亲密关系危机的女性，具体解决她们从争吵到离婚不同阶段的核心诉求。这样定位就比较细致了。

如何验证自己的 IP 定位是否可行呢？

这里有几个问题大家可以问自己：为什么是你？你是做什么的？对你的目标用户有什么用？你如何变现？你能坚持下去吗？

这里面有一个巨大的坑，就是“怎么变现”。很多同学一开始做 IP 就想着怎么做流量，但其实流量只是杠杆，是帮你放大价值的工具，怎么变现才是你一开始就要思考清楚的问题。

如果等流量做起来了再考虑变现，往往会非常痛苦。所以在一开始，我们就要考虑商业闭环：为哪些人服务？通过什么路径服务（是低转高，还是授课、咨询）？想清楚这些，再开始做流量和人设。

另外一点就是“能不能坚持”。很多同学做着做着就没信心了，本质上可能是没有找到自己热爱且擅长的事情。如果做短视频或 IP 让你感到非常消耗，那很可能是方向或定位错了。做自己擅长的事情应该是相对轻松的，不应该是特别费劲的。如果此刻你感觉很痛苦，那大概率是哪里出了问题。

## 2、理解视频号算法

那么，在视频号上做内容，首先要了解这个平台。很多同学上来就直接开干，我其实不太赞成。你在一个平台里玩，首先要了解平台规则是什么。

早些年在平台运营的经验告诉我们，用户的时间是平台竞争的唯一资本。用户在视频号上刷内容，就不可能同时在抖音上刷，同一时间内用户只能做一件事。所以，用户的时间是最宝贵的。理解了这个核心诉求，我们再来看看平台是如何规划产品的。

第一，观看时长和内容跳出的博弈。停留时长会是一个比较高的权重指标。因为只有用户留在平台上，才有商业变现的机会，用户才会养成习惯，高频打开，平台才有价值。

大家都知道完播率高才会有流量，但这只是现象，底层逻辑是平台为了把用户留下来而设定的规则。你要思考如何利用这个规则。比如，如果你的 3 秒跳出率过高，就可能得不到推流。因为你影响了用户在平台的停留时间，连大盘平均水平都达不到，平台为什么要把流量给你呢？

第二块是互动指标的质量检验。 平台如何判定你的内容好坏？通过点赞、评论、转发、关注这些互动指标。为什么会有这些指标？因为从点赞到评论，再到转发、关注，每一个指标都代表着用户更深层次的行为，意味着用户需要在平台上花费更多时间。点个赞可能一秒钟就结束了；点“在看”（现在叫“点赞”心形图标），意味着你要曝光自己的价值观，让朋友圈的人看到；评论的话，大家写的长短不一，会花时间；转发更是愿意与朋友分享。这些都是深度行为，能帮助平台更好地留住用户，所以才会有社交推荐机制。

第三块是内容消费的频率与打标签。 当你的内容能够持续影响某一类特定人群，就会形成长期的用户粘性，算法也会被驱动。也就是说，你的内容会被推给对应的目标用户，帮助平台完成用户时长等指标。这样你就能拿到更精准的流量，这些用户更愿意看你的内容，完播率更高，跳出率更低，从而完成个性化推荐。所以说，用户关注决定了流量的走向。

## 3、如何撬动视频号算法

讲到这里，大家可以看一下我们之前做的几个案例。

先说第一个案例，我们曾打造过一条千万级爆款视频。为什么能成功？关键在于我们抓住了一个特定的时间节点——大学生开学前。我们当时思考的是，开学这个节点，大家会关注什么？我们发现，很多家庭和家长对大学生活充满美好的想象，认为这是人生的重要新阶段，但他们其实并不知道大学里可能存在的一些“坑”。

于是，我们设计了一个“大学避坑指南”的内容，采用了一种“偷拍”的形式来呈现。这条视频的数据非常可观，在1500万的播放量下，转发量达到了110多万，也就是说，基本上每15个人看到就有1个人转发，这个比例是很惊人的。

这个逻辑背后是什么呢？它具备了很强的普适性和社交属性。你的孩子，或者你七大姑八大姨家有即将上大学的孩子，看完这个“避坑指南”，一定会转发给对应的家庭。所以，我们在做视频的时候，就已经围绕“转发机制”去设计内容了。无论是偷拍的形式，五个避坑指南的干货，还是“大学老师”这个人设，都是为了促进用户的主动传播，从而带来了很好的数据。

再看第二个案例，也是一个1500万播放量的视频，来自“冷爱”这个IP。它的数据特点和前一个不太一样，评论互动量非常高，但转发可能比不上前面那个。这反映了什么呢？我们分析这是“共鸣现象”。当内容真正说到用户心坎里，引发了他们的强烈共鸣，自然就会产生很多赞同、争议以及点赞、收藏等互动行为，这些都会进一步加剧数据的传播。

而且，这类视频的评论区质量通常很高，用户会主动描述自己的相关经历，表达被共鸣到的感受。

从这两个数据案例，我们可以侧面印证视频号的一些流量逻辑：

要么帮助平台吸引更多用户观看（比如高转发带来的新用户）。

要么评论互动足够多，能帮助平台把用户更多地留在视频号上。

满足这两点，你就更容易获得平台的流量倾斜。当然，其他基础数据也不能太异常。总体来说，用户在平台上消费内容的时间越长，你内容的权重就可能越高，也越被认为是有质量的内容。

接下来再看一个反面案例，是我们旗下的一个IP“伍叶老师”。他有两条视频，一条100万播放，一条300万播放。在设计第二条视频的评论引导时，我们后来反思觉得有点“过了”，导致视频下方出现了一些比较负面的评论。结果，这条视频在播放量超过100万，进入人工审核阶段后，就被平台毙掉了。这个教训告诉我们，内容设计一定要有“度”，绝对不能引导过多的负面争议。

为什么呢？因为视频号和抖音、小红书这些偏娱乐化的平台不一样。它是嫁接在微信生态里的，而微信的核心是通讯工具。微信的安全和风险控制是第一位的，其次才是视频号的发展。大家可以理解为，视频号是微信的一个内容平台模块。有了这个基本认知，你就能理解为什么有些视频会被下架或限流。比如，当天如果有重大政治事件上了头条，你发的内容如果与其调性不匹配，甚至有所冲突，就很可能会被处理，严重的甚至会封号。

我们再从本质上探讨一下视频号用户几个核心行为的心理底层逻辑：点赞、在看、评论、转发。

点赞：点赞代表什么？我们通过多个IP测试发现一个有趣的现象。比如，有个博主传达的观点是“女性要利用自己的年轻优势去上位”，这和现在主流的“大女主”价值观背道而驰。结果呢？这条视频的评论很少，收藏也不多，但点赞量却非常高。这说明什么？用户可能内心认同这个观点，但碍于社会普遍价值观，不敢公开表达（评论），只能用点赞来默默表示认同。类似的，在原生家庭、子女与父母矛盾等敏感话题上，也常会出现“只敢点赞，不敢评论传播”的情况。

在看❤️：这个代表了，我认可，我并不介意别人通过这个视频更好的了解我的价值观；但是考虑到，我们有很多用户带了厚厚的面具；那么这里用到一个心理学逻辑，在这个逻辑中，视频的负面现象，用户都会存在，这是一种心理投射，正面的解释可能是用户的伪装；那么针对这设置，往往负面现象的正向表达法，更容易击中用户；例如“焦虑是个过度保护我们朋友，你强大了，他自然安静的离开。我们在设计内容中，负面词抓用户痛点，正向表达引导给到价值，在那一瞬间的，从情绪能量会得到很大的提升，体验会加剧（可以参考下霍金斯能量等级表）；

评论：评论的激发因素有很多。比如盲目从众的“太好了”、“+1”；比如“杠精”，总要发表不同意见；但最有价值的是“高度共鸣”，用户会因为内容勾起了某段过往回忆或场景，从而主动讲述自己的故事。要做到这一点，需要功力，核心在于你能否从情感角度精准描绘出用户的当前现状，从而在内容设计上引导用户行动起来，产生评论。

转发：转发的逻辑相对清晰，有用的东西、有价值的东西更容易被转发。比如实用的干货、正能量的鸡汤、符合主流价值观的内容、爱国主题等，这些都具有高度的传播性。正向内容在引发“点赞”和“转发”上，逻辑是相通的，只是一个是被动认同，一个是主动传播。主动传播往往代表用户更愿意参与，更有社交谈资的需求，行动力也更强。被动传播则可能源于用户内心有某种情绪或观点，但无法完整或公开地表达出来。

理解了这些，我们在内容设计初期就要规划好，这条视频是主打评论互动，还是主打转发分享。当然，也不要为了单一指标而走极端，要考虑多个指标的共通性，这样加权之后才能获得更好的综合得分。

## 4、IP在不同阶段的内容运营差异

接下来谈谈IP的发展阶段。我们通常认为IP发展会经历0到1、1到10、10到100这样的过程。

0到1阶段：这个阶段，我认为不需要过多强调“自我”，而是要“跟随爆款、跟随竞品爆点、跟随主流”。核心是验证方法论，把从竞品那里学到的东西，结合自己的理解，去测试是否能与市场匹配。如果匹配成功，大概就能完成0到1的启动，吸引到第一批垂类用户。

1到10阶段：这个阶段的重点是“增加确定性”。你可以把之前验证过的几个方法论进行重组，用自己的语言、自己的观点去输出，帮助用户更好地理解你。这其实就是套用方法论，并形成自己确定化公式的过程。

10到100阶段：到了这个阶段，你应该已经有了比较完整的输出模型。这时需要做的是“跨界”。比如，你讲情绪管理，可以结合其他行业的案例或热点现象；或者整合自己的方法论，与不同行业进行对标。这个阶段更多的是从行业思考的高度，去规划你要对用户输出什么样的内容。

## 5、人设视频、转化视频怎么做？

在IP内容构成上，通常会有流量视频、人设视频，以及转化视频。

这里分享一个非常适合打造人设视频的脚本模型——“英雄之旅”。

这是心理学和神话学中的一个概念，由美国神话学大师约瑟夫·坎贝尔提出，很多好莱坞电影，比如《哈利波特》、《指环王》、DC和漫威的超级英雄电影，都在用这个模板。它的核心框架可以简化为“启程-启蒙-归来”三个部分（完整版有12步），大家可以深入研究。

用到我们自己的IP上，比如“冷爱”这个案例：他得了癌症，这是“启程”，处于困境，内心失望、退缩，活在恐惧里。然后是“启蒙”，他看到一个残疾小哥即使身处逆境，也能每天充实生活、活在当下，这给了他勇气，让他重新面对病症。最后是“归来”，得到共鸣，也给他人带来力量。这个模型的核心不在于步骤本身，而在于你如何设计故事中的“转折点”。如果大家想做人设视频，这个模型非常值得参考。

很多小伙伴在做了流量视频后，会更关注如何转化，毕竟要面对业绩KPI。那么转化视频应该怎么做呢？

首先，信任可视化。用户为什么相信你？你的证据是什么？口碑怎么样？比如我们做课程，那你的线下课程是什么样的？你是不是真的老师？用户对你的评价如何？这些都是用户非常想看到的，能直接建立信任。

其次，讲述与“我”有关。短视频的信息密度很高，如果你的视频内容有很多与用户无关的“废话”，哪怕包装得再好，也是在浪费用户时间，一定要果断删掉。

再者，常规词转换与敢于下定义。比如，“性格太软弱，太过善良，往往都是心力不足”。你能否用一些用户常见的现象把他们圈进来，然后给出一个新的、有冲击力的定义，引导他们看下去？这是一个关键节点。提炼出像“心力不足”这样的核心概念，就能抓住用户。

这里给大家推荐一个转化视频的模型：现象 + 认知颠覆 + 危机/共鸣 + 背书 + 解决方案 + 行动引导。

现象：点出用户面临的具体问题或观察到的现象。

认知颠覆：提出一个与用户固有认知不同的观点，引发思考。

危机/共鸣：对于理性用户，要指出不解决问题的后果（危机）；对于感性用户，要引发情感上的共鸣。

背书：展示你的权威性、专业性或成功案例。

解决方案：给出具体的解决方法或你的产品/服务。

行动引导：明确告诉用户接下来要做什么。

转化视频的核心，在于识别并打动不同类型的用户决策卡点。我们可以将用户大致分为三类：理性的人、感性的人和本能的人。

本能的人：动物性比较强，更关注结果和行动指令。比如“你是不是很牛逼？”“我能不能用最简单的方式做到？”“我现在立马下单是不是就能达到结果？”这类用户需要直接、明确、能快速看到好处的内容。引导语可以是“你想要更多的模板或方法吗？”

感性的人：更容易被情绪打动。“我曾经也这样经历过，我理解你的痛苦”——这类表达能迅速拉近与他们的距离，让他们感觉到被理解，从而促进决策。

理性的人：注重方法、逻辑和性价比。你需要从逻辑上说服他，让他明白“为什么”，以及“是否值得”。比如，“不是你的沟通能力差，而是你陷入了防御性倾听的认知陷阱”——这样的表述能引发他们的深度思考。

一个视频如果想同时面对三个人群，难度会比较大。如果内容足够细分，其实每个视频主打一个人群就够了，比如这条视频我就专门打动理性的用户。但如果能巧妙地将这三种元素穿插融合，那这条视频的穿透力会更强，因为在曝光时，你并不知道会触达哪类人群，多元素能覆盖更广。

在视频号创业1年，变现2500万+，总结几个我认为比较重要的点：

锚定具象用户，解决痛苦需求：你的内容一定要精准定位到某个具体人群，解决他们真实的痛点；借势而为：借平台的趋势，借行业发展的东风。顺势而为，往往能事半功倍。就像雷军说的，“站在风口上，猪都能飞起来”；知识付费的差异化：知识付费产品本身可能不是标品，但用户对“解决问题”的需求是标品。如何把你的产品做出差异化，是成功的关键。

QA：

我们来说一下大家关心的问题：在视频号上，不留视频的话，联系方式怎么留资才安全点？还有，市面上怎么认证安全呢？

1、怎么样留资安全一点。我先说一下我们现在常用的几种方式：

第一种，我们会在账号的简介上做留资。

第二种，我们会在评论区做留资。

第三种，我们可能会把联系方式包装成一个小额付费的小诱饵，比如说 9.9 块，甚至 5.1 块这种，用最简单直接的方式来设置引流规则。

然后还有一个点，如果大家有公众号的话，可以试一下从评论区直接跳转到公众号，这个方式是 OK 的。另外，一些老账号可能权限比较多，点击之后可以直接跳转到公众号主页，这也是比较好的引流方式。

我们其实也会遇到一种情况，比如说当天的视频爆了，带来几百个甚至上千个咨询，但这时候你的视频号添加好友可能就会有风险。所以，要提前去布局一些能够帮助你完成用户筛选的动作或设置，在用户私信时设置一些自动回复等，这些东西就可以帮助你完成初步的用户筛选和分流。

微信号养号，尽量用自己的 5 G 或者 4 G 网络，不要用 wifi。我之前就因为这个事情损失了不少资产，所以如果添加好友的量比较大，比如说一天有几百个，甚至一个月有几千、上万个好友请求，那基本上不建议大家使用 wifi。

2、视频号不能直接留微信吗？

这取决于你怎么留。如果说是直接留数字的话，很可能会被系统屏蔽。这里建议大家可以引导用户先私信你，或者引导到客服那里。但是现在客服这块，平台也会有一定的风控，前提是你得有一个店铺。

3、直播的时候可以说“联系方式留在评论区”吧？

直播的部分是这样子的，直播时你可以偷偷地放个二维码，真的，就是不要长时间放，就放一会儿，比如放个一分钟，然后偷偷下掉。最好是在直播间人数最多的时候放出来，这时候做一个引导就可以了。对，偷偷地放二维码是个办法。
