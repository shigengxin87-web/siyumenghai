「格律诗」联合创始人@分享者

张晶老师分享了专业服务领域如何搭建新媒体矩阵获取流量，并通过业务流程和考核机制优化提升线索精准度；如何调动懂专业的专业人员跟懂用户需求懂内容的市场人员做配合；以及从前端获客到后端转化交付的市场化模式。

今天我给大家带来的分享主题是专业服务如何打造自媒体矩阵，实现年营收千万。在开始之前我简短地做一个自我介绍。

我叫张晶，大学是在政法大学学新闻传播的， 08 年毕业以后在一家互联网房地产上市公司从事互联网运营的工作，以前叫搜房网，后叫房天下。因为这样的学历背景，在 19 年，我从这个上市公司到了律师事务所工作，从事的还是律所品牌运营、市场运营，最主要的就是搞案源这样的事情。

在经历这两个职业阶段以后，我自己在 2023 年的 11 月组了一个团队叫格律诗，来做我们现在说的“赋能”，也就是通过案源开发、法律产品、律师品牌和组织管理四个方面的辅导，帮助律师团队实现业绩增长。现在我们做了一本公开的出版物，叫《律师案源开发实战笔记》，是今年 1 月份出版的。我的自我介绍就到这里，接下来我把过去四年在法律服务赛道中操盘的案例来跟大家做一个分享，和大家一起探讨。

在正式分享之前，我抛出自己的两个观点。第一，律师做自媒体到底是赚吆喝还是搞案源？在过去的工作经历中，我也看到有一些律师自己的流量做得很好但转化做得不好，所以也会停留在这样的困惑当中。带了那么多团队账号后，我认为专业服务做自媒体其实可以实现品效合一，也就是在做律所机构的自媒体矩阵和律师个人自媒体矩阵的过程中，律所品牌、律师个人品牌以及后面的案源转化、用法律产品做商业变现等品效合一是可以实现的。

那我是怎么做的呢？接下来就进入我的正式分享。在过去四年多法律服务赛道的运营工作中，我做了1个律所账号和 6 个律师个人的自媒体账号。机构账号是北京的一家律所，叫北京即明律师事务所，我们在抖音、快手、视频号、头条还有百家号都做了内容的发布。律师IP的话有马丹凤律师、向娟律师，邱晨律师、左锐律师、任静律师和王华律师等。

这些律师都有一个标签或者一类特征，都是征地拆迁或者行政诉讼。大家都知道每个行业都会有一些细分领域服务，我进入法律服务赛道的时候，选择了行政诉讼的领域。接下来我会讲，为什么这个领域的律师账号、律所账号是非常容易从互联网、从线上去获客的。在这里，我把之前做过的账号截图给大家展示一下。包括抖音、快手、视频号、头条号以及百家号。

下面是我们这个赛道细分领域的专业服务从获客到转化、交付的全景图。逻辑是我们在头条、抖音、快手、视频号、百家号这样的平台发布图文、短视频、直播，通过这样进行内容铺排，进而在平台上转化出我们业务的相关线索。然后再通过我们运营人员的客资录入进行线索分配、用户跟进，对这些用户进行分级、邀约面谈，最后转换成为客户到所或外出谈案。我们出具服务方案，客户满意的话我们就签约代理，承办案件，最后结案回款。

### 01 矩阵号运营的三大阶段

整个矩阵号运营会经历这样的几个阶段，首先是启动阶段，然后是持续增长阶段，最后是稳定成熟的阶段。这三个阶段我都遇到了一些问题，我想跟大家分享比较典型的问题是怎么处理的或者怎么得到解决方案的。

1）启动阶段

在启动阶段，我们主要做内容的完善，这个阶段我们的内容是律师作为主力输出的。刚开始的时候，我们其实没有摸索出市场和专业领域的人怎样做搭配才能够把这些账号启动起来。最开始的方案是鼓励律师生产内容，然后用少量的市场人员把我们的账号先启动运营出来。 19 年，我们主要做图文内容的发布，主攻的平台是头条号。

在这有几个问题，最开始我们为什么会选择头条号这样的一些平台？在短期只有流量、案源不多，甚至没有案源的情况下，怎么做客户律师的激励，让他们持续不断地参与到创作过程中来？其实这几个问题就是我们在启动阶段比较突出的问题。

刚才大家也看到了这些账号的一些特征，它们细分到法律服务领域的行政诉讼领域。行政诉讼领域，用法律服务行话来讲就是“民告官”，也就是说我们主要代理的是政府的相对方。

这部分用户有一个特点，就是 b 端和 c 端都有。比如我在 PPT 上列出来了行政诉讼的主要领域，涉及土地、房屋的征收拆迁、企业的拆迁关停、环保处罚，这类案件。

这类客户还有一个特征，一般“民告官”的官司，都会找北京的律师。因为北京的律师不受当地司法部门的管理，可以减少司法干涉的可能性。所以虽然我坐标在成都，但是我们的律所是在北京，市场团队是在成都，主要以异地协同的方式来完成工作。

我们这个领域最开始做的时候，短视频还没有成为引流或运营的主流，尤其是律师普遍比较保守跟传统。我们的图文生产是从今日头条开始的。我们认为这个平台会有一些潜在的客户，做了一段时间的图文内容发布以后就吸附了一些流量过来。然后随着账号的流量变得越来越好，就会有一些线索的留资。

图文过后到了短视频部分，我们选择的是抖音、快手、头条和百家号、视频号。最开始在快手的获客是非常好的。大家都知道快手的用户有下沉特点，尤其行政诉讼领域涉及到土地征收和房屋拆迁这类客户，大量都汇集在快手这样的平台。所以当同样的视频内容投到快手、抖音、百家号和视频号的时候，快手是最快起来的，到了2022 年下半年就向抖音倾斜了。

行政诉讼领域需求的解决虽然只能找北京的律师，但需求其实遍布全国各地，通过我们在线上的内容运营，就能吸附到全国除了港澳台三个地方以外的 30 多个省市、自治区。所以在平台的选择上，我们跟平台的用户做了匹配，而且我们的内容也是非常垂直，在平台上就能够实现精准匹配的过程。

第二个问题是在启动阶段遇到流量特别少，甚至说没有案源的情况怎么做？其实整个律所做自媒体这件事情之前有基本的案源渠道，比如华律网，律所自运营的爱土网，百度投放等这几个主要的渠道来支撑过去的基本案源盘，我们是在这样的基础之上去做自媒体的探索。正因为有了一条大腿，想要新长出一条大腿才去尝试做自媒体。我认为自媒体的作用其实就是增长。

前期没有流量的、流量比较少，没有案源的情况下，矛盾更多还是来自于怎么样让律师持续做好输出。现在做专业这个部分，我们经常就会拿医生和医院这样的职业、场景和法律服务行业做类比。比如医生他有自己的一些主业，他们都有自己的市场客户的基本来源。最开始，我采用了这样的方案：

给律师设置激励，按照他们提供的文字内容，给到五十到两百块钱这样的稿酬，让他们来参与最开始的文字图片产出，尤其是文章的产出。除了稿酬，在整个案源分配、品牌曝光上也会给予参与运营的这部分的律师优先分配的权利。这样其实就是鼓励他们占用时间去做内容的产出，不仅在案源上没有损失，反而有一些资源的倾斜，他们就更乐于参与到内容创作了。

在启动阶段我们也做了一个非常有效的管理动作，就是参考 MCN 机构和那些达人签署协议，用项目管理制来管理律师的自媒体矩阵号。因为我们都知道在专业服务这个赛道，专业人才资质是稀缺的。如果一个人不是律师，他在平台上就不能被认证为律师，去做一系列内容营销活动。所以他的职业资质相当于一种资源，他愿意把这种资源让渡出来，跟市场、律所一起去做，我们才有机会。

我们引入类似 MCN 协议的方式就是去规避或者约束律师。律师提供的是身份认证和职业认证，市场提供的是运营账号。那这个账号起来，有了粉丝、案源转化后怎么去做分配，我们需要把这些东西约定好。甚至这个账号做到一定量级以后，律师想要离开这家律所，他是否能够带走这个账号也有一定的约束，这样其实就从保障律所的层面打造了个人律师IP，也能有非常好的机制保障双方的利益。包括律所的账号让律师参与的话也需要签订这样的协议。

总结一下，在初期启动阶段，我们给激励，案源分配与品牌曝光。另外就是采用了 MCN 的管理方式慢慢形成项目制来管理律师的自媒体矩阵号。前期我们遇到的问题基本上就是用刚刚说的这些方法去解决的。

2）持续增长阶段

第二个阶段是持续增长阶段，有一个量级的突破。我们所在的赛道其实并不是特别的拥挤。这个阶段的话我们启用了一直延续到现在的项目管理机制，为 IP 律师配备他的内容运营、账号运营以及视频编辑，然后搭配着 IP 律师形成项目管理的机制。律师自己还可以组建一个律师团队来和他共同消化由这个 IP 律师自媒体矩阵产生的案源，这样就会形成项目管理机制。然后通过之前的图文沉淀，再延伸到短视频的内容发布、直播，我们就有了更多的流量入口。

在这个部分我遇到了一些问题。

比如怎样去提升律师参与运营工作的能力？这个能力是什么呢？首先，律师过去不需要出镜，他只需要写文章就能完成这些事情，但现在对他的要求更高了，他需要出镜，只能本人出镜。他需要去做直播，那他参与运营工作还是需要拥有这样的能力的。

第二，怎么样去确定 IP 律师参与运营工作的边界？律师这个行业太过于专业了，这个问题也比较突出。

第三个问题就是我们的内容审核机制怎么去做？毕竟我们要去做普法的口播视频，我们的法律方向不能错、专业知识不能错，但是又要说用户听得懂的话，那我们的审稿机制是什么样的？

第四就是我们有市场人员参与到整个运营过程当中的，那我们内容运营在所有的运营板块当中，尤其是内容运营人员的专业度，我们怎么解决？

我觉得这几个问题是我在持续增长阶段遇到的重要问题，跟大家说一下怎么解决的。

首先如何提高 IP 律师的运营工作能力，我们要给他们做一些出镜培训。就像我们现在常说的我们要做 IP 定位，你这个 IP 呈现出来的风格是什么？律师说话的个人风格是什么？包括他整个仪态、妆容、表达等，我们都要给他一一做培训。

第二就是心态的建设。因为律师是入门门槛比较高的职业，他们其实有着专业人士的清高感，甚至说碍于面子不想在镜头前去做推广，这是普遍存在的情况。这个时候其实就要打破他的这种清高感，帮他在心态上做一些建设，告诉他做这件事情意义和目的是什么？他真正的价值在哪里？我们要给他梳理好这些东西，然后去培养他参与到直播这件事情的技能。这部分相信做运营的人都会非常清楚，其实也就是我们直播的流程设计、话术设计。

以上我觉得最难的是心态部分。因为并不是所有的律师或者专业人士在下场做自媒体时，能够真正地打破自己内心的端着的专业形象。

律师都会非常缺案源，但是真正要去做的时候就会出现自己想说的、想做的和能做的不一致。所以我们在培训中也尽可能地去说服律师关心用户。因为这是打破传统获客模式，通过平台跟陌生的潜在用户、潜在客户建立信任的过程，所以你必须得让用户先能听得懂你的话，那就是讲正确的、明白的、生动的东西。

然后就是树立自己专业形象的时候也要尽可能地释放自己。尤其我们做行政诉讼这个领域，面对 c 端的用户其实大多数都是比较淳朴的老百姓，这个时候要和这些用户贴合在一起，能够同理他们的痛点。在保持专业的同时也要更多地贴近用户，别端着也别装着，这是要长期持续不断做的工作。

第二个问题是怎么让 IP 律师参与到专业运营工作当中的？这些边界怎么去确定？

我举一个例子，最开始我们在做这个事情时，律师在生产文案的过程中习惯性地带入法言法语，喜欢用专业的术语来表达，但这样的法言法语在短视频平台上，用户很难在短时间内听懂。用户可能觉得你很厉害，但是他们还是听不懂。律师又放下不了自己坚持做专业形象的执念。所以我们引入了 AB 测试的方式，来让律师接受我们运营团队的思路。

这个怎么做呢？首先就是同一个选题策划，我们让 IP 律师写一篇他认为满意的内容脚本，内容运营伙伴也出一个内容脚本。用同样的拍摄方式拍出来，把这两个视频都发布到账号上去，通过这两个视频反馈的数据来说服我们的律师。一般来讲我们内容运营出的文案都会让用户听懂，数据表现也会优于律师自己出的版本。我们会反复地进行这样的测试，让律师感知“能够获得很好流量、能够获得很好线索的文案是长这个样子的”。

在长期的反复测试当中，他们就慢慢地接受了我们市场团队的运营思路，放下了“法言法语”的执念。另外我们引入了项目管理的方式，内容运营和 IP 律师是长期搭档在一块的。建立这样一种良性循环以后， IP 律师他也就不再去纠结文案写得过于通俗，有可能会引起歧义这些非常细的东西了。

接下来这部分其实说一下律师和整个律所的结构问题。首先做自媒体这件事情一定是这个 IP 他想要去做，那他肯定要把自己的工作内容和时间做相应的调整。传统律师是一个超级个体，他需要去搞案源、谈案子、做方案、做法律服务的交付、客情的维护，有的还要涉及到二次开发。但如果想做 IP 并且想拿到一个很好的结果，他在时间和精力上是要放弃掉一些东西的。在做 IP 的过程中，我们的 IP 律师其实是放弃了办案的一些工作的，把更多的时间用来配合运营，做我们内容的运营、内容的发布、直播。所以想做这件事最难的点就是如何做取舍。

然后“我能不能做”这件事情其实更多的在于律所机构对于律师做自媒体的整体支撑，也就是说律所它是不是由市场团队来完成这些运营工作？律师的 IP 打出去了，形成的案源在这个律所的公共案源池里面怎么分配？怎么转化？销转团队怎么建立？整个更多的是机构的机制设置问题，是战略层面的问题。我认为真正地去做这件事情，想做和能做这两个方面非常的重要。

这个阶段也会涉及到一个问题，叫内容审核机制，我们最终还是让 IP 律师来决定最终定稿的文案。我们做完一个月的选题策划且选题没有问题时，会出文案。如果说律师对于最后出来的文案内容有自己的想法或者不想用这篇文案，我们基本上还是尊重律师的意见的，也就是说律师是作为我们最后出品文案最终的把关人。这会给律师一点掌控感，让他觉得在爱惜自己的羽毛。

“怎么提高内容运营人员的专业程度”也是我经常会被问到的一个问题。首先从招聘这个环节，我们就会有一个选择，到底是选择法学背景的还是非法学背景的？我过去的招聘和管理中，这两类都有，而且这两类伙伴进入到市场团队以后会有一些不同特点。但我觉得真正好用的还是非法的，为什么这么说呢？

行政诉讼的法律知识在整个法学体系中相对来讲比较简单，也比较少。所以只要是本科以上毕业的，对法律服务行业感兴趣的，能够写得出我们标准文案的就足够了。而且他们可能没有法学背景伙伴的那种执着。法学背景的这些伙伴还是有点类似律师，他接受过法学的教育，一开始是放不下法言法语的。

然后在人才培养这个部分，除了上面说的培养内容运营专员一些运营知识以外，我们每周都要让律师参与到运营人员的专业培训中。同时我们给每个律师都会搭配或者说培养匹配他项目的内容运营伙伴，他们也会形成长期的默契。内容运营伙伴会去钻研律师说话的方式，用到他写的文案当中，这种合作模式是长期的，也是持续的。最后我们内容运营人员基本的工作内容就是找选题、写文案、培训，其他啥都不干。

3）稳定成熟阶段

过了第二个阶段，我们就到第三个阶段——成熟稳定的阶段，这时就要真正有转化了。在转化中我遇到了两个问题。

一是我们的账号到达一定的量级，比如几十万，有流量后，如何在这些流量中拿到更多更精准的案源或者说流量？虽然几十万粉丝在自媒体平台上也很常见，但是对于垂直细分赛道已经是很难的了。只要我们的账号上了 10 万粉丝，做转化就比较稳定了。我们这几个律师矩阵号能够支撑 2000 多万接近 3000 万的业绩转化，我们也就要求前端的流量来得更加凶猛。然后第二就是我们的线索进来后，转化率怎么提高？这也是这个阶段比较难的事情。

先说流量阶段，我们从过去关注流量的增长转变为关注精准流量。这个事情我们怎么做到的呢？在 2022 年，我们就制定了精准流量、精准文案和流量型文案的标准。然后内容运营同学在做月度选题策划的时候要细化到说这个月流量型的文案做几条，选题是什么？精准型的文案的做多少，选题是什么？从生产源头上去做控制。对于内容运营的考核，我们也从过去只考核整个账号的整体流量调整到对精准流量的考核。那在数据上怎么体现呢？

首先来看一下精准文案的标准。大家在这里能看到我们对不同领域精准文案标准的汇总，符合这些标准的，我们把它标签为精准文案，然后统计这部分文案发布以后产生的流量，这就是所说的精准流量了。

在提高转化率这个事情上，我们首先是强化了销转团队。销转团队过往 90% 由律师组成，这部分律师等同于我们的 IP 律师。我们的 IP 律师作为项目管理的第一负责人，他可以去发展、去招聘一些律师进入自己的团队和自己一起去消化我们渠道产生的案源。现在这部分律师做销转，只负责谈案子，不再负责办案，打破了传统律所的作业模式。

到了销转环节，为了提高转化率，我们做了有效线索的判定标准。常规情况下市场人员是参与不到线索判定的，判定这个环节是由销转团队做的。但是为了能够体现出市场的作用，我们的判定标准是由市场团队和销转团队共同制定的。这样可以有效保证市场团队生产出来的线索能够更好地转化。我们也引入了一个市场抽调机制，后面可以给大家展示一下。

首先，我们制定出了线索分级的标准。什么样的线索是符合星级标准的？一星的线索长什么样子，二星的线索长什么样子？我们都在这个地方做了详细的描述。

在这样的分级规范下，我们市场人员还会定期发起线索抽调。也就是说线索到了销转团队，销转团队跟进以后在我们的客户管理系统当中记录，然后给这个线索进行价值判断。你判断的到底准不准，由市场团队定期按照一定的规则去做抽调。

比如我现在展示出来标红的地方，是市场人员在抽调时发现的销转团队做的不合规的地方。这个合规和不合规的标准就是之前展示的那个部分，比如线索录入到第一次跟进的时间没有按照标准执行，我们要求是两个小时内必须去跟进，他的反应时长已经是 4 个小时了，肯定是不合规的；或者价值判断上存在问题，没有详细的案情描述，也没有具体的跟进记录。

那怎样把这条线索判定为1星线索呢？ 1- 5 星是逐级递增的， 5 星就是接近于签约的线索了，3 星以上我们叫有效线索，还需要跟进；1、2星基本上属于无效线索。

所以抽调也是根据我们共同制定的线索跟进标准，去反向检查销转团队对待线索时是不是按照标准执行的，当然销转团队有一些奖惩制度。我们市场端去做抽调首先保证了减少那些被误判，甚至说是由于销转团队没有按照工作标准执行而产生的线索流失，这在我们提高线索利用率或者转化率方面还是有一些效果的。

接下来简单总结专业领域做短视频转化的模式参考，我觉得下面四个点是特别值得说的。

首先如果是我们律所的账号，我们可以对参与到律所账号运营的这些律师给一些激励，让他们能够积极参与机构账号的创作和直播。相信我们群里面的伙伴可能都遇到过一种情况，我们除了要做身份认证、职业认证以外，直播的时候也有直播资质的认证。在这个事情上，我们 2023 年初经历过一段非常痛苦的时期。平台，尤其是抖音的直播资质认证要求非常高。有些需要机构的账号必须上传出境的直播律师和律所的关系，也就是挂靠关系。

我们过往会让一些 IP 律师团队下面的律师利用 IP 账号做直播。比如主力 IP 是某某律师，他这个时段是在抖音上直播，那其他的律师可能在他的其他号直播，这样能大面积地铺开我们的直播。也就是说我们的账号和我们的主播有的时候可能没有一一匹配。

但随着平台管理变严格，从 2023 年 5 月份开始，我们个人律师账号都需要 IP 律师出镜直播，参与到律所账号直播的这些律师也要去做到直播认证。如果要做专业自媒体的话，职业资质价值度还挺高的。我们不敢让他的账号被封掉，被封掉的话也很麻烦。它不像素人账号，只需要做身份的认证，职业认证没有这么多的要求。

第二就是在运营律师账号的时候参考 MCN 机构的管理方式，跟他们签订合作协议，保障我们投入的运营成本以及最后的收益能够约定好，进而让这种运营机制能够持续有效地进行。

第三就是运营人员，这部分给我感触最深的就是在法律服务领域中，运营人才是真的非常稀缺。因为大家都会觉得法律行业太专业了，在内容上除了要掌握平台运营的逻辑、技巧以外，可能还得学习专业知识。所以说在运营人员这一块，我们也要结合专业的自媒体给到合理的运营目标、薪酬体系、考核机制。

刚刚也提到我们是用项目管理的方式来给律师做自媒体矩阵的。2022 年下半年以前，我们运营人员基本的薪酬就是底薪加绩效加一定的市场奖金，它和渠道运营的创收是不挂钩的。

但既然我们市场人员在创造高价值的线索，而且还要做线索抽调提高转化率，那我们其实可以通过整个分配机制，把渠道的创收奖励给市场运营人员。所以 2022 下半年以来，我们会拿出一定比例的自媒体案源的当月创收来奖励我们市场人员。这也是参考了其他领域操作模式，然后在自己领域里做的尝试。

第四部分就是销转机制，这也是非常难的部分。销转要求对自媒体获客线索的跟进速度非常快，因为用户在平台上做对比的成本太低了，你没有很好跟进的话，也许就被别的渠道或者别的律所同行给抢走了。所以我们销转团队必须扎扎实实地去做这件事情。如果他们还要办案子，就没有办法及时解决问题。

对于目前这种专业领域来讲，要模块化管理，要把人放在不同的工作环节中，这样才能很好地把转化渠道线索。这个部分的建立，除了团队，分配方式也要做到配套设置，这样才可能保证从流量到用户，用户到客户，再到最后的交付有很好的闭环效果。所以在专业领域里，我觉得如果想要在短视频平台上做获客，这几个点值得参考。

### 02 运营数据管理

接下来我想给大家说说，运营的数据管理。

第一个维度，我们会统计账号矩阵的流量数据、粉丝数据、有效线索量还有有价值线索成本这些数据。

我们还能看到每个项目组这个月每天产生的线索总量以及有效线索总量。整体来看，法律服务赛道，尤其是行政诉讼领域，我们能把有效率做到差不多 15% 以上。

单看的话，每个项目组的线索量和有效线索量会呈现不同的特征。比如有些项目组线索量高，有效率也不错，最后有效线索量也很好。有些项目组线索量获取相对就低，但有效率比家里高。这个跟每个律师账号的体量、律师的个人风格、销转团队的专业度等都有关系。

除此之外，运营的数据管理，也会关注到每个账号每天产生的流量。

在各个账号矩阵的直播数据管理中，我们会做排期场次和实播场次。从渠道的场均线索获取来说，数量并不是很高，但在细分赛道中，我们想要做的就是去抓非常精准的部分。我在跟其他行业的自媒体运营伙伴交流的时候，他们会疑惑我们量级也不大，怎么能支撑千万级的营收。因为非常的垂直，非常的精准。

最后在直播运营数据管理里面，我们能看到每个项目组，具体到每个律师每天直播的数据情况。我自己认为这些做的还是比较精细了。但专业赛道和电商还是有一点区别。做电商的话，数据可能会更加复杂，但对专业领域来讲，这样的数据已经够用了。

还有就是我们没有做大量的投放。我们能看到右边投放金额这一块，其实都非常小，都是小额的投放。为什么会这么做呢？因为我们还是希望通过内容去吸附精准流量进来。整个直播过程中，场观超过 100，我们都觉得算是不错了。

当然现在账号矩阵上也有上千了的自然流量，这个时候我们就采取双人直播。因为律师其实跟电商直播主播比还是过于“娇气”，一天干七八个小时的律师不常见。最开始我们的场均直播时长要求不低于一个小时，然后可能是一个半小时或者说不低于两小时，每天可能就一场，多的两场，这个时长是远远达不到电商直播的。

在这样的有效直播过程中，我们尽可能去吸附精准流量，然后再投流。所以自媒体矩阵这部分我们的投放并不多，反而会把一部分投流成本放在 SEM 上，做一些品牌词的投放，让所有的用户在自媒体上看到我后，搜索引擎上也能搜索到我，在他经过的地方都能有我们的内容，让他能做消费决策。

在分享的最后，我想给大家说一下我自己的观点。法律服务的专业赛道结合自媒体账号的运营，我觉得有三个点是非常关键的。

第一个就是专业服务赛道做自媒体，想要做出案源的转化，需要系统支撑。并不是只要到前端把线索拿进来，把所谓的客资拿到，就能够做到很好的转化，我觉得这个更多的是考验律所机构。现在我们这个行业中有公司化运营的律所，这样的律所它会做得比较好。

为什么我最开始的时候会问律师做自媒体到底是赚吆喝还是搞案源？如果是赚吆喝，你有一点粉丝量可以作为品牌背书，人家去搜的时候能搜得出来，增加信任基础。但如果真的是搞案源，那需要系统支撑。这个系统包括机制系统，软件系统，并不是说线上来了流量，然后到我的微信、我的私域里，我就能很好地去转化它。

第二个就是不是所有法律服务细分的业务领域都能够在自媒体平台上拿到结果。除了我过去做的行政诉讼领域以外，像婚姻家事、刑事辩护、劳动用工、债务执行、建筑工程这些领域非常容易在短视频赛道拿到市场运营的结果。但像一些专门做顾问服务，顾问单位是政府机关或者大型的央企、国企的律师，更多的要在圈层资源运营。他的甲方也不太希望这些律师在自媒体上做抛头露面的事。所以说这样的业务领域在自媒体上其实受到一些限制。

我不认为这个行业所有的细分领域都值得去做，尤其是我说的这几个。但如果说感兴趣的话，我还是非常鼓励他们选择这些业务领域去做。包括像一些搞上市、融资、破产服务的，在短视频平台想要做转化，我认为还是很难的。如果说从法律服务行业延伸出去，上升到专业领域概念的话，我觉得都值得用运营的方式来让我们的业绩实现增长。为什么说是增长呢？因为我认为专业领域还是有自己的常规线索或者说客源基本盘的，我们可以用自媒体方式让它长出第二条大腿。

最后在结束之前，我想和大家分享一下我的职业规划思考。

我在 19 年进入法律服务赛道，在23年 11 月份就筹备了自己的团队。这个团队人员来自于法律运营一线，从案源开发、法律产品、律师品牌和团队管理四个板块辅助律师团队或者说律所。此外我们团队现在出了一本书，《律师案源开发实战笔记》，同时也形成了两本内部资料。我们也希望后面能够总结出更多的行业运营经验给到大家。

现在我也参考了行业社群社群运营的方式去搞了一个知识星球，叫格律诗和他的朋友们。我们吸附了第一批付费用户，基本上都是律师。在群里面给大家分享一些干货，包括我们对于法律运营的思考，实战指引等。我们预计在我们春节后有个落地活动，把我们的新书做个发布。

今年作为一个新起步，我希望去尝试一下除了行政诉讼领域，我的运营经验或者说运营的积累能不能帮助法律服务赛道中的其他领域实现业绩的增长，我也希望能够跟我们行业社群的朋友们一起去探索。我觉得运营这件事情或者这个工作，它的乐趣和焦虑都来自于需要不断地去学习，成长。

## Q&A

格律诗的盈利模式  
刚才讲到我们业务有四个板块：法律产品、案源开发、律师品牌和组织管理。我们会去市场中选择我们能够去做辅导和陪跑的团队，律师团队或者律所交钱，我们参与到辅导当中，可能是专项的，也可能这四个板块我们都能去做。比如现在作为核心的是案源开发板块，那我们会帮律师团队把案源开发体系搭建出来。  
其实我们也是在挑选客户。虽然我以前没有做过咨询交付这种工作，但是我觉得如果我们想要辅导团队的话，这个团队本身也要具备要有一些市场意识，且团队主攻的业务方向是我们判定能够在自媒体上拿到结果的。如果不符合这样的标准的话，我们可能也不会做。

如何看待律师代运营工作？  
我觉得代运营、管理咨询以及我们现在想做的之间有一个界定式的东西。  
在法律运营的赛道中，我看到其他的伙伴做的是管理咨询，就是帮当整个的律所去解决明年该怎么干，在战略方面是不是要增加一些业务，人员怎么管理，怎么留得住律师，合伙人层面应该怎么做这些问题，是战略层面的东西。还有一些团队在做一些执行层面的问题，比如代运营。律师可能把自己的账号外包给一个团队，这个团队通过洗稿的方式去把这些律师的账号代运营起来。这个事情我不是特别想做，首先我觉得与其去代运营其他律师的账号，待在我之前那家律所成就感会更高一些。  
其次律师真的是很难管理的一个对象。他们的自我认知挺高，还有清高感，对你的要求比较多。你要和他磨合出这一套很丝滑的运营方式是很难的。  
第三点回到我现在做的工作，它介于战略咨询和代运营当中。我们今天盘点了一下，其实我们整个服务周期当中，有一部分工作是跟代运营重合，但我们不把它定义为代运营。比如我们现在辅导青岛的律所去做案源开发，会先去诊断。让他们梳理现在案源渠道是什么样的现状，然后再来看是不是要帮他做案源开发，到底是从线上开始还是从线下开始？从线上开始，如果主体是律所，可能建议他去做一些本地化的平台运营。如果是律师团队，拿不到律所的资质，那么本地化的平台运营就跟他没有关系了，因为他没有资质背景去开线上店铺。这时我们就会看他团队有没有人具备做自媒体的能力？如果有，我们就来打造自媒体。  
当然交付的前期我们也要反反复复跟他们磨一些文案，搞 IP 定位，也要去指导他们怎么去拍摄，但是这只是我们交付服务中的一部分，不是说我一定要去做代运营的。目前几个客户合作，我们拿到了线上案源的运营，但是陪跑辅导的服务，我还没有拿到很好的结果。我认为我们目前的业务是介于战略咨询和代运营中间的部分。  
代运营的工作的话其实分几种，短视频是一个方面，还有本地生活化的平台。像抖音小店，美团点评，还有地图都是本地生活平台的运营，这种基本都是基于律所的合作，或者某个律师团队拿到了律所的资质，由团队来做全权的代理，这种方式的话是可以做到的。

在私域这块儿是否开发了自己的流程管理软件？  
市面上有非常多适合律师团队、律所用的管理软件，这些管理软件它会涉及到我们的客户管理，功能比较齐全的还有按键流程管理，所以我们没有做自己的开发。

线上获客运营思路也适用其他方向吗，比如说职业生涯咨询订阅？  
我个人觉得很适合。  
职业规划其实也是专业领域的一个部分。如果真的做职业规划，那它交付服务的设计我觉得很关键。我能想到的是看它前端能够拿到什么样的流量级，以及它转化的是什么客户，交付都是一个 IP 去完成吗？另外一个思路是职业规划的服务交付除了能通过咨询的方式完成，还有没有其他的产品形式？  
举个例子，比如做婚姻家事这个赛道，那么多流量一来就说律师我要离婚，但是他可能想要的就是一个离婚协议。这种东西属于一个轻交付或者说零交付的东西，它就摆在那里，我把这个产品给到用户，这个流量就消化掉了，只不过我消化的方式不是案件代理。当然每一个用户背后的诉求是不一样的，所以我们要按照自己所处的领域去设计产品，尽可能的去覆盖掉我们线上获取的这些流量。

陪跑拿结果，重要的在客户筛选？  
对的，我觉得在做新的业务时，你的客户也要长得像你的客户才容易出结果。  
给大家讲一下我们团队发生的事情。在客户的匹配上，我们最开始评估觉得这个客户的合作的基础是非常好的。首先它是一个律所，以机构主体的方式来合作，那它能够运用的资源就比较多了。第二，他这个律所人不多，但背后有 5 个合伙人， 3 个合伙人是真正的执业律师，2个合伙人属于管理类型，我们最开始合作推进的非常顺利。  
后面就出现了一个情况。我们在做服务的过程当中，首先确定他们要做线上案源的开发，尤其是短视频这一块。于是我们也提供了怎么样去生产短视频文案的指导，帮他们修改了文案，培养他们现在市场人员的运营能力。  
但在这个过程当中，他们的市场人员离职了，我们这个服务还在继续推进，但没有人落实了。其他的合伙人，尤其是律师、 IP 律师就比较着急。他们现在要一些文案，要开始直播了，但自己的团队没有人能够辅助到。我们也不可能天天守在这个客户这边，所以负责人员就提出不合作了。在这样的一种状态下，这个费退出去了，这个客户就黄了。  
所以我觉得客户的筛选真的是非常重要的，我们内部要梳理出来客户真正具备哪些东西，具备什么样的标准或者说什么样的基础后再去合作，这个对于我们拿到结果是非常重要的事情。

运营团队人数、销转团队人数比例大概是多少？  
我们是属于非常典型的一鱼多吃方式，一个律师的矩阵前端的标配就是一个内容运营人员，一个账号运营人员和一个视频编辑。在控制成本的时候，可能会让一个视频编辑兼顾两个项目组的视频拍摄和剪辑工作，但是内容和账号运营这两个人是雷打不动的，不会去做项目交叉。你可以理解为运作一个IP矩阵，我们的市场团队的人数是 2.5 到 3 个人。  
销转团队这一块的话， IP 律师除了去拍视频、去直播、去做客户跟进，他还要培养自己的团队成员和他一起去做客户的转化。基本上是这样来的，少的项目组团队也会有 4- 5 个人。如果说运营五个渠道的话，那销转团队的话就在 25 个人，平均下来是 4 到 5 个人的样子。

律师在本地美团上宣传吗？  
应该说律师可以借助律所的资质在美团点评这样的平台上做。我在成都时，为了能够很好地做律师招聘，也成立了一个律所。我就用这个律所的主体的资质在美团点评上开了线上店铺。当时我也是把律所的美团点评店铺做到了全城前十，商圈第一。大家去本地搜一下律所就能看到非常多的律所已经在做了。这个对于我们运营来讲还是比较简单的。  
但是这要求必须是律所的资质。这周我跟高德地图法律板块的负责人沟通了一下，我跟他提到了这一点，说很多律师是想做推广的，但是个人律师在平台上不允许去这些，不是每一个律师团队都能拿到律所的资质。有一些律所他自己不做，也不会让渡这个资源给律师团队，所以没有办法打通资质的问题。  
高德地图现在也是在尝试把他线上店铺的运营端口开放给律师团队或者个人，当然这对于平台而言会有一些风险。所以他们想测试一下能不能跑通，如果能跑通的话，地图类平台也许值得律师赛道关注。这也是这个星期我得到的行业信息。
