# 01 业务流程分享

这是我们最近的一些直播和短视频获客成果展示（下图），直播时长大概在一个小时到一个半小时，一场直播多的时候能有 100- 200 客资，具体看 IP 的状态，如果 IP 状态好，我们就拉长一点时长；如果 IP 状态不好，我们就缩短一点。

关于直播转私频率，我们大概五分钟左右一轮。如果直播间流量高，我们会适当增加一点时间，让主播或者 IP 在前端多争取一些流量。我们的路径是，让大家先按照直播中的引导进入粉丝群，然后在粉丝群集中进行导流和转化，直播中的私信相对较少。

而我们的短视频以线索型为主。对线索型短视频的评定标准是：只有能够引导用户进入私域并且具有销售属性的视频，才能称为线索型。不是说在短视频里中途做个软营销，或者在结尾放个钩子，比如 “找我领个资料”就可以，客资进入微信必须能够变现。

短视频的转私路径，一方面是通过私信，另一方面是通过粉丝群集中转化。因为有些学员看到短视频后会直接私信，所以我们在后台评论和私信这一块，还是要下点功夫的。

下面介绍一下我们获客的链路图，以用户的角度出发，形成这一张用户行为流程图。我们主要以直播为主，短视频为辅。

简单说是通过短视频把用户导流到直播间，然后在直播间促成订单，比如通过橱窗或者抖店销售 199 元、998 元的课程，买了课的人会收到购课短信，点击链接就能跳转到微信。

当然，直播间里还有一部分人可能只是想白嫖，或者连麦咨询问题就走，对于这类用户，我们也会引导他们进入粉丝群，然后在粉丝群引导用户扫码，让他们进入我们的私域池。（线索型短视频吸引的用户，会直接进入粉丝群）

在私域池里我们会进行分流：

一类是购课学员群，这些人已经买了课，他们的需求更精准。针对有强烈意愿的用户，我们会直接安排电销跟进，通过电销来提升客单价，比如升到 59800 元的陪跑服务，低一点的 39800 元也可以（都是同一类产品）。59800 元的服务基本上是三个月陪跑、三个月评估。如果学员有续费意愿，那就续费；如果没有，那就流失掉。

另一类是需求不明确、还没付费的人，我们会把他们拉进粉丝福利群，通过文字销售或者社群营销来转化。

与此同时我们会把一些比较优质的学员问题拿出来，反哺到直播间。比如让学员在直播间连麦，他们发现直播间能够解决问题，就会买课，然后又进入这个流程。

# 02 IP 怎么选择？

接下来，跟大家聊聊 IP 的选择。

我接触的 IP 越多，就越觉得 IP 这个工作其实是在燃烧生命。如果大家遇到一个 all in 的 IP，他们会像发了疯一样，不停地摄入知识——运营给的数据、编导给的素材、操盘手给的对标账号、商业路径等等。甚至，他们还要顶着直播间那些黑粉的攻击，在前端进行持续的内容产出，他们是在用自己的能量来养活整个团队。

那么既然 IP 是一份燃烧自己生命的工作，我们就更应该珍惜他们。所以在选择 IP 上，我非常的谨慎，为此我这些年拜访了数十位在知识付费领域做 IP 孵化的顶级操盘手，总结出一些经验分享给大家。

## 1）观察 IP

先观察IP本人是否能合作，不要因为谈的分润很高就盲目的签约或深度捆绑。

这里强烈建议合作的IP有两种，一种是经历过商业周期，失败了还想再回到顶峰的男性，这部分男性懂商业规则，知道团队的重要性，也知道沟通成本极高，风口就那么一阵，他们的要性很强。

第二种，经历过生活苦难的女性，她们或是生过了小宝，或者是离异后理解了人性底层，知道没钱不幸福，在经历这些波折之后也知道沟通的重要性，自身的情商和对团队的包容度会更高一些。

这样的 IP 合作起来会非常的舒适，特别是对于以 IP 为核心的知识付费赛道，更显得尤为重要。

接下来，我们聊聊谨慎合作的 IP。我在这里列了三类，相信大家都或多或少接触过。因为和这类 IP 合作，可能会搞心态，消耗自己的心力。

首先是 20 岁左右的小姑娘和小伙子，他们共同的问题是不懂得团队配合，很难理解团队的组织架构，也很难理解要走得远必须依靠团队共同努力。这一类 IP，合作起来可能会比较费劲。

而一些有底蕴的老板或者说是企业家们，他们已经取得过成功，所以对自己的时间和精力要求很高，希望付出得更有价值。比如，他们觉得一个小时能收费 1000 元，就绝对不会去直播一小时只收几个客资。这类老板沟通成本很高，你追着他去直播，他可能会找各种借口推脱，比如 “我有点累” ，或者干脆就不直播了。

他们觉得一个月没见到效果，就不想跟着你三个月，因为他们觉得这三个月还不如拿去做别的事。和这类 IP 合作，解释成本太大，会极大消耗操盘手的信心和心力。对于一些心力强、情商高、性格好的操盘手来说，可能还好，不会那么内耗。但如果操盘手性格比较急，可能就会陷入负循环，比如内耗、焦虑等问题接踵而至，最后可能导致合作崩盘，甚至自己也落下个不好的名声。

## 2）提炼 IP 个人思想

观察好 IP，下一步就需要对这个 IP 进行思想提炼。通过编导采访或者让 IP 自己评估等方式，客观地看一下 IP 个人的核心思想是什么，所面向的人群是谁等等。大家可以看一下这份 IP 自我评测表，这些是我跟 IP 沟通时会经常问到的问题，围绕愿力、人设、专业、娱乐等板块展开，形成一份 IP 文档。

“知己知彼，百战不殆” ，你的卖点和用户的痛点要相匹配，很多 IP 没有做这种思想提炼，自己都没有统计过自己到底知道哪些东西，有多少方法论，有多少营销卖点，也不知道用户有多少痛点。既不了解自己，也不了解对方，那么最后做出来的结果大概率是效率不高的。

在完成 IP 的思想提炼之后，我会对 IP 进行潜力评测——把 IP 的潜力分为下图的几个板块，进行客观的评测并计算分数，分数大于 30 分的 IP，我会考虑与其谈一些深度合作。

当然，权重系数可以根据你的项目需求自行调整配合。比如你是脚本型的直播，更依赖知识 IP 的表现力，以及拉流能力，连麦能力可能不需要那么高，可以提高表现力的权重。

# 03 IP 如何矩阵化

我为什么会做小矩阵，其实最开始只是单直播间和短视频打穿就可以做下一个项目了，但奈何平台封锁，导致当时卖课销售额忽高忽低，甚至不让直接售卖，只要挂上小黄车就给封号，不管你说了啥，而且封号就会导致 IP 焦虑，然后出现流量腰斩、在线下降等情况，那么为了扩大曝光量，抵抗平台风险，就只有做矩阵。

大家都听过做矩阵的核心是要有爆款素材，但在我看来，做矩阵已经不仅仅是靠爆款那么简单了，也不是只要有一个爆款或者多个爆款就行，做矩阵的前提是素材足够多，创造一个不断产出的素材场。

## 1）账号布局怎么做

对于抖音平台的账号布局，我们头部账号只设置一个，用来做人设展示。只用来发短视频，不直播，因为像情感、律师、大健康甚至是相亲赛道，直播很容易违规。

真正发力的点在腰部账号。把短视频的流量导入直播间，进行引流获客、卖课。如果管控不严，前端就直接卖课；如果管控严，前端就转成获客话术，把流量引到粉丝群里进行开单。一般会设置 1-2 个，平台管控严的时候会增加到 3-4 个，用来抵抗直播封禁的风险。

尾部账号我会准备 2-3 个，一旦我们的腰部直播账号被封了，尾部账号就可以拉上来用。对尾部账号的要求并不高，只要能把短视频传播出去即可。因为主战场还是在直播间，尾部账号有一定的粉丝沉淀，配合 IP 的直播能力，起号稳号会容易很多。

## 2）素材产出

那我们是怎么做素材的产出呢？针对学员和非学员的咨询问题，我们通过文销或电销将其转化并筛选后转入直播间进行连麦，这样一来，只要直播间在连麦，连麦素材就可以制作成直播切片在短视频上传播。同时（线索型）短视频又会吸引更多人转到私域，甚至再导到直播间里面，这样一来，我就形成了一个源源不断的素材产出闭环。

甚至如果连麦切片违规，我们以口播形式作为素材散发就可以，只要定好文案框架，那么各个板块就可以有N多素材可以用来拼接再分发。

## 3）变现内容画布

接下来想强调一下信息对齐。我们之前在矩阵的起始阶段接入了付费推广，但效果却不好，原因就在于大家获取的信息不一致。以用户痛点为例，如果单个用户群体有 5 个痛点，有的伙伴只知道 3 个，有的文案伙伴只知道 4 个，信息就不对称，所以要做好信息对齐。

我会让团队成员集中理解 “变现内容画布” ，并将其作为电脑桌面图。这张图的作用就是让每一位伙伴都增添销售属性——知道我们在卖什么，产品可以解决哪些问题，是如何解决问题的，以及我要用什么样的姿态去跟用户对话，从而提高我们在私域的转化率。

当文案伙伴看到这张画布时，他们会设身处地地为用户着想：我要作为一个什么样的角色去写这篇文案？是作为一个姐姐，还是作为一个导师的角色？剪辑伙伴也会有销售属性，他们会想：视频内容能让用户产生共情吗？而不是仅仅把短视频剪完就发布到平台上。

展示一下最近我们编导的日常转化成果，他自己没事拿私域的手机，跟客户聊聊天，就能转化。这就是 “变现内容画布” 的好处，很多伙伴抗拒销售，那就在工作内容中融入培养销售意识。

我们不需要每个伙伴都去做销售的工作，但一定要以用户思维去思考：能不能帮助到这些用户？我获取到这个素材，或者我出这篇文案的时候，应该用什么样的方式跟他说话？我们的案例有哪些能够帮助到他？哪些素材能够匹配上？

如果发现你在聊以上内容时，团队小伙伴无法理解你的思维，那就说明你们沟通出了问题，需要做好信息对齐的工作。

比如，做好一份信息文档，列好 1、2、3、4 点，然后拿着这份文档开个小会，给他们讲讲接下来要做的事，以及必须要掌握的核心点，要稍微耐心一点，把信息点讲清楚。甚至可以在开会做好录制，然后把音频转为文字，丢给 Deepseek 或者其他工具，让它生成一份文字大纲。做完文字大纲后，让小伙伴们讲给你听，看看他们是否理解了你要传达的内容。

# 04 如何用 AI 实现获客全链路提效？

接下来进入关键板块：我们是如何把 AI 融入到日常工作中的？我把它分为 5 个节点：分别是团队赋能、文案运营、剪辑运营、直播端口和私域端口，基本涵盖了所有工作链路。

## 1）团队赋能

今年 2 月份大家开始用 DeepSeek 的时候，问两三个问题就提示繁忙了。但我当时没有遇到服务器繁忙的问题，因为我的 DeepSeek 是提前配置到本地的。后来团队伙伴问我：“你的 DeepSeek 有没有服务器繁忙？” 突然意识到，我们又需要做信息对齐了。

基于这个情况，我整理了市面上所有关于 DeepSeek 的资料，包括文档、PDF，比如清华 100 多页的 PPT 分享，还有 DeepSeek 如何高效制作 PPT、DeepSeek 如何高效出图、DeepSeek 如何高效出思维导图等等。结合我自己的实践经验，我进行了一波信息整合，整理出了一份内部使用的 DeepSeek 手册，用来提高团队的工作效率。这份手册大概有 70 多页，涵盖了所有关于 DeepSeek 的操作。（俱乐部会员可以附件下载）

## 2）文案运营

接下来是具体的业务提效，首先分享一下我们短视频侧的应用，短视频侧分为两个板块：短视频文案、短视频剪辑。我先聊聊文案运营板块。

在 DeepSeek 内训会议刚结束的时候，我的编导伙伴问我：“这玩意儿能不能用在工作里减轻一下负担？”，其实他是想在聊天窗口写文案，我以为他是想用工作流来解决劳动量的问题。我说可以，那就开干。

我打开文案运营协作手册，里面有短视频文案写作 SOP。这个 SOP 是基于 IP 思想提炼之后，构建出相应的人群，然后根据写作说明与爆款公式选定一个文案框架，直接输出拍摄素材。同时，我们还会把拆解的爆款文案总结到表格里。

在流程清晰的前提下，通过工作流，就可以将比较繁琐、浪费时间、重复性的事情进行整合。我整合的第一个板块是爆款拆解，以及公式入库、已拆文案入库和拆解表的整理。

（关于人群及方法论整合，其实也有一个工作流，只不过我还没有完全投入使用。具体来说，我可以去获取评论，再加上我的文案思路，再给出提示词，让 AI 在表格里帮我总结，按照我的思维去总结人群画像和方法论，这样就完成了整合。）

### 一号工作流：批量提取拆解改写

之前大家可能需要去抖音上获取视频链接，然后把视频转换成文案，根据需求一步步去拆解成标题公式、开头公式、金句公式等等。即使使用 AI 工具，也需要把文案复制到聊天窗口里，一步步拆解导出，再整合成表格。

而现在可以做到：用户、伙伴拿到一个工作流，把主页链接或短视频链接丢进去，就可以自动获取文案，拆解并填充到表格里。

我的具体思路是这样的：

① 提取链接

第一步是自动提取链接，链接的来源可以是飞书文档的链接，或者是飞书文件夹里的表格链接，关键在于表格里要包含抖音视频的链接。

②文案获取&转写

大家肯定要用到一些文案获取助手工具，把链接导进去之后，它会自动转为文案。这一步是基础操作。我做的改进是从表格里获取抖音视频链接后，通过一个循环体来处理：

进入循环体后它会直接获取对应抖音视频链接，然后调用市面上成熟的插件，解析为音频和视频两部分。我会再调用阿里云的音频转写服务，把音频转写成文案，转写后的文案会分为标题、金句、具体内容等部分。经过拆解和归类后，它会自动把内容填进表格里。

简单来说，就是把抖音视频链接丢进工作流，工作流会自动获取抖音视频链接，进行文案转写、拆解，并在飞书表格里进行填充。

接下来给大家看了一段短视频（①号工作流的视频演示），这段视频展示的就是刚才提到的飞书里面的链接表。我们先把飞书链接填进去，点击“试运行”，然后就能看到它正在工作。它会根据飞书表格里的抖音链接，一个个把标题拆出来，把原文拆出来。

而且，我在飞书的多维表格里加入了提示词，告诉它：“我要把标题拆解成一个公式，然后把标题公式填到这里。”这就是大家刚才看到的提效点。这个视频是加速的，大概总时长是 42 分钟到 43 分钟，处理了大概 100 篇内容。这一块的指令其实大家在网上也或多或少见过。

今天我只是把思路以及具体的实现流程展示给大家，具体实现还是要根据你们公司内部的业务板块，按需去写工作流。这个工作流在市场上是获取不到的，即使获取到了，可能也是一些不太健壮的版本，运行起来可能会容易崩溃。

现在，这一整套流程看起来还是比较震撼的。虽然看起来有点乱，但我可以让他们把 DeepSeek 的标题指令这一块隐藏掉，把相关指令也全部隐藏掉。最后，只保留标题公式、原文，以及从原文拆解出来的公式等内容。

### 二号工作流：拆解对标文案结构

这个工作流主要是针对文案框架。

之前我们获取到文案之后，文案转写完成，然后要把它们放到一个文件夹里。文件夹里会有很多文案，这就很麻烦，比如我现在列了 3 个文案还好，但如果是一个文件夹里有 10 个、100 个文案，那怎么办？你要一个个去拆解，拆解完之后还得手动把它们丢到表格里去改，这很浪费时间。

那这部分时间我们怎么节省呢？我们可以让智能体去勾选，或者用 TIPC 去写，让 DeepSeek 去拆解但是不用它写，现在我的做法是：文案获取到之后，直接丢到工作流里面，根据提示词自动拆解文案框架，然后填充进表格，就完成了，非常轻松。

接下来，给大家展示具体指令，我们是以 IP 事业树的文案和文案结构为基础的，当然也可以用总分总、论据加论点的形式去拆解，公司内部应该都有自己的文案结构。只要告诉它，你希望以什么样的形式拆解，它就会按照你的要求去做。

这其实只涉及到一个 DeepSeek 指令。这一块基本上是通过工作流获取之后，原文直接填到这里，然后根据指令自动填充进去。你们会看到有些地方会出现“无”的形式，这是因为我在提示词里标明了，如果没有拆解出这部分内容，就打一个 “无” 上去，不要乱填。

我不需要它给我创作任何东西，我只需要它替代我完成重复性、劳动性的工作。

这是我们2号工作流的演示视频。只要把文案粘贴到这里，或者让工作流自动填充到这里，它就可以自动生成。主要是拆解对标文案结构。如果你们要拆更细的东西，后面可以再加一些具体的形式词等等。这只是给大家做一个展示。

### 三号工作流：批量提取公众号

用 AI 释放出来的精力，就想在其他板块上继续发力，编导伙伴跟我说：“松哥，这个公众号文章 1000 多篇，你说咋办？” 能说咋办？那就开干。

比如说我们拿 “小声比比” 这个公众号来举例，“小声比比” 这个公众号有 1288 篇原创内容。以前我们是一个一个去扒的，用软件下载，整合成 1 号文档、2 号文档、 n 号文档，文档整合完之后再填到表里面去。甚至用软件可以直接导出表格，之后又导到飞书里去，路径极其繁琐。

而现在就是给定一个链接，给定一个公众号链接扔到工作流里面去，扔到工作流里面去，自动获取文案后填充进表就 OK 了，（还可以批量提取公众号评论区的内容）。

① 获取公众号内容

给一个飞书链接。然后它会拆解这个链接，找到链接里面的表格，再找到表格里对应的公众号链接。

② 判断链接有效性，获取内容

拿到公众号链接之后，可以判断链接是否存在、是否有效之类的。然后直接把链接丢到插件里，获取公众号的内容就行。

③ 拆解内容，进行分类

获取到公众号内容之后，它会拆解出很多东西，比如标题、文案、图片等。图片可能会以图片链接的形式拆出来。这一块的作用是把内容拆分，然后根据飞书多维表格的插件，把拆分好的内容一个个对应填进飞书多维表格里。这是一个循环体，循环直到把所有链接都转化为文案和标题。因为我们的需求就是文案和标题，就这么简单。

我给大家展示一下这个工作流，这是我自己录的视频，没有加速。这是整个工作流的页面，把飞书链接复制进去，其他不用管，直接点“试运行”。

点完之后，它就会自动运行。大家可以看，运行成功了。这个地方也开始输出了。但因为公众号主要是文章，数据量瞬间获取得非常大，有些可能没办法及时填进去。那怎么办呢？如果有些没填进去，我们再进行一次运行就行。这一块它不会重新获取已经填过的 1 到 11 这些内容，只会判断空行。我在工作流里已经设置了判断，如果有内容就不管它，如果没有内容，就重新获取链接并转化。

继续看，我发现这个地方没有填进去，那再进行第二遍。速度会很快，大家可以看进度条。好，这一块获取到了。上面这个还是没有获取到，那就进行第三遍。反正基本上填个链接，点一下“试运行”，就等它转就行。这个视频大概 2 分钟，整体逻辑就是：给定一个飞书表格链接，找到表格，把获取到的链接转为文字，拆分各个板块，然后填写到表格。

## 3）剪辑运营

接下来是剪辑运营部分的提效。

我们的短视频剪辑 SOP，其实很简单：先根据产出的素材进行剪辑拼接，然后同步补充到素材库里面去；然后对发布的作品进行导流和数据统计。

其实，我没有想着给剪辑部分增效，没有想着给他们用混剪软件之类的，因为我觉得混剪最后一定要人工把关，AI 没有什么特别高的人情味，所以就没有给他们写工作流。但剪辑伙伴也说：“松哥，这东西能用在工作里，减轻一下负担就好了。” 那好，那就开干。

### 1. 数据分析

之前的数据统计基本上都是手动的，要打开电脑，浏览器上挂着账号一，再有一个浏览器，挂着账号二。要两个浏览器是因为一个浏览器可能会把另一个账号挤掉，可能还得看一个对标账号，然后分别统计出各自的表，大家也可能会用到软件批量导出数据表，但还是得丢到飞书里面去。

现在用工作流提效之后，就两步：第一步打开工作流，给一个链接，点一下 “试运行”，就这两步。然后它会自动填到飞书多维表格里面去，甚至它自己的多维表格都会自动创建好。

这就是我的整个工作流的一个总览。给定一个飞书表格的链接之后，会判断这个表格里面有没有创建。如果它没有创建，那么就创建一个；如果创建了，那就直接提取数据，因为抖音获取的链接可能不是容易转的格式，可以用代码把这个链接转换为很容易转换的格式。

如果说它没有出现对应的数据表，那就直接创建一个数据表。创建进来之后，就跟之前一样，直接获取对应的短视频数据，然后再填入飞书表格。

然后接下来，我尝试扒了运营社小贤的抖音号数据（视频演示）。我直接复制链接，然后在工作流里面点击“试运行”，它会弹出一个窗口，在窗口里我直接把小贤哥的链接复制进去，再把飞书表格的链接复制进去，然后点“试运行”就行。大家可以看一下，它会自动创建一个数据表，包括了作品网址、标题、点赞量、分享量等等。

获取完了之后，它提示了一个“已成功创建表格，并写完数据，请反馈表格并查看”。大家可以看一下，这是 68 条记录，小贤哥的主页现在应该也是 68 条作品。

这套工作流能解决三个问题：

第一，在用市面上的软件时，获取不了全部数据的情况，比如没办法获取短视频的链接等等。

第二，没办法获取短视频对应的负向参数，比如点赞、分享、转发等。有些软件爬取数据的能力没那么强。

第三，当你把所有对标作品或者自己的作品数据扒下来之后，还得手动填进去，再做一波整合，很麻烦。

我做的就是解决这些问题，减少花时间的地方。我不需要 DeepSeek 或 AI 帮我做创作型的事情，我只需要它帮我解决那些劳动量大的点。

### 2. 发布和导流

接下来是发布和导流。之前是一个浏览器一个账号，单独发布作品，设置定时，然后换到另一个浏览器再设置定时，如果有多个账号，就得搞多个浏览器。

现在，用一个软件就可以直接定时发布，后台选中账号直接发布，支持多账号管理，不需要占用电脑太多资源。

我们是用「推将军」去实现多账号管理。这是推将军的后台，可以把所有的所有账号全部放在这，它支持抖音、小红书和视频号的多账号后台管理，我这只展示了一部分账号。

选中账号，点击发视频就可以了。

接下来是导流板块。之前在粉丝群可以用软件导流，24 小时无限循环，但听说开发者跑路了，软件没人运营，我们也无法续费，只能人工导流。

以前是每个人拿着不同的手机，连着不同的网，登录不同的账号，回复不同的后台。现在变成一个信息聚合：用一个软件，在后台可以看到所有账号的回复，也可以设置自动回复。

利用「推将军」的互动管理功能，我们可以设置智能回复规则。只要用户回复了关键词，比如“666”、“开口”、“上头”等等，就会回复引导到粉丝群。不管是评论还是私信，都可以自动回复，但需要消耗额度，大家按需跟客服沟通就好。「推将军」是抖音的，如果其他平台也可以用一些类似的工具来实现类似效果。

## 4）直播端口

讲完了团队赋能、文案运营和剪辑运营，接下来是直播端的提效。我们目前主要应用在数据复盘上。

在介绍具体的复盘提效方法路径之前，先简单介绍一下我们是怎么做直播间数据分析的。分为两种情况：流量和转私。

如果重点是拉流量，后台可以关注这四个数据：

① 曝光率

我们的曝光观看率一般在 13% 到 27% 之间。如果曝光观看率太高，可能会引起平台的“刺激流”，后台会推大量的流量。但目前我不想让直播间流量太高，一个直播间稳定在 300 到 500 的流量，可以多开几场，或者在多平台同时开播，这样更灵活。

②互动率

每到一个板块都会和大家互动两三次，因为互动率提高后带来的人均观看时长也会上升，一旦人均观看时长增加，平台会认为你的内容质量很高，就会给你更多的流量。

③加直播团人数

加团人数很重要。基本上三场做一个人数递增，第四场的流量就会很大。

④直播观看加团率

这个和你的新增加团数是相吻合的。

如果重点是把公域流量转到私域，就重点关注新增粉丝数、观看关注率、新加团人数和观看加团率。因为路径是：用户先点关注，点完关注之后送粉丝灯牌，才能进入粉丝群，通过这种方式可以提高转私效率。所以，要优化相关的设置，比如提高知识点密度，让用户更愿意为你点关注。

如果知识体系足够丰富，即使没有投放流量，也可以通过后台直接拉私域。因为投流很难跑动量，而且一旦跑动量，封号的概率就会增加，情感赛道尤其难做。

如果重点是转私域但效果不好，那就要看一下主播直播中心，检查当场画像是否偏离了目标用户画像，如果不一致，运营或者操盘手应该提醒主播，话题要贴近之前提炼的 IP 思想文档。

每次直播后我都会做一个复盘表。以前没有投流软件的时候，单个 IP 会写几十份复盘表，但现在不需要写这么多。这是我的复盘大纲，大家可以按照这个大纲自己整理，直播间每一个点都要足够细致，每一场再去做对比。

关于直播复盘提效的流程，还是用一句话总结：AI 只能替代大部分的重复性劳动，它没办法替代人。

以前我们是用手机录制直播间，因为要看到右上角的时间，下播好做数据统计，然后打开巨量百应，抓取其中的优质片段。

比如，我会选中进入人数和离开人数。如果进入 1000 人，离开 500 人，那我觉得这是一个优质的片段，可以拎出来，把视频或者文字一起拎出来给主播去复盘，整个过程非常繁琐。

如果主播播得好还好。但如果播得不好，下来就板着脸，还要跟你 “battle” 。这种时候就需要操盘手的情绪把控能力更强一点。一般会拿着复盘数据，把做得好的点复盘 3 到 5 个，做得差的点稍微复盘 1-2 个，等他每一场把优质动作复制下来就 OK 了。

后面我们用「爱复盘」这个软件来提效（目前还在内测），可以自动录制视频，包括录制时长和录制当时的自然时间，同时把所有优质的点都给你拎出来。

我会在线上查看曲线，比如 22:11 到 22:12 这段时间，比上一段人数减少了 23 人，那这一段就是劣质动作。我们就看一下这块到底是个什么情况，怎么优化。当然，如果这一段人数是增加的，那直接拎出来复制就行。这样就不需要我再手动把这段切出来拿给主播看了，会非常节省大家的时间。另外，如果违规词被抓取到了，这也都能在下面看到。

上面是连麦型直播间，如果是脚本型直播间，当你的主播或者你的 IP 告诉你：“我觉得这场直播没问题，跟上一场说得一样。” 这时候，咱先别急着跟他争论，可以用左侧 AI 对比复盘工具，它能同时复盘两场直播的内容进行对比。（这个工具是付费的，还在内测，有需要的伙伴可以找会员助理朵朵要软件客服的二维码。）

第二个是一个叫 AI DSO 的工具，它原名是 DSO 114，这个工具主要是用来做搜索词，尤其是长尾词的。大家可以直接在百度上搜索“AI DSO”就可以了，是抖查查旗下的。

（如果大家有兴趣的话，可以去找朵朵要一下之前波波在运营社分享的关于 DSO 的内容，最近我用这套打法受益不少，两天就用新号引来了保险类的客资，主要就是靠搜索流量。）

基于直播端口这一块，我想再给大家多分享一点：

直播端口主要是能解决主播和运营之间互相 “丢锅” 的问题。但毕竟 IP 本身在前端直播时，付出了大量的时间和精力，把所有的情绪价值都奉献给了直播。下来之后，肯定需要情绪上的补给。

如果 IP 对你语气不太好，也可以稍微耐心一点，毕竟大家都想把事情做好。如果初期磨合不好、沟通不够顺畅，我建议在初期就不要选择深度合作了。但如果已经深入合作了，那这就是一个双向选择的过程，要互相理解，互相包容。

## 5）私域端口

接下来跟大家讲讲 AI 在我的私域端口的提效，是我还在内测的东西，没有完全成熟，只是在我们某个项目的私域里，做了小测试，没有拓展得很宽。

首先还是想给大家分享一个思想—— “去除冗余，高内聚、低耦合”。

去除冗余就是一旦一件事你重复做了三遍以上，那这件事就一定要整合起来，去制定一套 SOP ，再搭上工作流，用工作流去执行 SOP。

高内聚就是把你们板块的内容，每一个伙伴的工作内容都规划好。比如说我写的《文案运营协作手册》，只有把每个板块的内容凝聚到每一个动作上，才能做到高内聚。

再说低耦合。比如说 A 部门的工作是 123456 板块，B 部门是 456789几个板块，那么它们重合部分就太多了。让 A 部门只负责 12345，B 只负责 56789，留一个端口进行对接就可以了，剩下的东西都内聚到各自部门中。

每个板块落实到具体动作之后，会多出来几个板块。板块之间衔接的地方不要过多地重合。比如手上四个手指头，先不算拇指，这四个手指头不要全部重合到一起，基本上重合一个就够了，只给他们一个对接的接口就行，接口就类似于智能体和扣子的 API 接口，或者扣子和 Deepseek 的接口，逻辑是一样的。

做到了去除冗余、高内聚、低耦合之后，你会发现责任会落实到每个人身上，每个人都会为他的结果负责。

私域池里我只设置了两个微信，进入私域池的用户被分流之后就对他们进行文字销售，同样的话术可能需要对不同的学员重复一到两遍才能成交。那这一块也可以做去除冗余，把重复的内容用工作流代替掉。

我们整个效果实现的思路是这样的：用户把消息发到客服微信上，客服收到信息后，通过内测软件进行信息捕获。然后在软件里面调用扣子的智能体。智能体里面会写工作流、知识库，里面就包含了我们的销售话术。

智能体会处理好问题，把结果返回到软件里面。软件拿到这个结果之后，再把它放到客服微信的聊天窗口里。然后按下回车，把这个消息发给用户。用户会觉得是在跟我们人工客服聊天，但实际上，这是通过软件调用智能体回复的消息发给客户的。

再给大家详细讲讲具体的实现思路：

我们先收到用户的问题或者反馈，信息会进入意图识别阶段：如果用户的信息是破冰的，那我们就直接走到破冰的固定话术那里，直接回复就行；如果用户是想咨询产品，那我们就走到产品介绍的环节。

在这个大模型我用的是豆包的免费微信聊天技能模型，把知识库的内容直接丢进去，让大模型获取到知识库里的技能（微信29.9成单话术），然后调用豆包的模型来实现回复，后面的内容基本都是产品介绍，也就是销售话术。

所有内容最终都会聚合到一起，在最后一个节点进行输出，输出之后返回到软件里。这个软件目前还没有在市面上公测，所以大家暂时还用不到。

我们来看一下视频效果。我现在模拟用户，比如说：“老师，29.9 课。” 这边就收到了消息，软件捕获这个消息后调用智能体，智能体处理之后直接给我回复。

接着我问：“有群吗？” 这时候软件又捕获信息，然后处理，再回复。这个视频是加了速的，大概 1 分 48 秒。实际上整个流程大概需要 12 分钟，因为中途会涉及到一些捕获消息，然后再把消息导入的时间。聊天中收款二维码获取之后可以直接转账，用起来是没有问题的。

整体流程主要看大家知识库的储备够不够。如果够的话，回复会非常详细。

因为这个软件目前还没有公测，我在内测的时候，还有一些问题没有特别精细化，比如有些知识库或者用户的问题我没有完全收集完。所以我们在私域里是在做小范围测试。

这里主要还是给大家展示一下 AI自动回复的思路和大致情况。我觉得腾讯内部应该不会允许个人微信再用这种功能，而且效率上还是有点慢，知识库这块也需要更精细化的 SOP。而且它直接涉及到变现，我担心它回复错了消息，对业务也不太好。所以就不推荐给大家用了。

如果你们确实想用，我也有看到一个私域管理软件，收费有点贵。它是按微信账号卖的，一个微信大概 700 块，五个微信一起卖。其实不太划算，而且这些东西还没有形成标准产品，大家可以再等一等。

如果能用企业微信去承接的话，还是用企微更合适。毕竟企微更官方，回复客户消息也会更让人放心。

最后总结一下我这场分享的核心主张：极致的 SOP 加上清晰的逻辑，加上 AI 的时代背景，就能打造出小而精的团队。如果所有环节都用极致 SOP 来做，那么不管是个人公司还是超级 IP 个体都没有任何问题。
