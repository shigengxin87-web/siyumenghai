## 01 同城实体门店如何选择账号类型？

首先，我理解的小红书很像微博和百度。我们行业在微博和百度上已经有很多大 IP 了，但问题是，这些大 IP 的变现基本不是以门店业务为主的。那我们做 IP 号能不能为门店引流呢？这就需要进行第一个调研——产品调研。

### 1）产品定位思考

这里可以参考一下产品运营的逻辑，也就是下面五个问题：

第一，做这个产品目标是什么？

第二，能够帮助用户解决什么问题？

第三，这个产品满足了用户什么需求？

第四，服务于怎样的群体？

第五，跟竞品比护城河/优势是什么？

这五个问题需要一开始就梳理清楚。前段时间在我们群里看到一个群友问他的业务适不适合做小红书。我问他，他的产品和竞品相比优势是什么？产品是怎样的？后面他开始思考这两个问题，然后发现当前所规划的产品路径其实是一个伪路径，所以现在又开始打磨产品。

### 2）用户画像梳理

了解清楚产品之后，第二步是去了解用户画像，这一步很重要。我做过现在公司和运动康复两个行业的小红书，两个账号都能做起来，原因是我把用户画像梳理得很清楚。不单是非常了解用户，同时还能够把我对用户的理解展现到做小红书的方方面面。

那用户画像该怎么梳理呢？主要是下面四个方法：

第一，利用行业数据报告做调研，了解整体行业的目标用户群体和用户画像。像健身、美妆等行业，可以利用小红书上的数据作为参考，但小众行业，可能难以找到小红书数据和行业报告，就可以参考其他行业。

我做运动康复，参考的就是牙医，因为医疗都是相关的。这里的数据分为两个部分，一个是行业的整体数据，另一个是小红书上面的数据。现在还可以借助 AI 进行搜索数据，但需要注意辨别信息真伪。

第二，梳理自身业务数据。我把我们的业务数据按照用户画像的三大维度——用户的基础数据、行为数据和业务数据进行了梳理。

第三，找之前成交过的用户做调研。

第四，找各大平台上的用户做调研，对他们的聊天内容进行分析。运动康复行业最早在抖音上是有大 IP 跑出来的，我会去大 IP 的账号评论区和社群观察他们在聊什么。你可以主要关注自己做的平台，比如你做小红书，就去小红书上面找自己行业做得好的账号，扒他们的评论区做一个统计。

我梳理完画像之后，做了两件事情：

第一个是找到共同点。比如运动康复行业，它的目标群体其实覆盖了所有年龄层，所以说这个产品是可以在小红书上面做的。如果你的产品年龄层比较偏大，比如 45 岁以上，那小红书就可以考虑放弃了。还有一个共同点是他们会更关注机构的资质、成功案例、口碑等方面。

第二个是找不同点。首先是对人群进行分类，比如运动损伤人群的核心特征是热爱运动，而慢性疼痛与体态问题人群的核心特征是长时间伏案工作、缺乏运动或者姿势不良导致的问题，长期没有改善。我们制定运营策略时，要根据不同的人群特征，去做分层区分。

### 3）对标账号调研

在了解产品和画像之后，下一步就是做账号定位。账号定位是我们所有对外展现的，包括首页、笔记封面等，都要符合定位逻辑，让用户一眼就能看明白。可以用一个关键词概括账号的核心内容和印象。

如果凭空想象比较抽象，可以去拆解对标账号。这个对标账号的拆解模板，可以帮助你找到共同点和不同点。共同点是我们要做的，不同点则是我们的优势。比如我们那家运动康复的店，它的康复师、老师和店长以及门店里面所有人都是非常积极阳光、温暖的，这就是我们的优势。

最后，回归到开始的问题，究竟是要做 IP 号，还是做门店账号？或者说 IP 账号能不能给我们带来同城的客资？

### 4）账号定位

可以把产品调研下来的优势、特性、用户画像、优势机会点以及自己做小红书账号的优势找一个表格全部罗列出来，找到它们中间重叠交叉的部分，看这个部分是更偏 IP 还是门店账号。

我跟很多运动康复行业的 IP 以及现在的行业 IP 操盘手聊过，他们都说做 IP 最关键的是 IP 本身要有突出的内容能力，比如一天能拍 20 条、30 条视频。

同时，内容也不用操盘手去准备，IP 本人会把内容准备好，这就是个人优势的重要性。如果说我们自己的 IP 本身做不到这一点，我建议还是慎重考虑做 IP 号。当然，其实还有另外一个方法，就是 IP 号和门店号一起跑。

像我们当时做运动康复的账号，实在梳理不出来，他们也不相信我说的要看内容能力这件事，那就两个号一起做。这两个号虽然做账号的逻辑不一样，但本质上并没有什么冲突点，账号定位的逻辑还是一样的。

### 5）精准用户从哪来

因为我是门店号先来的客资，所以后面重点做了门店号，想把门店号的客资放大。但又碰到了一个非常重要的问题——小红书上不同地区，它的用户量级其实是有上限的，一二线城市人比较多，其他城市人不多，这就意味着我的客资也受城市限制。

关键是我的笔记数据，特别是同城类笔记数据，浏览量、点赞以及涨粉，和他们想象的 IP 通过大爆款去转化是有区别的，数据没有那么好。因此我和他们产生了很大的分歧，运动康复和我现在的公司都有这种情况。我始终认为同城不需要那么多的数据，但是他们坚持觉得没有那么多数据我就做不起来，从而质疑我的能力。

那之后，我开始测试同城类账号究竟能不能通过粉丝涨粉，或者说爆款笔记能否带来客资。当时我们复盘想到的问题是，我们的精准用户是谁？我们的用户从哪来的？

这个是我根据当时调研的用户行为数据去模拟出来的精准用户路径，分为四个部分。

需求是在外部产生的，可能是他人告诉，也可能是自己发现，又或者是现实生活中遇到了这个问题。然后他会（上小红书）搜索，比如运动康复行业，他会搜运动康复，或者膝盖出了问题搜膝盖康复，我把它定义为大词。

也可能会结合一些场景词，比如打球崴脚了怎么办？搜完之后他会去看这个关键词下面的笔记。如果这时，他的关键词下面有一些笔记能够转化他，那他就会直接留资解决。但如果他比较谨慎，当前没有那么容易被转化，那他这次搜索完之后，后面他的笔记推荐也一定会出现这种相关的笔记，那他可能还是会去刷，或者去看其他的东西。

接下来我要说一个我们发现的跟抖音一样反常识的点。抖音的逻辑打法是先通过泛流量把人圈过来，然后再一层一层地逐层转化到最后成交。但是小红书，包括小红书官方推荐的其实是一个反漏斗模型，就是希望我们先触达到核心人群，再到兴趣人群，然后再到泛人群，一层层往下渗透。

根据我们前面的链路，会发现这三层人群是可以通过不同的页面触达到的。后面我也针对爆款笔记、推荐页以及粉丝转化做过测试，最终发现还是搜索页来的用户最精准，这也是我客单价高的原因。

而且还有一个原因是，我们的行业比较特殊。用户对我们行业的认知不统一，甚至有些人有些有色眼镜。最关键的是，他们不是刚需，更多是自我提升。而自我提升这件事本来就看个人认知，在这种情况下，你很难去教化他们。

所以我会只选择意向度最高、最精准的那群人先去做，也就是小红书建议的核心人群，并且通过搜索页来做。搜索页的核心价值，在 59 期迪安已经分享过了，讲得很好，有兴趣的可以去看一下。（59期分享：[《【小红书搜索】2025小红书搜索红海vs蓝海赛道玩法策略](https://1iak4.hk.xet.citv.cn/s/VdlpR)）

### 6）如何让我的用户看到我

在确定以搜索为主要打法之后，我还需要考虑，如何让更多我想要的用户看到我，目前主要有5个路径。

第一，最重要的是搜索关键词卡位。

第二，发笔记时带上定位。在小红书初始的笔记推荐规则里，发布笔记带上定位，会优先把这篇笔记推到定位的附近，比如 3 公里、5 公里、7 公里这样逐层推，所以这个功能对于我们同城门店来说非常重要。

第三，在主页打开店铺。我发现从店铺来的客资和我从搜索页来的客资还没有重合，可能是当前一些用户已经被小红书教化了，习惯去店铺里找。

第四，在主页打开线下门店，这是之前小红书测试的一个同城功能，只在部分地区开放。线下门店点进去之后直接是门店的地址。我们每个月会有十多个已知的用户，通过定位或者线下门店直接到门店。

第五，小红书新出的功能，在搜索关键词下面会有标签，还有问一问。

说到这里，有一个新的问题产生了，（其他笔记的）评论区能不能捞来有效的客资？我的答案是，不能。

我们测试过，自己发了一篇笔记，求推荐运动康复相关的机构，一个小时 200 多条评论，还有几十条私信，全部是自荐。试想一下，如果我们是用户，在这种情况下怎么挑？所以总结一下，要注意以下几点：

第一，如果你在评论区展现的东西有比较大的特色亮点，能让用户看到，那你其实能做。但如果说你没有的话，就别做了。

第二，门店号我不建议去评论区捞客。因为门店号带着蓝V，你跑到别人评论区下面，会让人觉得你们生意很差，反而会质疑你的专业性。

第三，素人号需要谨慎考虑，容易被举报。

第四，击穿信任成本比较高。从评论区到私信再到微信，我可能在一个客资身上花的时间至少半小时起步。这个时间不如好好写一篇笔记，可能同一时间触达到的就是几十、几百甚至几千的用户。

所以，我个人认为获得曝光量的入口是不包括评论区的。在这些入口当中，最重要的是搜索关键词。

## 02 如何布局搜索页精准获客？

那我们关键词怎么找呢？这里要注意，现在小红书市场上很多课程有提到用一些工具，比如聚光后台、新红去拉关键词。但聚光、新红后面的关键词热度数据是基于整个小红书大盘的，对同城不完全适用，这就需要自己去扒关键词。

### 1）同城关键词如何确认？

第一，参考对标竞品笔记。竞品笔记下面所有的关键词，都需要了解。还可以用新红后台把关键词输进去，就会有很多关联的关键词，然后再去看每个关键词下面的笔记内容。

第二，评论区提炼高频关键词。可以使用 AI 工具整理竞品或热门笔记评论区的评论，并提炼关键词。

第三，借助 AI 拆分业务对应关键词。比如我问 DeepSeek：“运动损伤容易出现在哪些部位？”它会回答我韧带损伤、半月板撕裂、髌骨脱位，这些都可以直接用到小红书运营上。

### 2）如何让用户看到我？

确定关键词之后，下面有个小互动。这 12 篇笔记，你第一眼看到的是哪一篇？

首先是第二行第一个，因为它背景很干净，关键词还高亮突出，非常抓人眼球。还有框选的另外两个，因为它们的背景很花。

在封面我会关注重点关键词，所以有一段时间我经常用白色底的，上面字非常简单明了。但当我发现很多竞品在抄我这种风格之后，我会换成这种花的。我们要保证自己的封面风格跟这个关键词下面展现的笔记形成一定的差异，这样就能抓住人眼球。

其次是要稍微注意一下封面的颜色选取。比如我们运动康复的所有用户都是很焦虑的，那就不要再用红色了，用了红色他看着更焦虑。

然后是要注意视觉重点文字的展现。还可以适当地加入这个城市特有的风格。因为不同的人，没有一个共通的统一的审美风格。在此基础上，还可以去测试封面的字体，然后找到一个可能比较符合我们城市用户的一个审美。

说完封面之后，我们再说一下标题。假设你肠痉挛痛得受不了，你会点哪些笔记？

首先第二行第二个，宝宝肠胃弱和我没关系，我肯定就不会看了。然后第二行第一个字太多，一眼看过去没有视觉焦点。剩下的说实话我都会看。这里其实会牵扯到一个问题，就是你的标题（和封面）一定要简单直白告诉用户你这篇笔记是干嘛的。

其次是，我取的标题并没有太高的文字水平，我就是把关键词堆砌起来，反而有些时候能打动更多有同样问题的用户。

那标题的关键词怎么来？我建议考虑这三个点，痛点、痒点、爽点。燃点和爆点可以慎重考虑下，因为燃点和爆点是更适合那种爆款笔记，但搜索笔记前三个很重要。

## 03 如何获取用户信任？

### 1）我的用户从哪里来

在初期按照上述方法操作后，我在第一个月就取得了不错的业绩。然而，第二个月遭遇了竞品的干扰，导致业绩受到影响。小红书的机制使得竞品笔记在搜索关键词下依然会展示，无法阻止其曝光。于是，我开始思考如何通过小红书建立用户的深度信任，即使用户联系了竞品，最终也能选择我们的门店来成交。因此，关键在于如何通过小红书的内容击穿用户的信任，让他们更倾向于选择我们。

如果用户有需求，要找一家店解决问题，那其实在前面这两个环节——搜笔记、看笔记的过程，就是用户在做决策的过程。

我理解（运营）就是要去干预用户的决策点。我大致分了一下用户的 9 个决策点。我们可以从这个决策点当中去找一些自己比较擅长的，或者说自己产品有的其他竞品没有的优势，然后去入手去做。

#### 1. 从众

首先，我选择的切入点是“从众心理”，这本质上是一种背书效应。专业人士、有一定信任基础的人，或者被广泛认可的人事物都可以为品牌背书。对于运动康复业务来说，背书尤为重要。

当时，一位拳王在比赛前到我们门店进行了深度的肌肉放松和保养。我将这一事件发布到小红书上，虽然那个账号现在已经不存在了（配图是当时的朋友圈）。这样的内容向其他用户传递了一个明确的信号：连专业的运动员都选择我们，这说明我们在运动康复领域具备专业能力，能够为追求运动表现的用户提供高质量的服务。

还有用户反馈的好评，也算从众的一种。

然后在这里还要注意一件事情，就是要根据不同的城市文化以及我们的行业去选择我们做哪些事情。比如说像北京比较重资质，那我们可以多展现一些资质的东西。像华东地区、广州地区更重实际经验，那我会在笔记当中更多地去展现经验部分的内容。

#### 2. 种草

第二个决策点是种草，这是小红书非常重要的一件事情。种草的形式有很多，小红书甚至有一本书叫《种草》。我们可以根据自己的产品以及我们的优势多写几个类型进行测试。比如我很擅长写攻略，所以当时发了很多测评笔记，你可以根据自己的擅长点去选。

#### 3. 认同

第三点是我比较擅长的，就是去做一些观点输出让用户认同。像我之前做的运动康复账号，我写了四篇，输出自己的观点和一些踩坑经验，在当时给我吸来了很多客资。

总结来说，我们还是要结合自己的产品优势，根据不同城市的文化方向去选择我们自己擅长的角色点，其实并没有很多标准答案，因为决策点有很多。

### 2）用户决策路径

定好决策点之后，要思考我们的决策点能用在哪里？首先第一个是封面，第二个是标题，第三个是评论区，第四个是内容，第五个是账号的首页，第六个是账号的合集功能。

### 3）评论区引导

比如你搜索之后，看到一篇笔记，你觉得感兴趣能解决问题，你点进去了。我自己个人习惯是先看评论区，因为我觉得我的时间比较短，可能没有时间看完一篇笔记。

这里我放了三个评论区，你认为哪个评论区会比较容易吸引客资？

我觉得中间的评论最简单直接，它能激发我的从众心理。看到别人在评论区进行咨询，我就会觉得“既然别人都觉得好，那我也可能会去尝试”。而左边的评论提到“这样练还是很疼”，这说明用户的需求并没有得到满足。所以，虽然左边的引导方式本身没有错，但关键问题是它的留资引导不够直接。如果用户按照这个方法练习后不疼了，可能就不会留下联系方式了。

所以说，评论区的关键在于前两条评论。当你打开并点开一篇笔记时，第一条和第二条评论能够为整个评论区的氛围和走向提供重要的引导。这与微博的评论逻辑有些类似。

### 4）内容选题

内容的第一部分是选题，我会把我们门店账号写的内容类型分为三类，第一个是日常类的；第二个是营销类的，营销类是指能够直接戳到用户痛点的内容；第三个是爆款笔记。

虽然我们做的是同城业务，主要依赖搜索位，爆款笔记在推荐页的作用相对有限，但爆款笔记依然重要。因为小红书的搜索笔记卡位会综合考虑笔记权重和账号权重。账号权重与抖音不同，它不看粉丝数量，而是看近期笔记的数据表现。经过测试，我认为流量笔记对于提升账号权重和笔记权重非常关键，因此爆款笔记仍然是不可或缺的。

关于内容选题的排期和发布时间，大家可以结合自身行业特点进行安排。以我们行业为例，周一的数据表现相对较弱，所以我选择在周一发布日常类内容。

选题建议结合本地城市的文化或热点话题。比如我之前运营广州号时，就大量发布与港剧相关的内容。总之，选题要贴近本地用户的兴趣和生活，这样才能更好地吸引他们的关注。

这里是一个案例，大家可以看到，这种很明显的绿色、黄色字都可以算是转化类，就是干预用户决策的笔记。然后这种看起来很中式的，就属于流量笔记。

还有内容的部分要注意两点，第一个是用户他其实想要的是解药，而不是广告。第二个是用户不为你的内容打分，只为他的痛点买单。我们写内容时，注意不要陷入自嗨的陷阱。

### 5）首页&合集

在内容创作之后，很多人容易忽略账号首页和合集的设置。合集对于精准用户非常重要。用户在看了某篇笔记后，可能心动但还不能下定决心，或许是出于自我防御心理，或许是还有其他问题需要解决。此时，如果他们进入首页并看到合集，很可能会点进去进一步浏览。

比如我的合集，不仅包含科普类笔记，还有老师介绍、日常实用内容以及案例示范等。如果用户能够完整地浏览这些过往笔记，就会增强对我们的信任度，进而提升他们的决策意愿，因为看到一篇和看到多篇笔记的效果是截然不同的。

在运营门店账号时，首页的设置非常重要。很多门店账号的封面虽然设计得不错，但缺乏场景感，会使用书本或风景图作为封面，用户很难从中感受到这是一个门店账号。所以，笔记封面一定要体现门店的场景感。

比如，我习惯每周发布 2 到 4 篇笔记，其中 1 到 2 篇会用老师训练场景或门店环境的图片作为封面。这样可以增强用户对门店的感知，让他们更直观地感受到这是一个专业的门店账号，提升用户对我们的信任感和参与度。

## 04 用ABtest优化运营细节

那我们该怎么去验证方法的有效性呢？我这里推荐 AB test，笔记的标题、封面、字体、发布周期/时间都可以通过 AB test 进行验证。

就好比我们发笔记，设置了6个变量进行测试。每次测试时，我们只改变其中一个变量。当我们不确定哪个标题更好时，可以准备两篇相同内容的笔记，分别使用不同的标题。然后在固定的时间点，用统一的关键词发布这两篇笔记。

但需要注意的是，由于小红书对抄袭的检查很严格，我们无法在两个账号上同时发布相同的笔记。所以我们只能在同一个账号上进行测试。例如，A测试在本周四晚上8点发布，B测试则在下周四晚上8点发布，确保发布周期和发布时间一致。通过这种方式，我们就可以准确地评估每个变量对效果的影响，从而优化运营策略。

建议大家可以好好研究和实操一下 AB test，但是要注意一点，笔记发了之后，数据效果不好的那一篇记得及时删除，不要囤到一起大批量删除。也不要留着，不然可能会被小红书判定为是抄袭账号限流。

## 05 一些互动&思考

下面聊聊关于几个问题的我的个人思考。

1）对于门店业务，IP 号究竟适不适合？

第一，我觉得门店不适合做 IP 号。因为我们门店的业务受到地域的局限影响很大。但是 IP 号最重要的是爆款笔记和涨粉，这两个东西逻辑是相悖的，到最后 IP 号很有可能是叫好不叫座，我们公司的 IP 号就是这样，数据好但转化不了。

第二，IP 号要看的是他本身的内容生产能力，以及他自己的理解，我们作为操盘手其实只能锦上添花。

第三，IP 号有一个风险，但凡 IP 号不是老板本人，员工做起来后直接离职会竹篮打水一场空，所有的运营都无效了。

2）团队管理，非行业的伙伴怎么快速上手？

第一，第一个星期我不会让他写笔记，我会要求他大量地去刷关键词和关键词下面相关的笔记，并且用前面讲到的方法扒评论区了解行业情况，每天至少 10 个小时以上。

第二，第二周到第三周，对评论区的问题进行总结，了解用户痛点和聊天内容。

第三，做竞品调研，对竞品的笔记进行拆解。

第四，第四周，结合实际业务对用户的需求进行调研和提炼，了解行业基础知识。

每周我会花一个小时为他做辅导总结，发现问题就及时指出。每天还会花15分钟和他一起总结当天的工作，主要是他讲述自己当天的成果、收获和灵感。需要注意的是，用户需求调研和专业知识，会随着我们了解的深入一直迭代，是贯穿职业生涯的一件事情。

3）如何应对同行的竞争

第一，我们先做好自己，要遵守小红书的规则，不给同行举报我们或者找到我们漏洞的机会。

第二，善用举报功能，多监测同行在干什么，竞品在干什么，一旦发现不对就直接举报。还要找到自己在小红书运营上的优势，大家没有必要去补齐自己的短板，而是要深入地、极致地去挖自己的这个优势，然后把这个优势放大，形成护城河，那其实也一定能在小红书上趟出一条路。

这里还是建议大家在合法合规的前提下，实打实地用实力进行竞争，不要抄袭，不要擦边。我坚决反对通过虚假营销、抄袭、截流等灰色手段进行引流获客。

4）我对小红书的理解

第一点是在小红书强制投放之后，很多人会问小红书还能不能做？我都会回他们一句话：小红书遍地是黄金。现在所有的生意都值得在小红书上面做一遍。

第二点和我自己经历、认知有关系，我其实从来没有把小红书的运营跟内容运营画上等号，因为我觉得小红书的运营除了内容以外，你还要做很多事情，总的来说是对平台、业务、用户和自己的理解的一个叠加。你只有去多方面地去了解了之后，然后才有可能去把这个事情做好。

第三点是我们公司刚开始做小红书的时候，自己验证出来的一个道理。我们所发布的每一篇小红书笔记，本质上都是将我们自己的观点、认知和一些东西进行投射的过程。所以只要你发的内容是你自己的，只要你不违规，小红书就会给你推流，就一定会有看的人，一定会吸引到那些跟你人格底层比较相似，或者差异很大但缺少这一部分的人。区别只在于你投射的内容是多还是少，以及你用技巧能不能让更多人看到，所以，放弃流量焦虑。

如果你之前做抖音就会发现，抖音可能直接暴力起号，一个星期这个号就过完粉丝了。小红书不会这样，特别是这几个月，小红书涨粉比之前更难了。它一定是要一个时间积累的过程。所以，我们要静下心来，认真、坚持地做账号，一定会有收获的那一天。

第四点是再次呼吁大家遵守平台规则，不要薅平台羊毛。平台欢迎的是那些能和平台形成互惠互利关系的人。我之前亲眼见到一个竞品，去年一整年都在利用小红书的漏洞，到了年底，小红书和他算总账，品牌旗下所有账号全部被封掉，相当于直接删档重来。

第五点是尊重用户。用户是不可被引导或被忽悠的，而且小红书上的用户认知相对来说都不低。你有时候可能引导他、忽悠他，他当时没反应过来，情绪上头，但后面一定会反应过来。

最后，互联网唯一不变的就是变化。我们要始终顺应市场，才有可能立于不败之地。小红书现在规则老是变，我们不能不变，否则就会被淘汰，我们也要跟着它变。今天的分享就到这里，谢谢大家。

# 【Q&A】

Q：请问你们做素人号吗？

A：素人号我们很想做，但目前还没跑通，还在摸索阶段。不过，我们肯定不会去做截流的方式。我们还是会坚持种草、测评、探店这些形式，通过这些内容去抢占关键词的位置。

Q：你们的素材来源有哪些？

A：我们行业的素材来源其实很有挑战，用户评价是个很好的素材来源，但我们行业不能发用户评价，所以我们的素材主要靠自己去拍摄。我们会拍摄一些照片，然后制作成图片或视频内容。

Q：搜索笔记和内容种草笔记分别适合什么行业？

A：我理解的是，所有遇到问题后可以在小红书上寻找解决方法的行业，都适合做搜索笔记和内容种草。我其实把搜索笔记理解为是内容种草的一种笔记形式。

Q：领导要求用蓝V聚光号每天截流怎么办？

A：如果领导要求截流，可能会让你发图给他。但我觉得他未必能检查到，因为小红书是千人千面的，他能看到的只是你截的图。你可以自己多搞几个号，发一个，然后去评论。其实一开始，我们老板也要求我们每天做这件事，但我当时直接拒绝了，因为我觉得这没有意义，反而会让用户觉得我们生意很差。后来，有些同事尝试做了三个月，发现两个问题：一是私信沟通成本太高；二是即使留了联系方式，也很难成交。

如果没办法拒绝，可以多弄几个号。小红书的普通账号改名很方便，一周可以改一次。你可以弄 7 个号，第二周换一个名字，这样就能避开检查了。

Q：如何从评论区提炼关键词？

A：关键词的提取可以利用工具来完成。我用的是“新红”，它会在页面底部显示关键词，不是显示评论的部分。当时我用了个笨办法，就是把所有评论复制粘贴到一张表格里，整理好之后，再把这张表格交给一个叫“通译千问”的 AI 工具，让它帮我分析提炼在所有评论中高频出现的关键词，比如 10 个、50 个。最早之前，我都是手动统计的，现在有了 AI，确实很方便，能帮我们节省很多时间。至于“新红”这个功能，我记得应该是不需要会员的，你可以直接复制粘贴下来。

Q：账号点赞收藏多但没有评论，需要自己做评论区运营吗？做的话多少条评论合适？

A：在账号前期，可能需要这么做，但要注意方式方法，别被小红书识别到你在刷数据。在账号刚起步的时候，可以让朋友帮忙在评论区互动一下。不过，等账号稳定之后，就没必要再刷了。我现在已经不刷评论区了，因为账号标签已经建立好了。一条评论就足够了，不需要太多。你朋友的账号也不能频繁出现在你的评论区，否则会被识别出来。现在小红书要求实名认证，所以刷评论的意义不大，一条引导性的评论就足够了，就像微博一样。

Q：蓝V号发布内容比较单一，曝光量不过百但没有违规，对后续流量会有影响吗？

A：如果蓝 V 号之前发布的内容比较单一，且曝光量不过百，那首先要检查账号是否有违规行为。如果有违规，肯定会影响流量，需要先处理违规问题。如果没有违规，可以用“新红”工具看一下小红书给你的账号打的标签，看这些标签是否和你的行业匹配。

如果标签匹配，那问题可能出在内容上，需要调整内容策略。调整之后，对后续流量不会有影响，只是要把当前的内容质量提上去，可能比较难。

如果你的账号没有这些问题，那反而是健康的。因为小红书的流量分配机制是这样的：单篇笔记的流量主要看这篇笔记本身的质量和账号权重，不会因为你之前有一篇笔记爆了，就给后面发布的笔记也推很多流量。这和抖音的规则不一样。抖音之前有个规则，如果有一篇视频爆了，会带动前后发布的视频流量一起提升。但小红书是一篇一篇单独算的，这篇笔记的流量就是这篇的。如果你的曝光量破 10 但不破百，那大概率是内容问题。另外，也可以检查一下内容是否有敏感词，如果有敏感词，通常曝光量不会超过 10。

Q：账号没有违规，但24小时内流量只有几十或者不破百是正常的吗？

A：当时我刚开始做门店账号的时候，流量也很低。而且我的同事和领导还陷在流量逻辑里，所以我的挫败感更重，压力也更大。但我坚持认为我的方向从理论上来说是可行的。所以我一直坚持到现在，虽然流量和涨粉都不太理想，但至少变现还不错。毕竟，变现才是最重要的。

还有一点，我之前说过不要有流量焦虑。说实话，小红书的流量本身就比较低，你可以理解为抖音的流量除以 10 就是小红书的流量。所以，几百、几十的浏览量也不算少。

而且我之前还碰到过这种情况：我发了一篇笔记，一开始没什么流量，可能就二三十，甚至只有几十的流量。但过了半个月，不知道小红书是怎么运作的，那篇笔记突然就火了。不过，它不像抖音那样瞬间爆火，而是每天几十个收藏、几十个点赞这样慢慢增加，持续了两三个月，最后点赞和收藏都过千了。

Q：账号发本地泛内容会影响标签吗？

A：对于本地内容，如果你直接发港剧相关内容，可能会对账号标签产生影响。内容需要和自己做的业务结合一下。比如，我记得港剧里经常出现的场景，像大晚上煮泡面之类的。如果你是卖碗的，或者和煮泡面相关的产品，就可以结合港剧里的这些元素来创作内容。这样既符合用户兴趣，又能精准地推广自己的业务。

Q：地域精准但人群不精准怎么办？

A：如果人群不够精准，可以先用画像分析工具分析一下，看看目前的受众标签，然后再调整策略。前期可以通过一些工具和方法来优化，但最终还是要根据实际效果来微调。

Q：流量增大后地域和人群不精准，如何优化本地客资获取？

A：如果地域不精准，可以通过多研究竞品的关键词来解决。如果人群不精准，当笔记流量变大时，就要回到选题排期的规划上。在发布内容之前，需要有一个明确的选题排期，清楚地知道哪天发布转化类内容，哪天发布流量类内容。

对于地域和人群的精准性，尤其是转化类内容，一定要明确目标，触达本地的特定人群。而对于流量类笔记，主要目的是吸引流量，不用担心它不爆。因为单篇笔记的数据不会影响其他笔记的表现，最多可能对账号权重和标签有一些影响。但标签是可以自己打上的，只要确保笔记内容的标签与行业相关，且不乱打标签即可。

回到营销漏斗的概念，其实要看你的目的是什么。如果是为了涨粉，地域肯定不会太精准。因为小红书总共才3亿用户，如果分摊到全国各个城市，每个城市的用户数量就很少了。所以，如果单独针对某个城市的粉丝，增长空间是有限的。

如果目标是全国范围，那粉丝画像和地区分布就会根据每个城市的人群占比来分布。但如果目标是本地变现，那就需要做好关键词优化，确保内容在搜索页有好的表现。因为粉丝本身与变现关系不大，能通过粉丝直接变现的情况很少。粉丝主要是用来积累客户资源的，但粉丝和客户资源之间的转化其实比较困难，这和抖音的逻辑有点不一样。在小红书上，更多的变现机会还是来自搜索页的流量。

Q：搜索流量很少怎么办？

A：如果搜索流量很少，可以参考一下第 59 期迪安的分享。你也可以梳理一下自己的笔记，看看收录的占比情况。按理说，如果推荐流量比较高，说明你的账号权重是没有问题的。如果账号权重没有问题，那就可以多发一些同城相关的笔记，尤其是那些能被同城卡搜索词收录的笔记。然后观察一下这些笔记是否被收录，是否能卡住搜索位置。之后就交给时间，搜索流量会一点一点增加的。

Q：你认为在小红书上视频流量和图文流量谁更好？

A：目前小红书平台整体在主推视频内容，但具体是做视频还是图文，还是要根据你的行业特点来决定。比如，像运动康复这类行业，更适合用图片和视频来展示，那我就会重点做视频。而像我之前提到的膏药这类产品，更适合图文形式，那就发图文。从实际效果来看，只要笔记写得好，能切中用户的痛点，视频和图文并没有太大区别。关键还是要看你的行业适合哪种形式，以及哪种形式更能满足用户的需求。
