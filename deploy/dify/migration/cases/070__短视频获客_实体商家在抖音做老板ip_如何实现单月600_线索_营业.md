### 一、自我介绍&业务介绍

首先简单自我介绍一下，我是一个拥有全网 10 万粉丝的家装公司老板 IP。我从 2023 年开始做这件事，到现在已经两年多，快三年了。

我们从 2023 年开始转型，从建材供应链转向整装装修公司。在三年的时间里，我们从零做到现在，今年预计能做到 5000 万规模。在做装修公司之前，我们主要依靠传统渠道，比如跟小区合作做团装项目。后来我开始亲自带团队深耕新媒体领域，尤其是抖音，从 0 到 1 打造了一个变现能力比较强的账号。

今天我主要分享三个部分：第一，我为什么要做家装公司老板 IP；第二，我的账号是如何取得这些成绩的，我会完整拆解整个流程；第三，作为老板 IP，我想分享给各位操盘手和老板们我的心路历程，我觉得心态非常关键。

先讲第一点，我为什么要做老板 IP。在开始之前，因为我发现有些朋友可能不太了解家装行业，我先简单介绍一下我们的业务。我们是一家区域性家装公司，服务涵盖设计、施工、辅材、主材到全屋定制。由于交付周期长、环节多，我们只做本地落地服务。

我们的定位是中偏高消费群体，面向 25 到 50 岁、有一定消费认知、愿意为设计买单的客户。现在很多消费者不愿意付设计费，但我们坚持收取合理的设计费，尊重设计师的劳动。和独立设计师相比，我们的设计费更亲民，一般在每平米 50 到 200 元之间，根据客户需求、面积和风格来定。设计师也会依据自身能力定价。比如 150 平的房子，设计费大概在 1-1.5 万左右，是普通家庭能够接受的。

这部分消费群体在硬装部分，比如瓷砖、卫浴、门等主材上，倾向于选择大品牌，比如 TATA、蒙娜丽莎、东鹏、马可波罗、诺贝尔等。我们提供有质价比的装修，价格不像施工队或小型夫妻店那么低，但品质更有保障。

家装行业的痛点在于产品复杂、交付链路长。从设计到完工，涉及几百个工艺细节，交付周期可能长达几个月甚至一两年。装修不是标准品，客情维护难度大，业主往往认为公司应该零失误，但实际过程中方案可能会有调整。这也是行业普遍面临的挑战。

我们的客源 80% 来自抖音，10%-20% 来自老客户转介绍，其余来自小红书和视频号。投流方面，我一般会拿出营业额的 3% 进行投放，比如这个月想做 100 万，我就投 3 万。

### 二、为什么我要做家装公司老板IP

接下来讲为什么我要做家装公司老板 IP。首先，家装行业已经进入用户主权和数字化时代，客户都在刷抖音、看小红书，找避坑知识，所以我们必须去他们所在的地方做营销。

其次，家装是一个高客单、低复购的行业，老板做 IP 已经不是可选项，而是必选项。现在很多大型装修公司老板也开始走到一线，用个人代表公司发声。老板的认知和格局反映了企业的文化，而文化是可以传承的。很多业主跟我说，他们看我天天发视频、跑工地、参与巡检，相信我和我的团队是认真做事的。

装修是人生大事，一套房子投入可能从十几万到大几十万，因此信任极其重要。老板 IP 能有效破解行业信任难题，把我们公司的信誉和我个人人格绑定在一起。

第二点是打造差异化。现在产品同质化严重，各家都能说自家能落地、有大品牌、设计好。差异点要从老板身上找，从卖材料转向卖人。通过视频和直播，我可以展示创业故事、专业见解和个性，让潜在客户提前建立信任。

第三是降低获客成本。老板做 IP 是从买流量转向造流量，吸引认同你的粉丝，大幅降低获客成本，比之前打电话、谈小区合作更有效。同时，转化率和客单价也能提升。比如我们会在客户积累到一定量后办粉丝见面会，或做私域直播，集中转化，提高效率。

第四，也是很重要的一点，做老板 IP 后，我每天后台收到很多合作咨询，甚至很多人想加入我们。很多优秀的设计师看了我的视频，认同我们的企业文化和价值观，愿意加入。经常有人说“冰姐，我终于可以不昧良心做装修了”。所以，做 IP 不仅能对外吸引客户，还能对内吸引人才，这是我觉得特别有价值的地方。

打造老板 IP 后，我们的获客链路发生了很大变化。以前是客户先找到公司，经过反复试探、建立信任，最后才成交，沟通成本和服务成本都很高。现在有了 IP，客户是先认同老板、带着信任来咨询的，再由我们的团队提供服务，客户认可团队后，便能高效成交。家装行业链路长、服务周期久，必须先打消客户的信任顾虑。

我认为，打造家装公司老板 IP 不是在搞副业或出风头，而是用个人魅力和价值观，展现你如何做企业、如何把理念融入公司和团队，信任才是最稀缺的资产。

### 三、老板IP获客全流程拆解

接下来，我重点分享账号的全流程拆解。

#### 1. 账号定位

做账号首先要有清晰的定位，我的人设就是老板 IP。家装行业其实有多种 IP 类型，比如设计师 IP、施工端工长 IP 或厂长 IP。如果公司规模较大，应该多维度布局人设。我们现在就在打造施工端的工长 IP，下一步计划做设计师 IP，让用户不仅能了解老板，还能全面看到公司的设计、施工等实力。我的抖音简介写明了我是谁、承接什么项目、公司优势和服务范围。

人群定位和产品定位也非常关键。我们每天复盘，就是要看来的客户是否匹配。如果总来的是局改客户，而我目标是毛坯或别墅业主，那说明内容或话术出了偏差，需要调整。

做内容前，要先总结目标业主的痛点：比如，有一定认知的业主，最怕增项，不再相信“69800 全包”这类广告，他们关心报价包含什么、有无隐藏费用，害怕被坑或公司跑路；也担心材料以次充好，比如电线、瓷砖不是承诺的品质；同时，他们付了设计费，就希望设计能落地还原，保证装修质量，明确付款方式和工期。尤其是中高层管理者，可能没太多时间跟进。这些痛点，正是我们内容的核心，比如讲清楚如何实现零增项。

产品定位要和人群定位匹配，否则会造成客户浪费。来 100 个客户，一个都消化不掉，就说明内容或产品定位有问题。我们把自己定义为设计型整装公司，整合供应链，在个性化设计和预算间找到平衡，提供有质价比的服务。这个定位也是经过多次数据调整才确定的。

在做老板 IP 时，找到差异点很重要。在产品同质化严重的市场中，我首先从自身优势出发：有 13 年大品牌厂家资源，能带客户到源头展厅选品，在价格和选择范围上建立优势。整装公司常被认为主材选择有限，但我们打破了这一点。

其次，我以国家高级色彩搭配师的身份，强调老板亲自把关落地效果，这也是一个有效的营销策略。在做视频时，我会刻意放大这些差异点。

#### 2. 起号阶段：流量型视频为主

起号阶段，我的目标是做流量型视频，告诉平台我来做什么，同时拉升账号权重、打上标签。

最初我没投付费，全靠自然流做起。现在有预算的话，可以直接付费起号。当时我成本压得很低，以口播形式为主，在工地或实景案例中拍摄。内容风格需要不断尝试，我试过在展厅、戴安全帽等多种形式，有的视频获得了百万播放。

寻找爆款视频的方法，主要是用热点宝找低粉爆款视频对标，但不是照抄，要有自己的风格。尝试中我发现，不同形式都可能出爆款。比如最近九月发的扎丸子头、在衣帽间拍的视频，也有几十万播放，成本低、拍摄快。现在用户更喜欢有“活人感”的内容，真实、放松的场景更吸引人。

家装是小众赛道，只有有需求的人才会关注，所以呈现上要让 IP 显得自然、舒服。起号阶段我花了一个月左右做这类流量视频，后期减少了比重，转向更多人设型和营销型内容。

#### 3. 稳定阶段：多维度呈现内容

我从做泛流量转向精准本地流量，总结下来，一个高变现账号一定要多维度呈现。流量视频能带来播放，但可能无法变现，因为客户找你不只因为流量，更基于信任。他们需要看到你的专业内容、落地案例和实现细节，所以后期我调整了账号内容维度。

现在流量型视频我拍得很少了，更多的是营销类视频，主要围绕产品卖点、活动等内容，让用户了解我们的服务和选择我们的理由。后面我会具体讲这些营销视频、人设视频和案例视频是怎么做的。

人设类视频主要传递 IP 的观点、价值观、人生观，以及我们经营公司的理念、装修理念和做事靠不靠谱，都要通过这类内容展现出来。

还有案例视频，呈现装修过程中的细节，比如水电、木工、瓦工、油工等环节的工艺，以及最终完工的效果。

目前我账号的内容比例是动态调整的，根据账号和变现的成熟度不断优化，我自己的调整也不下几十次了，经常参考别人、跨界学习。

现在我的人设视频占比最多，营销型视频只占 10% 左右，因为它们太像硬广，放多了会影响人设。人设加营销的内容目前测试下来留资效果很好，案例型视频占 20%，流量型内容已经非常少，只有一两条，后期基本不再主拍这类了。

人设型视频主要包括几个方面：一是创业历程，比如我作为普通女孩 35 岁创业的故事，有一条 8 分钟的视频效果很好，一直用来置顶。二是作为创始人兼老板的日常记录，比如谈单、工地巡检、开工、帮业主解决问题等场景，都是真实和业主沟通的内容，拍完再剪辑出来。

很多老板刚开始做 IP 时不知道如何输出，往往是因为没抓住业主痛点。这就需要我们基于人群定位，总结出业主真正关心的问题。我和业主沟通时，大多是在解决他们的顾虑，比如设计如何落地、有没有增项、水电木工怎么做等等。把这些沟通中有逻辑、有共鸣的内容拍下来，剪辑成视频，既能解决当前业主问题，也能回应潜在客户的疑虑。

这样做既真实又能突出我们的价值观和服务细节。比如我视频中有工地巡检、和业主面对面聊天的场景，都是签单的真实记录。

最后还有一种人设观点类视频，比如我讲“预算不足不必死抠细节”，其实也是在传递我们的定位，筛选目标客户。你想吸引什么样的客户，视频内容就要对应呈现。如果你的产品主打中低端，比如几万块全包，内容就要往这个方向走；如果想做中高端，那内容、拍摄和剪辑都要更显质感和高级。

营销视频也必不可少。我现在主要做这几类：库存营销、活动营销、案例营销、痛点营销和人设营销。效果比较好的脚本，比如“选择冰姐装修的六大理由”，就是我总结的能解决业主六大痛点和提供的六大价值。我建议每位老板都总结自己公司的优势，以及能为业主解决什么问题，这本身就是很好的营销素材。

其他还有活动类的“冰姐样板间”，案例类的实景落地视频（比如 198 方跃层意式极简案例，含效果和价格），以及人设类的“一个很较真的装修公司老板”，这些视频获客效果都很好。

案例部分我们通常通过多个视频呈现：一是粉丝开工现场，我会讲解这个案例如何落地、有哪些痛点、怎么解决；二是落地案例的细节展示，包括完工和未完工的场景。只有多维度展示，用户才能全面了解我们，判断是否要留资、靠不靠谱，看到我们的案例、工艺和完整服务流程，账号内容才真正立体。

#### 4. 持续生产好内容：搭建素材库

其实我做到现在会发现，我们能够持续稳定地合作，核心在于拥有好的内容。而好的内容呈现，首先必须搭建一个完善的素材库。

就像我刚开始做老板 IP 时，并没有那么多素材积累。我们需要把前面讲到的内容，比如你在工地上的日常、工作点滴、甚至创业历程，包括从你小时候、父母那一辈的故事，全部收集起来。

前期我会先列一个大纲，然后在做的过程中，逐步去丰富这些素材。我们所有的素材收集好后，会先上传到百度网盘，然后由剪辑和运营同事进行分类，比如分成：人设类、营销类、案例类。这些分类其实是基于我们视频账号的整体搭建来规划的。

以我的素材为例，可以分为：他个人的、团队的，以及产品的。通过这些维度，我们把所有素材归类整理，这样剪辑同事在操作时就有内容可用。比如说，有些内容可能需要以 vlog 形式呈现，而 vlog 就需要大量、全面的素材，才能把内容做完整。如果暂时没有，我们就逐步补充——甚至刚开始没有工地素材的时候，我们都是去补拍的，包括明天我们也计划去工地，补拍一些觉得还不到位的细节。

可能大的场景有了，但还需要更细的动作、更具体的呈现，这些我们都在过程中慢慢完善。刚开始素材可能不够丰富，但关键是要先开始做，再不断补充。

#### 5. 持续生产好内容：结构拆解

包括我们对营销视频内容的拆解，也会参考别人做得好的视频。注意，不是一比一照搬，而是拆解它的结构：看它的动作、场景、镜头是怎么做的，再通过一些方法，甚至借助 AI 工具，去分析它的框架。AI 确实帮了我们很多，减轻了操盘手在内容策划上的压力。

我们拆的是结构，不是原样复制。比如那条视频“为什么要找冰姐装修的六大理由”，它之所以成为一条获客效果很好的视频，正是因为它有一个清晰的结构。我们学习的是这个框架，而不是内容本身。

包括我自己做 IP 这两年多，有一个很深的感受：未来，没有原创能力的 IP 会越来越难做。老板 IP 做到后面，绝对不再是靠模仿，一定得会原创，得清楚什么样的内容值得做、为什么要做。这是我亲身走过的体会。

#### 6. 放大精准阶段：我怎么做投放

说到第三个阶段，也就是放大阶段，我真正开始做投放是去年 10 月份。现在回头来看，我最大的感受就是：投晚了。

我当时找的是第三方投放团队，筛选标准主要有这几个：

第一，必须是家装行业的投手。我合作过几个投手，最后发现效果最好的，还是专注我们家装行业的。因为他懂行，懂业主的痛点。泛行业的投手，根据我的经验，效果并不理想。

第二，他最好有对标的案例，有对标的同行给我参考。

第三，一个很重要的标准是，他至少是从百度时期就开始做投放的。我认为投放的底层逻辑是相通的，只是平台政策会有变化。第四，他的应对能力要强，能根据平台政策快速调整。

比如最近我们从 AD 投放到本地推，整个过程非常痛苦。7 月份开始，平台政策调整，家装行业不能投 AD 私信，只能投 AD 表单。但表单是被动获客，而我们更希望直接触达用户，所以转而做本地推。转型的过程就很煎熬，因为本地推的底层逻辑不一样，而且效果还不稳定，时好时坏，像坐过山车一样。

我考核投手的标准，首先是有效率（精准度）。不能说我想要全屋改造的客户，却来了一堆只想做局部翻新的；或者来很多同行误触，这些都会影响效率。

其次是获客成本，比如我们的理想成本是多少，以及流量跟产品的匹配度。

目前我们和投手的合作模式是：他们只赚取充值返点，具体多少我们也不清楚，可能十到二十个点。

根据我的经验，最重要的一点是：老板自己一定要懂投放逻辑。你得知道哪些视频适合用来获客，哪些适合做投放，哪些只适合加热。如果不懂这些底层逻辑，很容易被割韭菜——我自己也踩过这个坑。

包括我刚才说的原创视频，你做一条内容，得清楚目的是什么：是为了立人设？还是为了搞笑赚热度？还是为了获客？尤其是我们这种高客单、低复购的实体商家，必须想清楚每条视频的目标，以及它是否值得投放或加热。

投放之后，给我带来了三个层面的进步：

第一，确定性：投放之前，我单账号靠自然流每月大概获客 100-150 组，波动很大，完全没法预测。但投放之后，我能清晰地掌控这个月想要 300、500 还是 600 个线索，只需要调整预算和成本控制就可以了。

第二是有效率：投放之后，我们的人和品牌每天能几万甚至十几万次触达到精准用户，能在当地快速出圈。我以前没意识到，最近明显感觉到自己在本地的知名度提高了。做个人 IP 和品牌，现在的速度比以前快太多，这就是效率的提升。

第三是科学性：作为老板，我得清楚公司的毛利结构，投流成本、人力成本、房租水电等占比各是多少，才能科学制定销售目标。比如我这个月要做 500 万业绩，我得知道运营成本占比多少，投流占比多少。

我目前把营业额的 3% 用来做投放，也就是一个月 15 万左右，对应 600 条左右的线索（这个线索量已经到我目前团队的承接上限）。所以这一切都是基于科学计算来调整的。

500 万的业绩目标不是随便定的，它必须和团队配置匹配。做 300 万、500 万和 800 万所需的团队架构完全不同，投流成本和线索量也都不一样。所以我们必须科学分析，比如明年想做 800 万，那么需要多少人、什么样的架构，在年初就要规划好。

在我们这个行业，设计师是有承接上限的——一个月接三五个客户已经饱和了，最多五六个，再多服务质量就会下降。所以流量来了，必须有人能接得住，不然就浪费了。前后端必须匹配起来。

#### 7. 打造老板IP矩阵

我们接下来的重点，是开始做老板 IP 矩阵。

我现在正在尝试打造一个男性 IP，因为我觉得不同风格吸引的客户偏好会不一样。根据我目前账号的数据，我的粉丝中大约 60% 是男性，40% 是女性。如果做一个男性老板 IP，这个比例可能就会反过来，这样就能在风格上形成互补。

下一步我们还计划推出一个设计师 IP。不过有一点我需要强调：只有当我们确定这个设计师会成为公司的合伙人，我才会去投入做这个 IP。包括工程端未来也可能打造专属 IP。这样做的目的是，当用户在当地刷到我们时，他看到的不只是一个账号，而是我们公司不同板块的专业呈现——让大家更清楚我们是如何把产品落地的。

另外，我自己目前还在做一个泛流量的内容账号，积累了几万粉丝，后期可能考虑家具类的变现。这算是我布局中的一环。

#### 8. 老板IP短视频获客各阶段总结

回顾我早期的做法，流量型内容主要是为了告诉抖音：我是一个家装账号，想要吸引装修人群。这样做是为了拉高账号权重，让平台识别这是一个有价值的账号。

但光有流量不够，更重要的是变现。

所以第二阶段，我开始搭建更丰富的内容维度，比如用体现老板专业和信任感的内容来建立用户关系。

直到现阶段——也就是账号相对稳定，人设视频、各种内容类型都比较完整了，我才开始投流。

我个人不太建议一上来就投流。因为如果你的账号内容还没搭建好，用户不知道你能提供什么服务、解决什么痛点，投流效果会打折扣。真正精准的用户，他会看你的视频、进主页了解你，甚至关注你几个月才留资。所以内容搭建是基础，投流只是放大精准流量的手段。

我们通过投流吸引来的用户，最终会引导到私域成交。在私域里，我们做老客转介绍、办粉丝见面会，下一步我还计划重启老板 IP 直播。

#### 9. 进阶：老板IP直播

其实在没做投放之前，我是直播过的。对我而言，直播最大的价值是打造差异化。现在家装赛道竞争越来越激烈，不管大公司小公司，老板纷纷下场。怎么让用户记住你？我觉得最终还是回归到“人”。

通过直播，用户能真实感受到老板是个什么样的人、性格如何、专不专业。你可以在直播间解答问题，让用户因为喜欢你而认可你，从而留资。这也间接降低了获客成本，同时构筑起公司的护城河。

但说实话，直播非常考验一个人的脑力、体力和心力。我一般一场播 2 个小时，一天 4 个小时。播完整个人像从水里捞出来一样，全身是汗——如果没有这种投入，说明你没有真正高度集中。

直播中你要回复问题、组织话术、留人、转化，还要应对黑粉，必须全程保持专注。身体不好根本扛不住，能坚持下来的都是真本事。

目前我以坐播为主。场景搭建比较重要，灯光、背景、个人形象其实都在传递你产品的定位——是做高端还是中低端，用户一眼就能感知。

坐播对话术和留人能力要求更高，但来的流量更精准。虽然场景播容易吸引人，但来的用户可能太泛，所以我们还是选择精准路线。

我的直播框架核心是利他主义：完全站在业主角度，帮他们解决问题。比如教他们怎么选装修公司、合同有哪些坑、哪种装修模式更合适。在内容中传递价值观，最后引导留资——这些都是经过验证的有效路径。

#### 10. 我的团队构成：3人小团队

最后讲讲我的团队。作为 IP 操盘手，我本人负责出镜、内容规划、投流、数据分析和团队培养。运营同事主要负责我的日常安排，比如粉丝见面、工地巡检这些需要出镜的行程。我们团队几个人都具备拍摄和剪辑能力，包括我自己——最早所有视频都是我自拍自剪的。

我始终认为，如果公司体量在几千万以下，老板一定要亲自干。如果你自己不懂，你就没办法判断运营的水平、内容的好坏，甚至容易被专业岗位牵着鼻子走。正因为我自己干过，我知道标准在哪、什么样的内容能爆、结构应该如何——所以我才能快速培养新人，用 7 到 10 天让一个新手剪出我这样的视频。

尤其是流量端口，它关乎公司命脉，必须由老板或核心合伙人亲自掌握。这是我一路走来的切身经验。

### 四、老板IP获客心法：必经阶段&必备素质

接下来我想分享一下关于老板获客心法，我觉得这一点也非常重要。

我自己实践下来发现，做老板 IP 不能像打造网红那样操作，我们必须突出自己的专业性，真正销售的是我们的产品、服务，最后才是“人”——也就是自己。如果一个老板连自己都推销不出去，可能也算不上一个合格的老板。

我们主要通过这几个方面来建立信任：

第一是靠谱，实实在在做生意，让人感觉踏实；

第二是靠专业支撑，让自己成为行业里的行家；

第三是表现力，这一点我觉得特别重要。同样的脚本内容，不同的老板讲出来，感觉完全不同——有的人让人觉得真诚可靠，有的人却可能因为形象或表达方式，反而显得不太可信。表现力是需要刻意练习的，我自己就花了大量时间去训练。

第四，我们不是以做成“网红”为目标，而是始终带着商业思维运营账号。这个账号应该是公司流量的重要入口，所以它的流量贡献占比、投放策略，都必须与公司的整体商业闭环紧密结合。投流不能盲目，既不能完全不投，也不能乱砸钱，必须科学规划。

回顾我自己做 IP 的历程，大概经历了四个阶段：

第一阶段非常艰难，抗拒镜头、害怕表达，觉得特别累。这是很多老板都会遇到的坎，不少人就在这个阶段放弃了。

第二阶段是坚持三四个月后，方法找对了，也开始拿到一些正反馈，越拍越有感觉，逐渐有了成就感。

第三阶段是规模扩张，团队从去年二三十人扩充了一半，投放预算增加，店面也扩大了。

现在进入第四阶段，偶尔也会感到疲惫，甚至需要运营推着去拍内容，对数据有些麻木、分享欲下降。我不断提醒自己，必须始终保持对平台的敬畏之心，坚信只有好内容才能带来持续回报、降低成本。

什么是好内容？我认为是那些真正利他、具备高变现能力的内容。同时，老板的表现力、拍摄场景、灯光布置等等，也都要跟上，不能落后。

做老板 IP 最重要的几个素质：

第一是心态。心态直接决定你的下限。起初大家都急：急着要客户、要转化。但一个好的账号搭建，没有两三个月根本沉淀不下来，急是没用的。另外，千万别追求“完美人设”。粉丝其实更喜欢真实的你，镜头显胖、状态不好，这些焦虑都得放下。

心态调整确实不容易，尤其平台规则几乎每两三个月一小变、半年一大变。我的方法是多看那些正能量的人物访谈，尤其是从新媒体走出来的人，了解他们如何面对困难。你会明白：想做好一个能落地的账号，本来就要经历这些，心态必须稳。

第二是学习力。平台和用户的喜好一直在变，去年的内容今年未必有效。必须持续学习、拥抱新事物。像我们最近开始布局小红书和视频号，每个平台玩法不同，必须主动适应。不要说“我不懂”“我年纪大”，要保持开放。就像我以前也没想过会开电动车，但试了后发现真不错——先接受，再优化，多和年轻人交流，随时记录灵感，把学习变成习惯。

最核心的是第三点：内在驱动力。老板必须自己冲在一线，因为没有退路，也只有老板最懂业务。我从没想过“我做不起来”，只会想“哪里还能优化”。我相信只要方法对、人坚持，事一定能成。现在做 IP 已经是我百分百投入的日常工作。

如果老板自己不全情投入，指望第三方团队帮你做起来，我至今还没看到成功的案例。除非你愿意花钱买经验，先摸清打法再亲自干。否则，做老板 IP 这件事，真的很难靠别人完成。

以上就是我的一些真诚分享，希望能对大家有所帮助。

### QA

Q：装修服务一般怎么定价？我们也是做全案整装的装修公司，城市人口 60 万左右，收费区间大概是多少？

A：收费其实没有统一标准，每个城市都不一样。一二线、三四线、五六线城市，收费标准差异很大。关键还是看当地的市场行情和消费水平。

Q：怎么找到适合自己的对标账号？

A：首先得明确你自己的人设定位。先确定你在同行业中的角色——是设计师、老板，还是专家？定位不同，内容打法就完全不一样。你是瑜伽老师，那就应该打“专家人设”，去找同类优质账号，多看他们的内容，慢慢你就能理出思路。

Q：老板人设和专家人设有什么不同？

A：老板代表的是公司，要传递企业战略、价值观和用人标准。你的价值观就是你公司的价值观，这点非常关键。而专家人设，比如设计师，必须突出你的专业差异：你和其他设计师比，独特在哪里？客户为什么选你？但要注意，不是讲得越专业越好，用户不一定听得懂。

Q：我是做房地产自媒体的，一直找不到自己的定位，感觉老板讲的内容不是客户想听的，客户到底想听什么？

A：做房地产自媒体，可以适当结合热点做泛流量，因为买房是大众需求。但最终还是要回到精准流量——找到目标准客户的痛点。你需要明确：你的客户是谁？他们买房最关心什么？你能提供什么独特价值？我的经验是，营销视频一定要直击痛点，让用户清楚“你能帮我解决什么问题”。

Q：找了很多对标，还是找不到自己能做的方向，怎么办？

A：如果还找不到方向，建议先“内找”再“外找”。内找，是弄清你的产品卖给谁、客户为什么选你、你的核心竞争力是什么。弄清楚这些，你再出去找对标，思路会清晰很多。我自己早期也是这样一步步摸索出来的。

Q：剪辑人员的薪资大概多少？该怎么培养？

A：在我们广州、佛山，新手剪辑月薪大概 4000 左右。我一般招大学刚毕业、学过相关专业但没经验的人，从最简单的口播视频开始让他剪，熟练后再慢慢增加难度，比如 vlog、实拍剪辑等。

Q：需要专门招一个助理跟着老板拍摄吗？

A：这要看公司体量。像我们目前还不是特别大，不会专门配一个助理整天跟着。我会让团队里有空的人来拍——运营、助理、剪辑都可以，重要的是他们得具备基本拍摄技能。我要求新媒体团队每个人都要会拍、会剪，这是基本功。

Q：做 IP 之后，是不是所有客户都指定要见你？怎么平衡？

A：不会所有客户都要求见 IP。有些客户下面的人就能搞定，他们自己解决；偶尔有客户强烈要求见面，我会去，因为见面成交率确实更高。关键要把握好度，既让客户感受到重视，又不过度消耗 IP 的精力。

Q：每天发多少条视频？运营剪辑的工作量大不大？

A：我要求账号日更，两年多基本没断过。现在有几个 IP 账号，抖音主号坚持日更，全国泛流量账号两三天一更。剪辑每天最少要完成两条，这是最低标准。

Q：做账号有哪些推荐的第三方工具？

A：拍摄的话，可以用“轻抖”这类有提词功能的软件；内容创作上，我常用 DeepSeek 这类 AI 工具辅助，但生成后自己还要调整优化。

Q：内容要同步发小红书和视频号吗？

A：我是先发抖音，再发小红书，最后发视频号。但不会完全一样——每个平台的用户偏好不同，封面和内容会稍作调整。

Q：小红书接下来打算怎么做？IP 内容在小红书投放有效吗？

A：小红书我们已经尝试并拿到了一些结果。家装行业在小红书获客没有抖音那么稳，所以我的策略是“多做账号+适当投放”，把它作为抖音的补充。IP 内容在小红书是有效的，我目前用公司号和个人号绑定运营，个人号内容不像硬广，但仍有营销属性。小红书不需要日更，但抖音我建议尽量日更。

Q：如果不露脸，能做 IP 吗？

A：如果不露脸，很难做出差异化。尤其像我们这种高客单价的行业，必须露脸——人和人之间的差异就是最大的差异化。同样的产品，不同的 IP、不同的背景、不同的表达，感受完全不一样。如果客单价不高，或许还可以，但要做 IP，我强烈建议露脸。
