# 登录并下载 ChatGPT：

(a) 解决好网络和谷歌账号后，在百度搜 ChatGPT 进入官网，进行注册登录。

(b) 登录后左下角有"下载客户端"，可以尝试下载。如果不能下载或无法登录，可能是因为没有订阅套餐（即没有会员）。

(c) 客户端下载下来后，登录时可能还需要验证码（就跟注册谷歌账号一样），需要的话就再用一次接码平台。

# 订阅套餐：一般有两种方式：

(a) 找别人代充：最简单，就是多掏个几十块钱。在你有b方案的情况下没必要。

(b) 自己充：需要注册美区账号+购买礼品卡。（第一次用时就注册美区账号花个半小时），**我就是用这个方式**
