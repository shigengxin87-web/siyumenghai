# 二、诊断与优化动作

## 1. 视频：补上“领课”承接

不应该直接结尾，漏了一个步骤。

前面铺垫卖课，开口卖课，卖课后要领课，**没有领课的口播和引导**，也没有规则和约束，没有紧迫感，所以只要犹豫或者慢半拍30%的主动加微就丢了。

直播主动加微率高，是因为有实时的引导和口播强调，短视频本身没有实时性，如果再不增加确认步骤效果就会大打折扣。

**这是视频的问题。**估计提升10%+，优化的越好，提升的增量越大。

## 2. 评论区的问题

**评论区没有运营动作。**

那些负面信息和差评，影响下单转化率和下单后的加微率。  

因为虚拟电商商品不会直接弹出二维码，而是发短信。但短信本身就不是一个最明显的方式，以及也不是让人安全放心点击的方式。

如果客户下完单还没去点短信，跳到评论区，看了那些评论甚至可能都不敢领、不想领了。

**不想领之后通常会有两种情况：**

1. 直接申请退款 （我看你们销售反加电话的速度还挺快，所以这部分应该会对冲掉）
2. 放着不行动，既不退款也不加。等销售打电话去提醒、引导、加好友。

**这部分预计可以综合提升5%，顺带提升下单率。**

## 3. 朋友圈

企业微信本身确实没有那么强的信任感，界面设计就是那样。这个改不了。

**可以自我优化的是，朋友圈。**

当你点击获客助手跳到主页的时候，量级越大，先去点击朋友圈的人也会越多，朋友圈现在一看上去有点不太美观和信任，可以优化一下。

**这部分预计可以提升2-5%。**
