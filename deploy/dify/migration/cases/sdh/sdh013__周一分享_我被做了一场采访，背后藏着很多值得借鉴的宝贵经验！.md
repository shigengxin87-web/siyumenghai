公域0元、3元、9元低价课，引流到私域，

这个模式，现在越来越多行业在用。

但我们在高途，很早就跑通了以及做到极致了。

 

2019到2023年，我一直在高途，主要方向就是K12。

21年双减，整个行业巨变。机缘巧合我们在内部创业，

# 三、操盘理念：深度非标个性化，联营不签约

我的操盘理念只有七个字：

深度-非标-个性化。

什么意思？

 

# 第一，我不是MCN。

我不会用一套打法，拉一堆老师来适配我。

我永远问一个问题：

是人套模式，还是模式套人？

我的答案：人套模式。

每个IP背景不一样，擅长不一样，产品不一样，目标不一样。

获客+转化的组合，有无数种。

有人公开课三天，有人五天；有人第一天推课，有人第二天推课。

有人适合做短视频获客，有人适合直播获客，细节全不一样。

 

# 第二，我做的是深度项目。

不是给你做一个月账号，也不是做一次发售。

我是围绕你，构建整个项目：搭团队、定模式、做运营、做投放、做私域、做交付管理。

这叫深度。你的事就是我的事。你好我才会好。

 

# 第三，联营。

老师做老师的事：配合内容、配合转化、配合交付。

商业操盘的事，我来管。

最后，我们一起分公司利润。

 

合作模式是：

先是股东合伙人，再是老师IP。

分钱是：

先是老师IP，再是股东。

你作为老师，配合内容、转化、交付，拿角色绩效；

你作为股东，再拿利润分红，杠上加杠。

 

成本呢？

所有成本一起担，最后分公司利润。

每个环节，你参与了多少，就按环节设计工资或者提成。

 

 

我的合作原则：

到了不得不合作的时候去合作，而不是为了合作而合作。

前置要有静默期、观察期。

大家在社群里相处，你问我问题，我帮你解决。

常来常往，我了解你是谁，你也了解我是什么人。

我觉得匹配，比能力更重要。

很多独立K12教培IP，公域做得不错，私域也能转化。

但为什么规模上不去？

 

因为他们只做“续”和“转”，不做“扩”。

 

转，是转介绍

扩，是扩科。

升，是升单。

 

举个例子，全网皆知的头部英IP，雪梨老师，两千万粉丝，几百万的私域，只卖英语。

买英语的家长，能不能买数学？能不能买语文？能不能买物理？

一定能。

但他没有扩科，不管为什么，结果都是流量只用一套品去洗，太浪费。

 

新解决私域首单的问题，让更多人买单，成为付费客户。

续、转、扩、升，提高LTV，让付费客户付更多费。

 

裂销撬导合，让流量获取不只是依靠公域，私域获客+渠道获客。
