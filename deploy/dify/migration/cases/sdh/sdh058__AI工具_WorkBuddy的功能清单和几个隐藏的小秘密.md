# WorkBuddy的功能清单和几个隐藏的小秘密

# 微信端或者手机端遥控指挥电脑工作

WorkBuddy左上角有一个“助理”的功能，但这个功能对于目前来说我觉得意义不大了，用微信、企业微信、飞书、钉钉等作为沟通频道跟WorkBuddy对话控制执行任务，如果你本身就在电脑上工作，那么直接切换到WorkBuddy的客户端就好了，没必要用其他软件对话，而且其他软件所有对话混在一个对话框里，比较乱。

如果不在电脑旁边，直接在手机上下载一个WorkBuddy的app就好，支持连接本地电脑（需要电脑开机登录WorkBuddy）和云端电脑工作。

# 我用的最多的板块：“专家”和“skill”

一共有四类：

- 专家（申请开放平台：open.workbuddy.cn）
- skill（申请开放平台：https://skillhub.cn/）
- 连接器
- 顶部的“发现应用”

这种智能体在 WorkBuddy 里面叫做**“专家”**，在豆包工作里面叫做**“伙伴”**。

同样的智能体，在两个平台上的来源有一点不一样：

WorkBuddy 里的专家，**一部分是腾讯官方自己上传的，还有一部分是个人或公司单独上传的**。比如我在某个业务上非常擅长，就可以把过往经验和知识库训练成一个知识智能体并封装起来，上传到 WorkBuddy 的开放平台。上传之后，在“专家”里面就可以调用自己的智能体了。

豆包工作目前公开能看到的，都是它平台内置的。这种和创作者上传的区别在于：**很多内置的其实只有个框架，实际用起来并没那么好**。

那对于个人创作者上传的，只要上传的人确实有货、东西也做得不错，**那这个专家用起来就会非常好**。**它比官方自己上传的同类型功能要更好一些**，因为融入了个人的经验，而这些经验是官方拿不到的。

不仅仅是专家这个板块，像技能这个板块也一样。WorkBuddy 是有 SkillHub 这个开源网站的，然后你可以把你的这个 Skill 上传上去。

**案例：这个叫做“创业伙伴的”专家，引导语和开口就开始用书引流了。**

# 积分和模型调用

目前WorkBuddy每天只要你上线就送 **100 积分**，所以你每天记得打开一下，领取一下积分（在左下角会弹出来）。

模型这块有这几种用法：

- **HY3（混元3，腾讯自己的大模型）**：这个模型是免费的。
- **自定义模型**：用 DeepSeek、用 Kimi，去这些开放平台生成自己的 API key 并充值，然后把 API key 放在这里，就可以调用了。
- **生成图片或视频的模型**没有免费额度，会消耗你的积分。**积分就是钱**，当你没有积分了，就得拿钱去充值，所以现在这个软件你用的多不多，都要每天上来领 100 积分。

# 空间

WorkBuddy 里的空间就等于文件夹，比如短视频空间、直播空间，里面可以有多个任务。

你去创建任务的时候想清楚，如果是一个系列的，那么你就直接建立一个空间，然后在空间里建任务，因为WorkBuddy现在有一个bug，**一个单独的任务，不可以移动添加到一个已经有的空间里，它会自动创建成一个单独的空间**。

可以理解为本来是想把一个任务放到一个房子里，结果这个任务自己变成了一个新的房子。

# 总结

整体功能主要就是这几项，但是每一项功能**都有很深的空间需要去使用去挖掘。**

**文字性**的内容创作和沟通用Workbuddy都没问题，图片类和视频类的一般，这两类依赖模型。

像目前**图片创作**还是更建议用gpt的image2，**视频创作**用即梦、可灵等。AI剪辑用chatcut。

日常的一些轻量级的开发，比如说给自己做个工作台，或者做个小软件小应用小程序，这些也都没问题。因为它主打的就是高效、容易上手、模板多。

所以，Workbuddy确实是目前国内AI办公智能体平台第一名。

目前微信聊天记录可以合并转发到Workbuddy，相信未来还会有更多的关联性功能出现，而且视频号、公众号这两个不对外开放数据的内容平台全部都能成为Workbuddy的语料供给和连接通道。
