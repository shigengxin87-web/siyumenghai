## 一、定位与价值

石更新的标签是"7 年知识 IP 私域增长策略专家"，主打从教育大厂到独立创业操盘这条线。石董会不是一个泛泛的"私董会"，而是围绕"IP 打造 + 公域获客 + 私域转化"的垂直实战社群：帮 IP 找到自己的生态位，把公域流量稳稳转成私域成交。

## 二、权益：999 元永久

一次付费 999 元，永久权益，长期在群里。

交付标准很明确：当你因为石董会的帮助或分享，直接或间接赚回 999 元（或减少了 999 元损失成本），就算交付到位；没回本就等于还没交付到位，继续加速产出价值，之后全是超预期。

石更新说过，他不在意赚多少钱、有多少人参加，"做了就是赚了"，更看重持续分享、对接资源、反哺公域。
