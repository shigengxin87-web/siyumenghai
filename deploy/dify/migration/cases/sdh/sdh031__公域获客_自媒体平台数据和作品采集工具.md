结尾有四个工具的使用推荐。

# ego浏览器

一款AI浏览器，直接上手用，去感受。

需要借助AI agent 接收任务，并驱动浏览器去执行。支持 Cloud Code、Codex、Workbuddy、豆包工作等多种agent工具。

安装ego浏览器后，在agent对话框里，输入/ego，就会出现/ego-browser 插件，然后附上你的任务指令即可。

官网下载地址：https://lite.ego.app/

# 使用推荐

- 社媒助手和媒讯助手都是以付月费、年费为主，年费就 200 多。如果习惯走这种付费订阅，就可以选择这种方式。
- ego浏览器和Agent Skill 这种就是消耗算力。如果自己 Agent 订阅的会员里面算力额度足够，且习惯用 Skill 方式，那就可以直接选 Skill，不用再去额外订阅。
- 如果有 ego 浏览器和 Agent Skill 解决不了的问题，恰好社媒助手或者是媒讯助手能解决，那也就需要单独去付费。
- 比如视频号和公众号的监控和采集，目前**媒讯助手**是支持这个功能的。
