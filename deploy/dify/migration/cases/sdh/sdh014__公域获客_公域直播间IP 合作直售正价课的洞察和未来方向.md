# 公域直播间IP 合作直售正价课的洞察和未来方向

### 核心洞察
公域直播合作直售正价课（大场模式）2024年巅峰期一场直播轻松卖一二百万，很多卖几百万卖上千万，到2026年效果断崖式下滑——核心原因是私域存量被反复清洗、IP自有产品体系升级后自我消耗、投放用户的信任与需求不匹配。
解决方案：从"堆合作数量"转向种草前置 + 固定联盟合作 + 内容交付店播三驾马车。

# 一、什么是大场模式

**不知道你们有没有注意过或者刷到我一些直播间。两个不同的IP老师在一个画面里出现卖某一个老师的课程。**

这种大多数卖的都是学科和素养课程，简单的说都是针对孩子的，大部分是少儿到初中范围。

商业类变现的类目，做发售的时候比较常见。

因为我有两个客户过去很大一部分营收都是靠着模式，但是这个模式现在有些问题，对于增长下滑了，所以我发现这个问题后赶紧做了拆解和应对方案。

k12之间合作一般称之为**大场**。所以我下面都会用大场来说。

本质其实就是一个卖课卖货的直播间，所以大部分家长粉丝是不太反感的，甚至有很多家长是非常高意向的，因为很多妈妈关注他们就是为了给自己孩子买书买课的，需求很精准，所以在直播间直接卖好几千的大课卖的也很不错。

### KOL带货的两个隐患

这些KOL的差评和舆论主要出现在两个方面。

1️⃣带谁的品说谁好，2️⃣带的品客户反馈不好。

**主要问题会出现在这两方面：**

1. 首先是上面提到的问题
2. 其次，因为大部分能直接购买正价课的家长本身就是经过筛选的，而且 KOL 也会选择那些产品口碑和交付质量都还不错的品牌，否则根本无法达成合作，因为他们会有专门的选品团队来进行严格把控。

另外，K12 相关的课程类目并没有那么多，常见的也就是语数英这几个科目，或者是素质素养类的课程。它不像电商那样有特别特别多的类目。

所以他们最近要带这个品的时候就会极力推荐这个好，下次带另一个同类产品但不同品牌的时候又会说那个好。

**典型案例：**比如说，这个月带的是作业帮的学习机，下个月呢，又带学而思的学习机。带作业帮的时候，她说作业帮好；带学而思的时候，她说学而思好。

对于新家长新粉丝来说还好，因为确实每个都挺好的，不好也不能通过他们的审核进到直播间，只是对于那些买过的持续追随的家长来说，有的时候就会觉得很无奈，到底哪个好，前面买了那个今天又说这个好，还要不要继续买这个？要不要退那个？ 就开始纠结了。

> **轻一点说这是正常的现象，严重的说，如果不把控自己的嘴，为了提高本次销售额，可能就是割韭菜了。**

## 类型二：超级个体单IP合作

另一种是超级个体单ip。

简单的来说就是个体户和个体户或者机构和机构之间的合作。

从2023年北大花花（一个教育MCN旗下的主播IP）和豆神大语文（一个机构）合作之后，这种大场越来越多，本身花花算是一个语文类的学科ip，不算是带货KOL，所以很多机构或者个体之间的合作就开始了。

**合作模式简述：**比如说你是一个名师，你的产品和交付很好，但是你不想前端获客或者公域获客做的一般，那么你可以通过联动具有kol影响力或者有大量私域用户的其他ip做联动。你带着你的品进到合作ip的直播间，然后合作ip把他的粉丝和私域导进去集中卖你的课。

我这两个客户过往靠这个合作模式一年做几千万，好处就是不需要自己担心获客问题转化问题，只要有资源合作上基本躺赚，做好交付就行，坏处就是确实依赖别人，对于资源能力要求高，一般的对方也不跟你合作，想做很大，要么就得持续找几个顶流的跟你合作，要么就得找好多个好多个腰部的，所以对资源要求高，我觉得倒不累，因为也不可能每天都有合作大场直播间，半个月能有一个都非常牛了。

这种合作在2024年是最好做的，那会天时地利人和都到位。经过2023年头部之间的合作，大场模式得到验证，经过一年时间市场玩法也迭次了，比较成熟了。

大部分家长用户其实还没有被覆盖到，对机构来说玩法成熟了，但对家长来说是新鲜的，所以这个模式的下限直接抬高。一场直播很容易卖个一二百万。

另外24年很多超级个体IP或者MCN旗下的IP还处于有私域但没升单，有升单但没拓品的情况。

因为做大场需要势能，势能靠人堆起来的，大部分业绩其实都是靠私域的用户拉到直播见怼上去的，所以你会看到IP之间的大场合作为什么会选视频号作为主战场，更丝滑，用私域也能撬动公域。

很多IP的私域用户还没有被重复利用过，且做的早的，就是21年开始做IP的，都有两三年的存量在了，所以直接怼上去做一次大场就可以卖出去一二百万，甚至更多。

发售一般是发售自己的品，这种是拿自己流量做大场卖别人的品。

# 三、为什么2026年大场模式下滑了？

**现状：**现在已经2026年了，这个模式对应的效果和结果越来越差了，过往随便一场合作一二百万，现在一场直播使劲搞也就几十万，还不算退款，还不算双方分钱后，算上之后真实到手没多少了，一方能分个二十万都是不错的了。

![这张图展示了四个不同公域直播间的核心成交及相关运营数据面板，每个面板均标注了“累计成交金额”。左上面板累计成交金额为1,328,297.80元，对应实时在线人数8.2万、新增关注208、点击成交转化率18.23%等数据；其余三个面板累计成交金额分别为612,313.00元、580,863.00元、537,598.00元，对应着不同的在线人数、成交订单数、转化率等运营指标。这些数据与文档中2026年公域直播间IP合作直售正价课模式效果下滑的现状内容相关，体现了不同直播间的成交差异，可辅助说明该模式下的实际效果情况。](https://feishu.cn/file/W1VQbBCVxoTB4kx1j2BcD8w7n9b)

**那为什么会出现这个问题呢？**

## 原因一：存量用户被反复清洗

上面我有讲到两种模式，一种是KOL，一种是超级个体单品IP，超级个体单IP是靠存量来合作的，市面上知名的头部IP，合作一圈后基本都被洗过了，存量用户只要洗过一次，第二次数据就会腰斩。

> 都是主打一个新鲜，除非你的产品极其稀缺，但是在中国没这个可能。

## 原因二：IP自有产品体系升级，自我消耗

现在已经26年了，超级个体单品IP或者教育MCN都围绕自己的产品体系做了升级，过往可能只有一个课，现在有了第二个，第三个，有了就会用自己的私域去售卖，所以自己已经把自己的私域洗过了。

## 原因三：私域用户质量参差——信任度与需求不匹配

**私域除了看数量还要看质量，看性质。**

要看超级个体IP的私域来源，主要是低价用户、还是中价用户、还是高价用户。

用户是自然流内容吸引进来的，还是投放买进来的。

如果是投放买进来的，那么做大场合作时转化率的数据就会非常差。主要有两个容易忽略的点，容易让自己对结果判断有过高期待。

### 🔸 问题1：信任度不够

纯投放买量的用户本身就对这个IP的信任度和喜爱度没那么高，因为是平台靠数据靠算法根据需求拉过来的，在公域成交客户的时候也施展过还有xx几单类似这样的销售话术了，并不是靠个人魅力和内容吸引的。

另外大场要卖的课是另外一个老师的，对于家长来说都不认识另外一个老师，对原本的那个IP信任度就不够，对另外一个更不够了。

### 🔸 问题2：需求不匹配

需求不匹配，心智不匹配。

越是投放来的，需求越单一。这类人群有一个特点，我来你这里就是冲着你能解决我这个需求的，不要跟我谈其他需求。

**举例：**比如你是语文老师，我是数学老师，你跟我合作做大场卖我的课，你的学员在你这的需求，对你的标签就是语文，不是家长没有数学需求，而是在你这第一反应没有数学需求。个别的可能会问问老师你们有数学课吗？

所以硬把家长拉到直播间去推另外一个学科老师的课，现在真的很难了。

这两个问题点就是我自己**成交三角体系**里最重要的两环。成交三角体系：**需求 + 购买力 + 信任度**。

# 四、解决方案：从堆量到深耕

## 1. 从「硬推」转向「种草」

这种情况要做的是换一个思路，把这种合作和关系变为小红书的打法，**要种草，要推荐，要提前植入**，**要有过程**，不能说过几天开播，临近前几天私信群发邀请了一个xxxx牛的老师，这样做肯定效果不符合预期的。

甚至要**公域私域双打同时做种草**，公域通过发布内容和产品投放相似达人粉丝做触达，私域的粉丝会以为是自然刷到的，在心里对这个新老师有一定的位置。

## 2. 从「广撒网」转向「固定联盟」

我这两个客户，他们是有商务专员的，甚至有的时候自己就是商务，过往靠不断跟各个IP合作，只要有合作就会分成，但这种靠旧模式靠不断堆合作IP的数量不长久不舒服。

会越做越别扭，未来要合作的IP也会越来越少，因为大家获取新客户都挺难的，如果咱俩合作，我的客户被我洗过后没有多少新用户给你了。

**建议：**应该选定几个过往合作过，价值观、默契度、人群和产品匹配度高的长期合作，形成固定稳定的联盟，对家长来说在外部看觉得你们是一起的，内部你们怎么合作怎么分钱自己沟通好就行。

> 这里我推荐两个IP，这两个IP的家长粉丝粘性老高了，甚至家长都抢着要买他们合作的其他科目的课程。

## 3. 三驾马车：内容 + 交付 + 店播

**归拢精力，做内容做交付，做店播找搭子。**

> 做内容是为了更好的获客和提高转化率。做交付是为了不崩塌和转介绍。做店播是用主播日不落直播来释放IP的时间精力投入到内容和交付。找到可持续长期的IP搭子。
