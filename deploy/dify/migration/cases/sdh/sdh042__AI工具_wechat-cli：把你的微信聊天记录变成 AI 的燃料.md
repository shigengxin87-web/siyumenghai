## 一、这是什么

一个辅助我们读取微信信息的插件：wechat-cli。

它干一件事：**让你（或者你的 AI 助手）能读取你电脑上微信的聊天记录。**

包括：群聊记录、私聊记录、联系人、群成员、收藏、未读消息。还能按时间筛选、按关键词搜索、按消息类型过滤。

## 三、装了能干什么

### 场景1：群聊精华总结

群里一天聊了几百条，你没时间全看。

用 wechat-cli 把聊天记录拉出来，它帮你：

- 总结今天群里讨论了什么
- 提炼几个关键观点
- 标出谁问了什么问题、谁给了什么方案

**以前翻30分钟群聊才能了解的事，现在1分钟看完。**

做社群运营的可以每天做总结推送给社群成员。

### 场景2：提炼选题写文案

你在群里聊了很多有价值的内容，但这些内容散在各处，没法直接用。

用 wechat-cli 把一段时间的聊天记录导出来，让 AI 帮你：

- 从聊天中找适合你的选题
- 基于真实对话写公众号文章、写短视频脚本
- 把群友的提问整理成 FAQ
- 把精华内容直接做成知识卡片

之前我在朋友圈看到一个人写的文章， 把我在那个群里说的信息和观点全都给扒走了。这让我想到我们自己更要学会截流自己的内容做成流量。

### 场景3：做网站做海报

在群里做了精彩的分享、讨论，但在群里发之后容易沉没掉。

用 wechat-cli 把分享内容拉出来，配合 AI 工具：

- 把分享内容做成一个网页（落地页、知识卡片页）
- 把核心观点做成海报图片
- 把群友反馈做成案例展示

**群里的内容不该只活在群里。** 它可以变成你的内容资产，对外传播。

### 场景4：信息提纯后导入知识库

你加了很多群，每天收到大量信息。大部分是噪音，少部分是金子。

用 wechat-cli 把聊天记录导出，让 AI 帮你：

- 过滤掉闲聊信息，只留有价值的部分
- 把散落的知识点结构化
- 导入你的知识库（Ima、Obsidian、飞书等）做长期存储
- 作为 AI 对话的上下文，让 AI 基于你的历史聊天来回答问题

**你的聊天记录不是用过就扔的，它们是你个人知识体系的一部分。**

### 场景5：定时监控新消息

有些重要的群，你想第一时间知道有没有新消息、有没有人@你。

wechat-cli 有一个 `new-messages` 命令，可以增量获取上次检查之后的新消息。配合定时任务，可以实现：

- 每隔一段时间检查指定群的新消息
- AI 自动判断哪些消息重要、需要你关注
- 重要消息推送提醒，不重要的攒着

**不用一直盯着微信群，又不会错过重要信息。**

## 四、怎么装

直接一句话发给你的Agent，比如国外的Codex、国内的Workbuddy，以下步骤了解下即可，让agent直接帮你安装，缺啥少啥它会告诉你，你就同意安装即可。
帮我安装https://github.com/huohuoer/wechat-cli

### Mac 安装步骤

#### 第1步：安装 Node.js

如果你的 Mac 上还没有 Node.js：

1. 打开浏览器，访问 [https://nodejs.org](https://nodejs.org)
2. 下载左侧那个"LTS"（长期支持版）版本
3. 双击下载的安装包，一路点"继续"就行
4. 安装完成后，打开"终端"（在启动台搜索"终端"或"Terminal"）
5. 输入 `node --version`，如果显示版本号（比如 v22.x.x），说明装好了

#### 第2步：安装 wechat-cli

在终端里输入这一行：

```bash
npm install -g @canghe_ai/wechat-cli
```

等它跑完，看到没有报错就行。

验证一下：

```bash
wechat-cli --version
```

如果显示版本号，恭喜，装好了。

#### 第3步：给终端"完全磁盘访问"权限（关键！）

这一步不做的话，后面的初始化会失败。

1. 打开 **系统设置 → 隐私与安全性 → 完全磁盘访问权限**
2. 点左下角的"+"号
3. 找到你的"终端"应用（或者 iTerm，看你用的哪个），添加进去
4. **关掉终端，重新打开**

#### 第4步：初始化

确保微信正在运行并且已登录，然后在终端输入：

```bash
sudo wechat-cli init
```

会让你输入电脑密码（输入时不会显示字符，正常的，输完按回车）。

它会自动：

- 找到你的微信数据目录
- 提取数据库的加密密钥
- 保存到 `~/.wechat-cli/` 目录下

看到"初始化成功"之类的提示就完成了。

> **如果报错 `task_for_pid failed`**：这是 Mac 的安全机制。解决方法：工具会自动尝试重新签名微信。你只需要：
> 
> 1. 完全退出微信（不是最小化，是右键退出）
> 2. 重新打开微信并登录
> 3. 再跑一次 `sudo wechat-cli init`
> 
> 重新签名微信是安全的，不会封号。但可能影响微信自动更新，需要更新微信时从官网下载安装即可。

### Windows 安装步骤

#### 第1步：安装 Node.js

1. 打开浏览器，访问 [https://nodejs.org](https://nodejs.org)
2. 下载 LTS 版本
3. 双击安装，一路"Next"就行
4. 打开"命令提示符"或"PowerShell"
5. 输入 `node --version`，显示版本号就 OK

#### 第2步：安装 wechat-cli

```bash
npm install -g @canghe_ai/wechat-cli
```

#### 第3步：初始化

确保微信正在运行并已登录，然后在命令提示符中输入：

```bash
wechat-cli init
```

> Windows 不需要 sudo，但需要用管理员权限打开命令提示符（右键 → 以管理员身份运行）。

## 六、风险和注意事项

### 数据安全

| 项目 | 说明 |
|-|-|
| **数据存哪？** | 全部在你本地。wechat-cli 不会把任何数据上传到任何服务器 |
| **能发消息吗？** | 不能。它是只读工具，不能发送、修改、删除任何消息 |
| **会封号吗？** | 不会。它只是读取你电脑上已有的数据，不干扰微信正常运行，不自动化任何操作 |
| **重新签名微信有风险吗？** | 基本没有。可能影响微信自动更新功能，需要更新微信时从官网重新下载安装即可。不会导致封号。 |
| **密钥安全吗？** | 密钥保存在你本地的 `~/.wechat-cli/` 目录，不上传任何地方。但不要把这个目录的文件分享给别人 |

### 使用边界

- **只查自己的数据**：这个工具是给你自己用的，不是让你去查别人的微信
- **遵守法律**：不得用于非法用途，确保遵守当地法律法规
- **尊重隐私**：如果你要用群聊数据写文章或做内容，注意保护群友隐私，不要暴露真实姓名和敏感信息
- **风险性**：无绝对安全，根据需求评估使用，如果读取信息主要是群聊的话，最安全的方式就是用小号进群
