# 去纳米盒拜访：重新理解好生意

前天我正好还在上海，我去拜访了知名的数字化产品教育品牌——纳米盒（纳斯达克上市）。

我和「大头老师」是第一次线下见面，之前都在一个同仁的群里，她是第13个加入咱们社群的。

我俩前后畅聊了4个多小时，中间还一起吃了个饭。

其中有几个词或者动作我想分享一下。

「自我觉醒」「停下来Stop」「写日记」「不做危险的事情」

她们公司面对的人群是家长这样的群体，但是她们的产品主要是数字化产品，也是自然规避了政策风险，app累计用户量高达四千多万。

她们之前也是做网校的，她也在内部创业搭建了IP团队，但是她们后来把网校业务弱化砍掉了，聚焦在数字化产品，就是切断风险！切断风险才可以放心大胆的做。

我这些年做的事情其实一直算是网校，就是做课程卖课程。

与她们相比，我反而更加羡慕模式背后的状态，她们的业务是不需要像我们那样周末上班、晚上跟课转化到很晚。

早上上班，傍晚下班。

工作好的背后是生活状态的支撑，需要持续长久的精神状态、身体状态支撑。

教培行业卷的不要不要的，员工换了一波又一波。

我以前深陷其中，但是我现在也慢慢的在往这种状态上迁移模式。

——————

她还给我分享到她已经连续写日记好久好久了，她会记录她的生活、情绪、故事，在写出来的时候，很多东西也都消解掉了，但之前她也是可能会敏感会内耗，现在早已自我觉醒了。

她分享到她现在会经常习惯主动去做家务，做家务可以专注的不去想任何事情，和写日记一样，做着做着所有的杂念 情绪就都没有了，人自然放空了（她跟我分享这个故事的时候，恰好乔伊发了个朋友圈也在提到做家务的事情），难道这就是灵魂的共鸣嘛哈哈。

我们聊了很多，发现有很多共同点和共同好友，走的时候还送了我一个礼盒，里面有一个充电宝，恰好我当时手机没电了，那次出行也忘记带充电宝了，所以你看，同频的力量太可怕了，都不用洞察需求，不经意之举就会自然靠近。

感谢「大头老师」接待。
