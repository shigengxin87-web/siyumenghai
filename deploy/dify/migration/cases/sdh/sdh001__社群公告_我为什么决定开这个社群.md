# 我为什么决定开这个社群

### 核心观点
做了就是赚了！不考虑客单价、不在意招生压力，当下能行动就去做。
999元永久权益，交付标准是帮你赚回999——回本了才算交付到位，后面全是超预期。

# 一、为什么以前一直没做

**从两年前到现在，有很多人跟我说过，觉得我可以做一个社群，然后分享一些东西。**

过往我一直没有做，是因为最开始压根就没想过围绕我自己赚钱，主要精力和心思都在操盘项目上。

出来创业快三年了， 也遇到过一些合作分手的事情，所以后面有意识要做自己后，我在去年年底付费请了一个教练，她给我定的高客单，然后有了我的9800咨询和几万到几十万的陪跑，所以我也没有做几百或者几千的社群。那个我收了一些，但也是随意，不算真正意义上的产品，有人问了需要了就说一下。

因为消耗的都是我自己的经验和时间，所以比较随意，但这个随意也确实延迟我的IP发展之路。**太慢了！**

# 二、花十几万学习后的观察

这几个月我花了十多万加入了一些社群和课程，以及深度参与了很多，所以我对社群有了一些感受，我看到了一些问题。

**观察预告：**后面我会当作案例给大家讲下，关于两个头部知名社群在续费率上的问题，我的观察。

现在已经26年了，如果要做一个新的产品，大部分人其实不建议做社群的，因为不够标准交付，且续费也不好做。

# 三、去年底的决定时刻

**但是昨天晚上十点来钟我为什么决定做了呢**，哪怕我知道可能参加的人并不多，以及我也不想群发私信触达。

**核心原因：**核心是一个点突然冒出来，有人有需求，是我当下能直接行动的我就可以做，不用考虑应不应该做社群，不用考虑客单价合适不合适，不用在意招生压力。

只要做了，就是在行动了，就会有新的内容产出，就会有我的体系完善，就会有新的东西出现。

因为我本身做事情至少在现阶段不是完全看钱的，如果看钱的话我就不用这么纠结了。

# 四、为什么做了就是赚了

我每天也有在记录在分享，每天都有人找我让我帮忙对接资源，那对我来说我其实本来就是在做社群该做的事情了。

当我做一个付费社群后，我就会更敬畏，对分享的内容有更高标准。

大家讨论问题问我问题后，我也可以有了更多话题去讲，去说，甚至可以帮我反哺到公域，我做IP就不用担心没话说了。

> **我根本不在意赚多少钱，有多少人参加，我就是想开了，对我来说，做了就是赚了！包赢的心态！干就完了！**

---

# 五、第一批用户来了

**然后我就去跟黄昶和韩老师发消息说：我决定了，999，永久。**

他们就给我转了费用，后面何木和一月老师也找了过来。

有人问我参加社群能学到什么我没有回复，因为我现在不想去介绍，也不想不懂我的人直接进来。

现在四个人挺好的，我也没有太大压力，把我的日常思考洞察分享给大家，解决解决问题，对接对接资源挺好的。

未来有人主动想参加，符合的我就收进来，一时半会我估计我也不会主动宣传或者发售这个产品，所以不会有很多人突然进来，不着急，**让子弹飞一会吧。**

你们也可以在群里观察一段，觉得适合身边朋友参加的可以邀请，觉得没啥帮助的也可以找我退款。

---

# 六、为什么是999永久？

**我为什么是定的999元给的永久权益呢？**

我对于这个社群的交付标准很明确，当你们哪天跟我说，由于我的帮助或者分享直接帮你们赚到了999，或者减少了999损失成本，那么我觉得算是交付到位了，我就放心了，如果还没有让自己回本，那我就知道我还没有交付到位，就继续加快速度达到999的实际价值回报，那后面的就都是超预期的。

所以我就直接定永久啦，我相信永久的情况下有足够机会和时间可以让我帮助你回报到999。

**交付哲学：**只要我还是在这个行业，我还好好的，我还有价值，我就持续分享，咱们持续处。
