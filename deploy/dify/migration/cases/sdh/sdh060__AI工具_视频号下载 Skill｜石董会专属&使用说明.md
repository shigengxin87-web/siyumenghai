# 第二种：我做好的skill

想要自己复用这项能力，就可以用下面这个skill。

目前是从我的服务器上走，如果要对外商用或者挂在自己对外服务下，可以先跟我说下，避免直接大量使用造成崩溃，影响你的口碑和体验。

## 1. 能做什么？怎么用？

把视频号分享链接发给 AI，默认保存视频、封面，并导出作者、文案、发布时间、点赞数、评论数等资料。也可以只下载视频，或只查询数据。

**安装一次，之后直接发链接。**

1. 下载并解压上面附属的 `download-wechat-channel-video.zip`。
2. 用支持本地 Skill 和命令执行的 AI 客户端（如 Codex、Claude Code、豆包工作、Workbuddy等）打开解压后的文件夹，发送：

   ```Plain Text
   请阅读这个文件夹里的 SKILL.md，检查并安装缺失的前置依赖，然后安装这个 Skill。
   ```
3. 安装完成后重新打开会话，复制视频号的单条作品分享链接，发送：帮我解析这个视频号，保存视频、封面和资料：这里粘贴链接或者说：“只下载视频”“只查作者、文案和互动数据”。

完整使用需要 Python 3.9+ 和 FFmpeg，AI 会按 Skill 指引检测并尝试安装缺失项；系统密码或授权窗口由你本人操作。

普通聊天网页仅上传 ZIP，不等于完成安装。文件默认保存在当前工作目录的 `downloads` 中，也可以指定保存位置。安装遇到问题见包内 README.md。

## 2. 基础原理

**你提供你想解析的视频号链接 → 石更新的专属服务器解析 → 元宝与视频号接口 → 返回视频地址和资料 → 文件保存到你的电脑。**

当前默认使用 `siyumenghai.cn` 的服务。服务器维护元宝会话，因此使用者不需要提供微信或元宝账号、Cookie、API Key。（相当于继续用我搭好的桥就行）

## 3. 使用规则与注意事项

只有一条：遇到任何问题第一时间找我解决。
