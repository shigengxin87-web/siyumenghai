# 用豆包工作画板，10分钟做完了整套课程上架物料

从一张Logo到4张1:1主图+8屏详情页长图，全程在豆包工作画板里完成，没有找设计师，没有来回改稿。
当然，也没有用 ChatGPT 的 Image 2 的生图模型。

豆包工作的画布功能在前两天刚正式上线，我自己之前用过国外的 Lovart这个软件（比较贵），所以我知道画布功能对于 AI Agent 讲是一个非常稀缺的设计功能。

所以我决定今天给大家分享一下豆包工作台的画布功能。

我选用的案例是用“石董会”这个社群的 logo，生成一套可以上传到短视频平台店铺的物料。

我在写这个文档之前，先自己去演示了一下，下面附属成品。

这篇我把整个过程拆给你们看，你们看完就知道这个东西怎么用、适合干什么、踩过哪些坑。

# 第一步：上传品牌Logo，建立视觉锚点

做品牌物料最怕的就是图片风格不固定。今天这个配色，明天那个字体，后天那个排版。

画板解决这个问题的方式很直接：**把品牌母版传上去，后面所有图都基于这张母版衍生，而不是从零开始画。**

我今天的操作是：

1. 把石董会的Logo（深墨绿底+金色书法字+青绿山水）上传到对话框
2. 跟豆包说："参考这张图的配色、字体风格、视觉元素，做一张3:4竖版产品宣传海报"
3. 它生成完，我看一眼，觉得可以，就把这张作为**主视觉母版**，存进画布

![原始品牌Logo](https://feishu.cn/file/Ln4Gbp6uOoeWthxSaa5cqhJXnef)

![基于Logo衍生的主视觉母版](https://feishu.cn/file/KRlrbz23NohearxzD6dcLjjJnG8)

**具体执行步骤：**

1. 先在豆包工作的对话框里输入一个左斜杠（/），在弹出的选项里点击“打开画布”，右边就会生成一个新的画布。
2. 勾选上“企业知识”，然后再输入一段指令，告诉它做这个画布的目的。比如这里我演示的是为“石董会”做一个产品宣传图。
3. 之所以勾选企业知识，是因为我已经把石董会的介绍和 logo 分别存放在飞书文档和多维表格里了，这样它就能直接调用，不用我再单独上传。
4. 当我输入这句话之后，它就基于我的 logo，帮我生成了这张主视觉。（当我看到这张图的时候，我觉得整体的效果非常惊艳。那一刻我就觉得我后面用 ChatGPT 作图的次数应该会少一些了）

# 第二步：基于主视觉，批量延伸主图

主视觉母版定了之后，后面的整套图就快了。

上架一般需要两套东西，一套主图，一套详情页。

我的做法是：

1. 先以主视觉为参考，生成几张1:1比例的主图
2. 主图确认OK之后，再基于主图，生成丰富的详情页

**4张主图放在一起，视觉上是一套东西，不是四张拼凑的图。（这就是画布的好处）**

以前要设计师做一套统一风格的主图，得调半天；现在你给个母版，AI自己就统一了。

# 第三步：分段生成详情页长图，自动拼接

详情页长图是最麻烦的部分。一般都很高，动不动上万像素。AI生图一次出不了这么长的图，怎么办？

画板的解法是：**分段生成，然后利用脚本直接自动拼接。（它先是直接给你一个整体的，然后你可以分图层修改。修改之后，你可以在对话框里面告诉它，让它组合在一起。）**

我今天做了6-段，每段都是3:4竖版（1080×1440）。

每段的内容如下，这每一段的内容主题是我给了了一个指令。我就讲了一下详情页里面正常应该都有哪些元素。他直接去调用我之前写过的文档内容（对社群的介绍），然后去产出了详情页。

| 段数 | 内容职责 | 解决什么 |
|-|-|-|
| 第1段 | 首屏定调 | 第一眼就知道这是什么产品 |
| 第2段 | 这是什么 | 讲清楚产品逻辑：从0到999，不是从9999降到999 |
| 第3段 | 关于主理人 | 谁讲的？凭什么信你？ |
| 第4段 | 适合谁 | 五大痛点直击，对号入座 |
| 第5段 | 你会获得什么 | 具体内容预览，不是空泛的目录 |
| 第6段 | 我的初心 | 情感共鸣，为什么做这个社群 |
| 第7段 | 成员展示 | 社会证明，大家都在里面 |
| 第8段 | 品牌收束 | slogan收尾，留下印象 |

# 第四步：局部编辑——插入真实头像

最开始的时候，他可能没有直接捕捉到我的头像，也不知道我要用哪个（因为我有很多）。所以我单独就头像部分做了，让他去给我做了这个修改。

具体步骤是：

1. 
2. 裁剪成方形头像
3. 跟画板说："把这张头像，替换到主理人图左侧金色圆环里，其他所有东西都不要变"
4. 它就真的只改了那一块——头像圆形嵌入金色圆环，色调和整体画面融合，其他文字、背景、山水全部原样保留

这就是**局部编辑**的能力。

你不用整张图重新生成，只改你要改的那一小块。

（可以在画板里面点击局部图片编辑，然后直接把你想修改的告诉他就行，你点击对应的分层图片之后，左边的对话框里面也会引用这张图，他就知道你要针对这张图片去做工了）

这一点太重要了。因为AI生成图最大的问题就是"牵一发动全身"——你改个文字，它连背景都给你重画了。但现在有了局部编辑，你可以先做一版整体视觉满意的底图，然后往里面换头像、换Logo、改局部文案，不用每次都从头来。

# 第五步：分图层，合并图层，导出成片

因为我是直接要求它给我生成一张详情页的，我并没有说让它给我分段。这里点击一张长图之后，它就可以去做分段拆分了，你就可以针对某一段去做编辑了。长按就有一个分图层功能。

画板其实有"分图层"功能，但自动分图层对AI生成的整图识别不准，总是失败。

如果在画板点击分图层失败了，那就在主对话框里面去下指令，让它去做分层就好。

分图层之后，要对哪一个图层做修改，你直接点击对应图层，然后在主对话框里面去输入你要修改的想法就可以。

当每一个图层都达到你的要求之后，你就在主对话框跟他讲，帮我直接合并成整一张图，你就可以点击图片下载了。

如果要把每一张都下载下来，可以直接在画布里框选住所有的图片，然后就会有一个“保存所有文件”的选项。

# 画板的核心能力，总结一下

做完这一套，我把画板真正好用的几个点总结出来：

| 能力 | 解决什么问题 | 典型场景 |
|-|-|-|
| 品牌锚点复用 | 保持视觉统一，不跑偏 | 做系列物料：主图+详情页+海报，风格一致 |
| 批量延伸生成 | 一套主视觉，衍生N个不同角度 | 电商主图轮播：首图+卖点图+讲师图 |
| 分段生成+拼接 | 做超长图，一次出不了那么高 | 详情页长图、小红书竖版长图、公众号长图 |
| 局部编辑 | 只改一小块，不用整张重画 | 换头像、换Logo、改局部文案、替换元素 |
| 多图层Frame | 每一层都可以单独编辑 | 后续需要频繁调整的物料，分图层管理 |

# 什么场景最适合用？

不是所有图都需要用画板做。我觉得这几类场景最值：

**1. 品牌系列物料**

你有一套品牌视觉，需要出各种尺寸、各种用途的图（主图、详情页、朋友圈海报、公众号封面）。用画板统一锚点，出来的东西风格一致，不用每次重新描述。

**2. 电商上架物料**

微信小店、抖店、小红书店铺，上架一个产品需要一堆图：主图好几张、详情页长图、SKU图。以前找设计师做一套要一周，现在一下午搞定。

**3. 需要反复修改的物料**

比如课程详情页，今天改个价格，明天换个讲师头像，后天加个学员案例。用局部编辑+多图层，改起来很快，不用每次重做。

**什么场景不太适合？**

单张简单的图，比如就做个朋友圈配图，直接文生图就完了，不用搭这么复杂的流程。画板的价值在于**体系化、系列化、可复用**。

# 最后说两句

今天做完这套物料，我最大的感受是：

以前做物料，最大的成本不是设计本身，是**沟通成本和等待成本**。你要跟设计师讲清楚你要什么，要等他排期，要改稿，要来回确认。

现在你跟AI讲，它立刻出图。不满意就改，改完再出。整个过程你自己就能闭环，不用等任何人。

当然，AI出的图也不是完美的——文字偶尔会错，细节偶尔会崩。但整体效率提升真的是数量级的。

你把它当成一个**随叫随到、改稿不厌其烦的设计师助理**，就对了。

最主要的是，它是我认为的国内生图、生系列图的最佳选择。

因为它跟其他的功能都绑定在一起了，不用我们到处去开各种的软件。

当然也有美中不足：目前画布里面没有办法针对图层去选中每一个框做文字修改，只能让 AI 去编辑。

国外的 Lookart 算是豆包工作画布功能的学习对象，相信之后的版本迭代当中，画布功能会越来越强。

再说一遍，豆包工作现在有 1 到 2 个月的免费会员，正常购买是一个月要 68 元。

PS:「豆包工作」的迭代实际上对标的一直是国外领先的产品，所以我觉得虽然豆包工作出现比Workbuddy晚了一些，但是在整个发展和实际使用上豆包工作会更强。（昨天企业微信发布打通了Workbuddy，实际上没有本质上的用处，豆包工作在上线的那一刻就直接跟飞书原生打通了，所以在飞书里直接就可以打开豆包工作）
