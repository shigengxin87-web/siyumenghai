# 基础背景信息

- **咨询问题**：视频号小爆了一篇图文笔记，想放大，第一次投流，不知道各选项是随便选还是各有玄机？
- **核心目标**：用最低成本把爆款笔记的流量吃干抹净，最大化导流到私域

## 一、投流设置方案（直接抄）

| 选项 | 设置 | 说明 |
|-|-|-|
| **优化目标** | 关注 | 核心目的就是导流加粉 |
| **预算** | 500 微信豆 | 小预算测试，先跑 |
| **人群模式** | 自定义 | 不要用系统推荐 |
| **年龄** | 对应人群年龄 | 你教什么年级就选对应家长年龄段 |
| **兴趣** | 知识 → 选符合的 | 在知识大类下找匹配子类 |
| **性别** | 女 | 你面对更多是女家长 |
| **人群** | 相似达人 | 找几个符合你目标人群的达人，**不要选大博主，选比你大一些的** |
| **地区** | 不选 | 先不限制 |
| **设备** | 不选 | — |
| **时段** | 24 小时跑 | — |

## 二、投放节奏

```Plain Text
先跑跑看 → 没跑完就再建计划 → 稍微放宽范围

```

逐层放宽，不是一步到位。

## 三、实战案例：50 元撬动 5 位数

**投放记录：**

- 建了 **1 个计划**，按上述自定义设置
- 地区做了微调：选了以往学员成交率高的几个地区（非全国）
- 花费：**50 元**
- 结果：私域加了 **十几个人** 🔥

**放大操作：**

- 追加投放 **100 元**，新建一个计划
- 借着这波热度，赶紧把流量吃干抹净
