从高途出来快三年了，最近一年我越来越强烈地感觉到一件事：我们这行靠"低转高"吃饭的日子，正在快速过去。不是说这个模式要死掉了，而是它的红利消失的严重——客户开始免疫，平台开始限制，投放开始打不平。

这篇文章把我最近一段时间的思考系统地整理一下，分享给各位。都是真金白银试出来的判断。

# 一、低转高为什么越来越难

先交代一下背景。我们这行做线上大班课，默认的转化模式是什么？三四天公开课拉个群，私域直播哐哐卖课，班主任群里天天发消息。这个模式行业里叫"低转高"，从知识付费到教育，大家都在用。

但这个模式现在有几个明显的问题。

第一，客户被教育出来了。一进群就知道后面要卖课，警惕心起来了。你那套三天公开课的剧本，家长闭着眼都能背。转化率自然一年不如一年。

第二，公域平台在倒逼。以前大家都卖九块九低价课，平台现在不让你这么玩了，开始引导你卖一两百块的课。我们过往几年是卖一个一二百的课，目的就是公域打平投放，私域做利润。现在这个账也算不过来了——打不平，退款率还高。

第三，也是最根本的：大家发现低转高这套打法，本质上是在消耗客户信任。不管你话术多高级，客户心里清楚你前面那三天是为了后面卖课铺垫的。一旦他觉得你在"套路"他，后面所有的真诚都打折扣。

所以我自己现在在验证一个判断：线上大班课的转化，未来一定是往线下那个方向走的——真体验、真交付，而不是纯销转。你把一个一二百的课好好交付一段时间，让用户真的有收获，他自己会来报正价课，而不是你追在他屁股后面卖。

有人会说，这样转化周期不就变长了吗？是的，周期会变长。但另一个事实是：线下体验课的转化率，30%起步很正常，做得到位的能到50%。为什么？因为线下没办法搞私域直播那一套，它只能在体验环节真刀真枪地做服务。这个转化率不是靠话术堆出来的，是靠路径设计出来的。

我也知道这个转向有风险——你把交付做好了，万一没人买单怎么办？我的看法是，没人买单大概率不是交付模式错了，是你以为交付做好了，其实没做好。交付真做好了，延迟转化的整体转化率一定是高的。没有复购，就说明交付有问题，这是个非常朴素的检验标准。

# 二、重新理解学而思和新东方这两条路

讲完我自己的困惑，再讲讲我最近对两家公司的重新认识。

我入行的基因是销售驱动的——跟谁学、高途这条线，追根溯源是新东方出来的打法。但最近我把学而思的模式想明白了一些，越想越觉得，这两条路的不同，可能藏着我们这个行业下一个阶段的答案。

先说结论：新东方和学而思，是两种完全不同的战略和模式。

**新东方是销售驱动的。**偏市场、偏运营、偏销售，各地分校校长不是教学出身，是市场运营出身。它的经典打法是双师：一个城市一个城市地拓，一年就打一个暑假，用十节体验课转化秋季正价班，一个暑假跑出来1400个学生，财务模型就正了。这套打法我太熟了，我们线上做的事，本质上是把这套线下的销售流程搬到了线上直播间里。

**学而思是产品驱动的。**它没有市场团队，没有销售团队（指的是线下业务）。校长全部是教学出身，老师占团队95%。你想下，一个公司老师占95%是什么概念？大多数公司反过来，运营、市场、销售、班主任比老师还多。这个组织结构本身，就说明了它信什么。**（学而思现在的线上团队和高途没啥区别，销售驱动，所以做的也困难）**

学而思进一个新城市怎么打？这个细节我知道之后挺受震撼的：**第一年不开校区。**

它先做"家长帮"。最早是论坛，后来是微信社群。它们是怎么干的？就是做免费服务。发干货资料、升学信息、学习方法，让家长加过来，然后邀请你线下领资料、领书。第一年，它什么课都不卖也不开校区，就是把这个城市最有影响力的家长、最拔尖的学生先搂住。第二年，只收100个学生。第三年，1000个。第四年，10000个。

我称之叫指数型打法。前两年看起来慢得要死，第三年开始爆发。它打的是什么心智？是"这个城市最顶尖的孩子都在我这里"。一个地方城市最拔尖的孩子，用北京最好的老师线上给他上课，哪个本地机构做得到？

张邦鑫有个观点我特别认：**靠销售招来的学生，不会被客户尊敬。**说狠一点，那跟乞讨没区别。说是学而思内部有个专门的学科部，专门用最牛的老师做学科运营、学科营销——拿小内容、小资料、小产品，一步一步把人吸引进来。就像钓鱼，鱼饵放对了，愿意吃的鱼自己会来。**就是用的4ps营销，主打「产品」。**

这让我想明白一件事：**生产资料才是离钱最近的。**你做销售、做运营，其实都离钱远。谁掌握了产品、掌握了教研、掌握了内容，谁就掌握了招生密码。你手里有一个产品，每月能稳定给合作方带来几十个精准客户，你根本不用求着别人付费，别人会来找你。**（说到这里，我觉得杨老师他们团队真牛逼，他们就是这么做的，可能也是因为过往是做线下的，有这块基因，他们目前靠生产资料+视频引流+交付服务，流量没有那么大，但是营业额和利润都很高，这个就是我觉得相对很健康的模型）**

当然，学而思现在个别业务也有跑偏的地方，比如线上的个别直播间开始销售驱动、过度承诺，我觉得是盘大了之后管理的问题。但它线下那套底层逻辑——**产品即营销**——我觉得是经得起时间的。

# 三、转化的本质不是天数，是路径设计

聊完模式，落到执行层面。很多人做线上转化，经常会问一个问题，这个问题我也经常会被问到：体验课到底做3天还是5天还是10天？我目前的看法是，天数是最不重要的。背后真正重要的，**是路径设计**。

我今年在着重接触很多线下老师线下机构。我觉得线上和线下必须要结合一下，哪怕相互学习一下。

线下有一套成熟的打法，我了解到叫**"三次超预期服务 + 三轮推班"**。

拿暑假班举例，十次课期间，要给每个孩子做三轮超预期服务，是针对他的具体痛点做，不是泛泛地问一句"孩子最近怎么样"。比如家长说孩子笔记乱七八糟从来不写，你就在课堂上用康奈尔笔记法带着他写，几次课之后把整整齐齐的笔记发给家长。家长一看：我家孩子之前连笔都不动，现在居然开始写笔记了——这就是一个被设计出来的小闭环。**（这个超预期的设计要针对痛点去做）**

每做完一次超预期服务，紧跟着一次推班。为什么？因为**付费是感性的**。家长刚看到孩子变化、心里正感激你的那个瞬间，情绪是燃着的，这个时候你推课，他的付费意愿最强。你前面没做这个动作，后面再哐哐打电话逼单，那就是在消耗信任。

这背后其实是一条完整的销售流程：开课前诊断探需 → 体验中针对痛点解决 → 让客户真切感受到"我的问题在被解决，未来会变好" → 情绪燃点顺势促单。客户像收麦子，熟一个割一个，没熟的你再做一轮动作。不能一锅端。

线上现在的问题是什么？路径设计全跟着公开课走：促到课、上完课、第二天开始卖。第一次推太早、太重，把那些本来要冒头、还在观望的客户一棒子打死。批量转化没办法做客户分层——成绩好的成绩差的、家长焦虑型学生内驱型，讲的内容都一样。这就是为什么线上转化率看起来比线下低。不是模式不行，是细节和路径根本没做到位。

这里还有一个分层认知。同样是帮孩子，你在哪一层帮，决定了你的产品值多少钱：最顶层是改变思维模式、激发内驱力——这是名师干的事，像张雪峰那种，不需要服务，要的是情绪价值和人格魅力；中间层是激发课堂意愿、给学习方法；最底层是只教知识点，情绪和状态一点给不了。大部分人卡在最底层，却想卖最顶层的价格。这个错配，才是转化难的真正原因。**当然，你的功能性做到足够牛逼足够有效果，也是可以卖高价。（比如我在中秋节前和一月老师深度的聊了下，我才真正明白了为什么她的99到9800转化率能做到50%以上，还是在全程不露脸的情况下，就是有效果！）**

# 四、产品体系里最容易犯的错

最后聊聊产品体系设计，这部分是我自己最近踩坑踩出来的体会。

关单有个经典"三部曲"：为什么买？为什么现在买？为什么买你的？但我觉得在这三步前面，还有一个第0步——**卖什么？**

很多人忙着解决"为什么买我的"（因为我真诚、因为我专业、因为我交付认真），结果把最前面的"我到底在卖什么"给忘了。主线一偏，后面所有的动作都是在给一个错的目标添砖加瓦。

我见过一个很典型的结构问题，这是一个同仁跟我咨询的问题，我发现到他的引流品和正价品不在一条线上。

举个例子，他真正想卖的是1980的赋能教培引流的陪跑课，但他用用一个365的读书共读营做第一次转化承接。读书和教培引流，这两个东西是硬靠的。客户为读书来了，你非要转他教培课，这就像给不需要梳子的和尚卖梳子——你围绕"为什么读书"设计了一堆动作，结果主线跑了。

我给他的建议是：**引流品、正价品必须在一条产品线上，只是价格不同、深度不同。**你可以用一块钱体验，直接转1980。买了1980的人，送他一年365共读作为增值服务——一份钱买两个东西，他觉得超值。没买1980的人，再用365慢慢养。这样路径是直的，反馈是快的，客单价也对得起你付出的一对一沟通成本。

所以这个时候365就是**养护品**的作用。（这个我之前给A梦解答问题的时候有提过这个逻辑，当时一月老师看到后马上调整了下自己的产品体系，把9800的正价品作为主打，把1000多的直播课作为养护，转化没有直接购买9800的家长学生）

这个案例我想表达的是：在关单三部曲前面，别忘了你要卖的到底是什么。如果你的核心产品是解决"教培老师如何引流"这个刚需，那你的引流品就应该围绕「如何引流」来设计，而不是绕到读书、绕到情绪价值上去。读书可以是送给正价客户的增值服务，但它不该是吸引正价客户的入口。

# 写在最后

收尾分享几句认知，跟大家共勉。

第一，战术勤奋救不了战略懒惰。天天在投放、话术、转化细节上卷的同时，也需要停下来想清楚：你的产品到底替客户解决什么问题？4Ps营销里产品排第一，战略上勤奋一点，比战术上忙死累活值钱得多。

第二，生产资料离钱最近。别老想着怎么卖，多想想你手里有没有别人拿不走的东西——教研、内容、案例、客户结果。这些东西扎实了，销售只是顺带的事。（确实是这样的，杨老师团队不是销售性质，是交付性质，利润率超过95%的团队）

第三，真交付是最大的营销。你把一个客户的问题真解决了，他自己会带新客户来。这比任何投放都便宜，也比任何话术都持久。（这个交付是真的要有效）

为什么我最近关注传统教培和线下更多了一些，线下做了二十年的那些老打法，看起来笨，其实每一步都是被时间验证过的。线上平台新、速度快，但如果我们只是把线下那套销售逻辑搬到线上哐哐跑，不回去补产品和体验的课，那这波红利吃完之后，下一波被淘汰的就是我们自己。

另外我前一段发了一个朋友圈，我发k12赛道的商业意识和能力弱，但销售和交付强，我说商业赛道对于人性的研究更擅长，的确是这样，现在多少k12的老师或者机构已经变为商业IP的那些打法和思维了，比如高客单。

只有痛了才知道要改变了。

方向比速度重要，与各位共勉。
