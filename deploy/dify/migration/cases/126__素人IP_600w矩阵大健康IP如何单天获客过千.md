## 03 如何拆分标准化流程、全域矩阵、ip复制

为什么能跨这么多赛道做出IP？很多人说“一个赛道要做精深，别跨赛道”，但我有一套标准化、可复制的做流量流程。

今天我会带大家重新理解抖音，分享批量产出IP的核心方法论——我这套模式的核心 key points 是“素人 IP + 超级表现力 + 全域矩阵 + 经营人群”，这里面有很多不一样的逻辑。

### 1）人群思维

我们和别人最大的区别是：别人经营产品，我们经营人群。

拿减脂赛道举例，我的认知是：永远不要教别人“如何变瘦”，而是告诉他们“今天不减肥会失去什么”“瘦下来能得到什么”。这背后是一套流量逻辑：情感的流量永远大于改变的流量，改变的流量大于变美的流量，变美的流量大于变瘦的流量，变瘦的流量大于运动变瘦的流量。

给大家拆解一下：很多人上来就做“精准内容”，结果发出去只有几个点赞；但爆款账号从不只讲产品，而是讲人群想听的东西。比如减脂，如果你讲“运动变瘦”，只能吸引正在运动减肥的人；讲“变瘦”，能覆盖运动、吃补剂、吃减脂餐等多种需求的人群，流量更大；再往上推，“变美”是变瘦的上层需求——教女生“变美后能得到什么、不变美会失去什么”，选题流量比单纯讲“变瘦”大得多；再往上是“改变”，围绕“想改变的人”做内容，流量大于“变美”；最顶层是“情感”——女性往往因为情感问题才想做出改变，所以讲情感的流量永远最大。

理解了这个逻辑，就知道为什么你的内容没流量：不是内容不行，是选题从一开始就错了。很多人急于卖产品，导致流量端口打不开——你在“卖产品”，而不是“卖人设、经营人群”。只要打准人群痛点，流量不可能低。比如给长江做账号时，他讲情感文案，播放量不会低于 500 万；讲运动变瘦，可能只有 10 万到 18 万播放。所以我们先用情感、女性成长破开流量层级，再输出精准内容，导流效果会好很多。

你看抖音上的大商业博主，他们每天教“怎么做商业”吗？不，他们只展示生活面、分享感兴趣的东西。能做成现象级 IP 的，都是“做什么不讲什么，找到背后的人群，匹配他们关心的话题”。

再看“经营产品”和“经营人群”的区别：很多博主每天教“怎么做减脂餐、怎么掉秤”，这种前端内容现在几乎做不出流量，还容易被模仿抄袭，同质化严重，甚至被封号打压。而“经营人群”是找到想变美变瘦的用户，用 IP 内容建立信任，再做成交。用户反感每天推产品，但如果用选题拉共情、建立信任，成交会很简单。你看那些围绕产品做流量的账号，点赞都是十个八个，就是因为没抓住人群。

不管什么行业，用这套批量产出 IP 的打法，都能切中细分行业的用户人群：先想“这群人想听什么、有什么需求”，围绕需求做内容，就能迅速占据流量端，吃掉整个赛道的红利。

比如卖白酒的，讲男性情感话题——“你老婆不懂你、不理解你”，先占据男性用户心智，再告诉他们“我是卖白酒的，我们是朋友”，成交就很容易。情感账号直接用这套模型，流量自然大；餐饮行业如果每天讲“小餐饮培训能赚多少钱”，用户会疲惫，但如果围绕“小夫妻创业”“负债人群”讲故事，拉共鸣后再推产品，效果完全不同。

现在大家对抖音有没有新理解？“做精准垂直内容”对吗？对，但要看是谁做。素人 IP 不具备行业顶尖的专业内容——你问他 1000 个问题，他未必能都答上来，这时候就该“打人群”，而不是“打精准流量”。

### 2）表现力

太多人因为“每天发什么作品”痛苦焦虑，甚至抑郁。我告诉你们：追求“爆火作品”根本没用。我公司所有 IP，从来不是“今天拍这个脚本、那个段子”，而是先练表现力，再给一套文案框架，让他们能持续输出优质内容。

这就讲到今天的第一个重点：表现力。大家觉得现在做抖音，表现力重要吗？

为什么表现力重要？往三年前推，架个相机读稿都有流量，因为当时内容稀缺。但现在，随便一个人架个相机说“做以下三点，最后一点最重要”，这种内容没流量——因为没表现力。我开头说过，做短视频就三个核心：场景、文案、表现力。你们觉得哪个是不可复制的？

对，是表现力。场景火了，我明天可以翻拍；文案爆了，我可以抄、可以洗；相机、设备这些都能复制。但表现力是“人”的独特性——你的说话感觉、状态，别人永远复制不了。就算知道你的场景、文案，也复制不了你的表现力。

三年前拼文案、拼专业、拼设备、拼场景，现在这些谁解决不了？相机能买，场景能抄，文案能洗，但表现力不行。所以做抖音，只要你是“不可替代的人”，表现力被用户喜欢，再加上爆款文案（抄谁的、洗谁的都行）、好场景（抄谁的、洗谁的都行），IP 就能迅速立起来。天天焦虑没爆款，根本原因就是表现力不好。

今天想和大家探讨一个问题：在抖音这样的线上平台，单从流量角度看，一个行业真正的专家和一个擅长表现的演员，谁更容易做得好？

很多人在线下非常成功，专业能力很强，但一到线上做IP，却发现有些同行明明专业度不如自己，流量却比自己好得多。为什么？核心就在于他们更懂流量，表现力更强，更“像”一个专家。所以，那些做不出流量、出不了爆款的账号，问题往往不在于选题或场景——各行各业的爆款选题、各种场景其实都已经被挖掘得差不多了。真正的关键，在于“表现力”。好的表现力是模仿不来的，当你开始模仿别人的那一刻，你就已经输了，因为你永远成不了第二个他。

我们现在做全平台布局，无论是抖音、快手还是视频号，核心都是“表现力”。你看那些能持续火的IP，无一不是表现力出众，每个人都有自己的特点，说话时都带着极强的分享感。

### 3）持续产出优质内容

接下来我想聊聊“持续产出优质内容”。要做到这一点，前提是建立可拆分的标准化流程。很多人拍视频拍到一半就更新不下去，甚至断更，主要原因就是内容创作过程太痛苦，难以坚持。如果能把这件事拆分成标准化的流程，就会简单很多。

我是怎么拆分的呢？流量 = 优质素材的数量。我们把流量模型进行拆分，对每个板块深入研究、优化机制，然后将其SOP化，用每个确定的模块去生产素材。那么，优质素材又等于什么呢？IP的表现力 + 场景 + 文案 + 拍摄和剪辑，无非就是这四个点。

IP的表现力一旦练出来，场景就很好解决了，因为场景是可以“抄”的——别人在海边拍有流量，我们就去海边；别人在夜市拍效果好，我们就去夜市；别人在专业场所拍受欢迎，我们就去专业场所。

文案这一块非常重要，我的秘诀是用“转发逻辑”来找文案。很多人可能更关注视频的点赞、评论、收藏数据，但我更看重“赞转比”。为什么？因为如果你的文案能让别人愿意转发，就相当于帮你做了裂变，流量自然会好。

大家有没有过这样的经历：别人转发给你的视频，你会不知不觉地看完？当别人转发一个视频时，说明这个内容对他有价值。比如，我看到一个对我女朋友特别有用的文案，我就会转发给她。转发的人，就是你的精准用户。这条文案解决的是精准用户的需求，而不是泛泛的人群。

再比如，一条讲“早起跑步对身体好，不要熬夜”的视频，就很具备转发逻辑。如果我女朋友每天熬夜，我看到这样的视频就会直接转发给她。而她收到后，因为是我转发的，也会更愿意看完，这样就大大提升了我们想要的数据。所以我选文案时，会看它的赞转比，一般来说，赞转比低于6:1，越接近1:1的文案越好。

我把这些都SOP化，落实到工具层面，简单、可复制。能产出多少优质素材，就代表你前端的流量有多大。至于拍摄和剪辑，其实很简单，现在各种剪辑模板、拍摄模板，同行基本都给出了标准答案，直接“抄”就行。所以，唯独“表现力”这一块，是核心中的核心。接下来我会具体讲什么是好的表现力，以及如何提升表现力。我们打造的所有IP，条条作品几十万播放，核心就是靠表现力撑起来的，再加上一些孵化手段调整粉丝画像。

大家看这个IP“长江说减脂”，左边这个视频是他刚开始找我打造时的样子，大家听听（模拟视频内容）：“今天咱们来分享五个高情商的恋爱思维，让咱的感情也可以顺风顺水……” 有没有感觉出来？当时他的场景、服装、妆面先不说，主要是说话夹生、有说教感、显得紧张，这样的视频谁会看呢？

再看调整后的版本（模拟视频内容）：“那女人就应该任性，他妈不喜欢的就扔，胖了就减。喜欢咱就买，没钱就赚，有讨厌的人\*\*直接拉黑，妈的人生这么短，哪有他妈天天时间去悲伤。”

大家觉得这两个视频区别大不大？是不是对“表现力”有点感觉了？第二个视频是不是已经具备爆款的潜质了？

所以，一个视频没有爆款，不是运气不好，也不是不知道内容怎么做，只是差了一个好的表现力。表现力上去了，不可能做不出流量。这和现实生活中一样，你要是老端着，谁愿意跟你交往？放在互联网上也是一个道理。

再看这个案例，调整前（模拟视频内容）：“自己老婆说话难听，但是她真；外面\*\*\*说话是好听，但是她假。很多男的就爱犯什么毛病，他宁可听外面的花言巧语，也不听自己媳妇的肺腑之言，所以这种男的到最后他一事无成活该……” 当时场景、镜头规整度都不错，但就是没流量。

调整后（模拟视频内容）：“你明明晓得跟这个人不得结果，但是你又特别喜欢这个人，你是会选择转身离开？还是享受当下？我听过一个特别有意思的回复，他说啥子叫做结果，结婚是结果吗？结了婚也会离婚，白头到老是结果吗？总有一天其中一个人会先走，所以人和人之间本身就没得那种世俗界定的结果，就是我们这个年纪相爱过，他就是这样……”

这些调整后的视频，在直播间可能看不全，但都是点赞超十万、播放超千万的爆款。其实每条视频的内容都很简单，只要表现力好，有足够强的分享感，别人就愿意看。

还有这个IP“疯狗面前不会因为你是好人”，大家见过吗？他也是短时间迅速起来的，靠的就是表现力，现在已经600多万粉丝了。

再看这个叫“雪哥”的IP，调整前（模拟视频内容）：“瘦到体态轻盈，瘦到锁骨清晰可见，瘦到五官精致，瘦到清爽又干练，瘦到你走路都带风……” 内容就是大家常见的加油打气。我给他换了场景，提升了表现力之后（模拟视频内容）：“一个女人最大的底牌就是不怕失去，我靠人活一世嘛，许愿自己才是头等大事，不满意就换，不喜欢就分，不舒服……” 流量直接就爆了，之前他的视频也就十几个点赞。

看完这些案例，大家对“表现力”是不是有更深的理解了？不是我们做不出流量，而是我们的表现力压根不够格。当表现力提升上来之后，不可能没有流量。看别人的案例很容易明白，“哦，这样就能有流量”，但一看自己，就会困惑“为什么我今天又没流量，又没变现”。其实道理就是这么简单。

做IP最难的永远是从0到1，因为这阶段充满了不确定性，你不知道自己的动作是对是错。我们之前操盘的“常老板”，前两个月只做了几万粉丝，摸索出这套打法后，五个月涨粉500万；“小龙哥”在线下课学完之后，三个月涨粉300万。现在像“藏家小龙哥”这种IP，我们闭着眼睛一个月都能起号。

所以，素人IP + 超级表现力 + 全域矩阵 + 经营人群，这就是我们的思路。大家觉得我们公司真正值钱的是什么？是我，还是团队，还是IP本身？都不是。真正有价值的是这套做号的流程和方法。我能起那么多账号，就是因为在“表现力”这一块，我们的方法不依赖于任何一个团队或个人。真正好的方法论，就是能快速见效且能复制落地的。

我运营项目的整体思路非常清晰，就是“以终为始”，所有动作都奔着结果去。这得益于我在快手操盘过几个头部千万级现象级IP的经验。大家知道快手最流行什么吗？是“剧本”。剧本需要有人来演，我当时做的第一个IP叫“太原老葛”，现在有5000多万粉丝，也算快手的头部了。做那个账号时，我需要策划大量剧本，里面有很多演员。这些演员是在直播中演，不是录好的，以前经常闹笑话。

快手上以前流行卖“传家宝”，比如几万块的翡翠，今天99元卖。为什么那么多人相信？就得益于直播间演员演得极其逼真，演什么像什么。我当时每天要调十多个人的表现力，比如卖传家宝，你得表现出“难过”，是什么样的表情才能让用户觉得你是真的难过？你总不能一边卖一边想着下播数钱开心吧？那样就没人消费了。

正是基于这些经验，我来到抖音后发现，这套方法同样行得通。普通项目操盘手和千万级别项目操盘手的区别，就在于对素材的重复利用效率。

## 02 如何批量产出IP

当 IP 模型确定之后，我开始研究放量。最初，我把单个账号做到了几十万粉丝，但发现单个账号想在短时间内做到几百万粉丝，规模上太难了。后来我换了个思路，开始搞矩阵，用规模效应去放量。对我来说，这件事只需要增加几个拍剪人员就够了。（示意现场照片）大家看，中间那个光头锃亮的就是我。为什么这么做呢？因为拍摄一个 IP、一个账号，可能只需要一个机位。但如果我多架几个机位，就能产出很多矩阵内容。只需要雇月薪 3000 块的拍摄剪辑人员，他就能帮你起一堆账号。

矩阵跑通之后，我开始慢慢给常江增加平台。我发现这套流量模型在全平台都能跑通，尤其是视频号，效果比抖音还猛，近百万粉丝的账号就有好几个。长江的这些账号，11 张图都放不下，加起来数量特别多。大家可以看到，无论是快手、抖音还是视频号，这套模型全都行得通，80 多万、十几万、20 多万、50 多万粉丝的账号有一堆。

接下来一定是全域的流量红利，不要只做小红书、抖音或视频号，要全都做，用一条作品吃遍全域的流量。以上就是批量产出 IP 的核心方法：硬生生把打造 IP 这个非标品变成了标准化的流程，摆脱对人的依赖，用三流的人才创造一流的业绩。

这句话怎么理解？相当于我只需要把一个 IP 的表现力调出来之后，剩下的都是工具人，用流程去做事。一个 IP 只要表现力没问题，我不断给你文案，你去获客。我这边则不断增加账号，然后增加平台，把 IP 只看作一个生产流量的工具，剩下的拍剪人员也是工具。这样就能标准化、可复制了。你想想，一个月薪 3000 块的拍剪人员，来了之后，他都有可能做出一个几十万甚至上百万粉丝的账号，大家能理解吧？

做矩阵是不是拍一条视频多个角度可以出多条视频？是的，还可以混剪。我们一晚上，比如说拍 10 条视频，大概一个小时，就能剪出 600 多条视频。也就是说，我们一个小时的产值是 600 条视频。600 条视频，用的都是月薪 3000 块的剪辑，你们想一想，这样的概率，出爆款的几率也是很大的。

以上就是我批量产出 IP 的核心方法论。

## 03 私域：大健康品类的变现核心

接下来带大家看一下我们是怎么变现的，那一定是做私域。大健康品类，想都不用想，闭眼做。账号和粉丝是平台的，只有私域是自己的。大健康私域的核心在于服务。

大家看，私域核心是服务，还有情绪价值。像这种几千人的账号，我们有十几个，不止十几个，有 20 几个。小龙哥那些账号，每个都能搞不少钱，对，这些都是长江的一些私域，大家可以看一下。

因为这次比较急，做 PPT 的时候没把所有都截下来，随便截了几个给大家放一下。这是我们现在导流的一个情况，隐藏的群还有好多，基本上群里都有人，还有很多。右边是一个变现的情况，中间这些是我们平常做微商从公域导流到私域，再转化成代理的流程，这个点我就不展开讲了。

项目操盘手不仅要关注素材的重复利用率，还要关注对流量的变现利用效率。接下来这几个点也很重要，它们会开拓大家很多新的想法。

以前的商业模型是由原先的微商项目产品决定的，只需要流量漏斗最下面那部分有明确需求的人群。但前端流量漏斗上面还有大部分流量其实没有被利用开发。如果把这部分流量利用起来，项目的体量必然会再上一个层级，大家这样理解吗？

比如说，我做出来 600 万粉丝，可能只有几十万是有减脂需求的，这几十万下面可能有几万人能成为代理或者想成为代理。那么我上面未利用的流量还很多，因为那帮人也是想要成长、想要改变的。我可能只用了 600 万粉丝用户的十分之一，因为我把精准用户筛选出来了。

这里边我有一个理论：没有一个流量是泛粉，只有你的变现与之匹配不匹配。

我给大家讲一个案例。很多人觉得涨了一堆 50 岁以上的老头儿老太太粉丝是泛粉，最没用。但这些粉丝给到卖保健品的人，就是精准粉丝。按照这个理论，没有一个粉是泛粉，只是你的变现与之匹配不匹配。

我给大家看一下这个视频：“女人就是情商、口才、懂博弈真的很重要，就是懂博弈的女人最幸福。这本书真的推荐你们所有人都要买一买，你就认真去看它里边的那些……” 这是我们带货卖书的。大家可能觉得卖书赚不了什么钱，我刚开始也是这么理解的。但当我做完数据调研，以及了解到几个朋友在做这个的利润后，我都震惊了，真的震惊了。大家千万不要觉得有些项目很 low，往往越是看似 low 的项目越挣钱。于是我转过年就开始给 IP 前端的流量加上带货板块，在原本项目不变的基础上，把流量效率提高了一半。

大家可以看右边的那张图，这是我们一天的变现数据：一天的营业额是 3 万 7003 元，利润是 1 万 8006 元。大家可以想一想，这个行业的利润有多大？

做完这个事之后，我还觉得有很多流量没有被利用，于是又开了无人情感录播。注意，是录播，不是直播。你看，这么多账号同时在“直播”，其实我们只需要录一个素材，然后放那儿一直开录播，导入私域做变现。

这是我们录播的数据，也不知道怎么回事，截图还截了两个，左边那个图是 1000 多人在线，右边那个是 500 多人在线，这些都是录播，场景只是换了身衣服而已。

我讲这些，就是想告诉大家：没有一个流量是泛粉，只是你的变现与之匹配不匹配。很多人能做出流量来，但一定要拓展更多的变现思路，不然那些流量就真的全浪费了。

## 04 总结

很多人说做 IP 不能复制，变现只有一种方式，其实都不是的。大家一定要开阔自己的想法，把自己理解为一个做互联网的——什么赚钱，我就搞什么，不要一成不变。你看，从去年我开始搞减脂，今年在减脂基本盘不变的情况下，又加了带货。带货跑稳定之后，我又跑录播，这些都是不需要太多额外投入的。你们去看一下那些头部的商业博主，他们都已经给出答案了。

有很多项目、业务是可以随便跑的，只需要记住一个点：只要咱们做出流量来，别把自己定义死——我是做什么的？什么赚钱就搞什么！太浪费了，很多人都浪费了很多流量。其实你们可以思考一下，在你的业务链条上，有没有上游或者下游比你更赚钱的？而你只是卡在中间，上不来下不去，比较难受。

这是我复制的 IP，这些都是我公司做出来的。不管你是 IP 还是操盘手，一定要掌握一套可以批量产出 IP 的流量模型和素材库。有的人把自己定义死了，比如在某个领域做 IP，5 万粉丝就是极限。那你能不能再找一个人，帮他也做一个 IP？把你做 5 万粉丝的能力复制一遍，重新走一遍流程，又一个 IP 就起来了。

你要想把 5 万粉丝提升到 50 万，那就去放矩阵。有的时候不要死磕单个账号，“我 5 万粉丝不行，我得做到 100 万”，做 100 万粉丝老难了。但是你要是向下复制，或者在你现有基础上平行复制，会很简单。

大家听这个文案：

“女人就应该任性，不喜欢就扔，胖了咱就减，喜欢就买，没钱咱就赚。讨厌的人直接拉黑，人生就这么短，哪有这么多时间天天去悲伤。”

是不是发现都差不多？我们用一个爆款文案，会一直复制，一直复制到没有流量为止。当有了这套标准的模型和素材库之后，就可以切同一个人群下的不同细分赛道。我用这个方法起了账号，起完账号之后，再去切不同的细分赛道。

IP 流量生意的终局，一定是细分垂直的 MCN 机构加上私域，才能带你穿越周期。这个点就是说，你相当于做成了一个……不管你是操盘手也好，还是 IP 也好，当你做成 IP 之后，你一定想的是怎么样能签更多的 IP，或者做更多的 IP。如果你是操盘手，也要有这样的思路，这样才能带你穿越周期。

我做互联网做了七年，有一个下意识的思考习惯：每一个 IP 都是有周期的。大家不要觉得做一个 IP 就能一劳永逸。当你在巅峰的时候，一定要想着签更多的 IP 进来，做这个细分领域，这样才能带你穿越周期。
