## 01 定位：挖掘垂直赛道的隐形需求

首先，我是如何挖掘到我们这个垂直赛道的隐形需求的呢？

一开始创业肯定还是需要先确定做什么产品。当时的市场情况是，大多数机构是在提供相对比较标准化的产品，但是我们会发现有一个人群是被忽略的——比如我们参加考研复试，初试分很低的人或者很多跨考生，这部分人群的付费意向是很强烈的，但是他们的一些隐形需求没有得到满足。所以我们就可以跟资本进行一定的错位竞争，去分析隐形需求背后的原因。

像这种初试低分，希望靠复试逆袭，但专业课很差的人，他需要的是什么呢？

因为他们基础太差了，而且需要在短期内准备复试，所以他们背书背得很困难，学得很困难，并且面试的时候，他们很难像学了四年的同学那样有更多内容输出。没有内容、没有亮点的话，他们复试就很难拿到高分，这是他们背后的需求。

我们需要把需求具象化，怎么样能够让他们面试有亮点，拿高分呢？

我们提出了一个方法，叫做“财经案例复试法”。简单来理解，就是将我们的专业知识和经典的、热门的财经案例结合起来学习。这些案例大多是耳熟能详的公司，跨考生也很好理解，就算面试的时候忘词儿也能答上举例子，也可以保证一个基础的分数。

我们的详情页里面展现了怎么去进行具象化：首先我会举一个例子，然后展示普通学生照本宣科是怎么回答的；以及如何用案例的方式去回答，这样既答出了书本的知识，又拓展了案例，内容更充实，你就可以在面试中拿到更高的分数。

基于目标人群的隐形需求，我们觉得这套财经案例复式法是有市场空间的，接下来就来到了第二个部分，也是我们破局的关键，名师 IP 矩阵的打造。

## 02 破局：名师IP矩阵的差异化打造

在破局阶段，我们结合“财经案例复试法”打造了自己的小红书名师 IP 矩阵，以及相关的财经案例书籍，对我们的课程进行了升级，同时也通过私域快速裂变获取流量。

下面来具体聊一下怎么打造名师 IP 。

我觉得一个很重要的点是， IP 必须贯彻跟产品一致的理念，或者说 IP 就是产品。从这个角度来说，如果一个老师一开始没有什么名气，是不建议追求“全能”的，只能追求板块第一。例如刚刚提到的财经案例复试法，我只需要大家想到这个方法的时候能想到我们的老师，觉得我们老师就是第一位的，这个老师就容易被人记住并认可。

这个过程中我遇到的第一个问题是，用图文还是视频形式？

很多时候我们打造 IP 人设都是用视频露脸、刷脸，增强记忆点。但其实对一个经验不太足的老师来说，他的镜头感是比较差的，我们制作视频的成本也比较高，这样我们其实做出来的视频，质量难达到很高的标准，也很难去产生爆点，这是我们测试之后发现的困难。

所以我们发现做图文或许更有优势，因为图文能够传达相关产品理念，并且产出快、制作成本低，而且我们本来就有一些研究生兼职可以供稿。

具体起号打法上，我们用了封面起号法。做小红书的小伙伴，应该有听过这个方法，像最近比较火的女生独立计划之类的号，就是运用了这种方法。其实就是把封面做得非常吸引人，让人一看就知道是一个系列的内容。

我们希望在封面上就融入财经案例、复试押题、复试常考这些点，从而圈定我的细分人群，比如我会标明这个就是商科类考研。我们每一期的封面大概都是这样的样式，方便后续快速产出。这其实也是一个记忆点，至少我记住了这位博主的特色就是做财经案例。

财经案例其实对我们的传播非常有利，每当有新的财经事件的时候，我们都可以快速跟进“蹭上热点”，也可以直接验证我们的财经案例复式法，比如之前的恒大跟普华永道事件。在封面下面可以附上我们名师的实体书链接，后面我也会跟大家分享为什么我们要去做实体书，而不是简单的引流资料。

我们在起号的时候用了赛马机制，同时做了几个版本，但基本上都是宣扬财经案例理念的图文。比如上图这两个还不错的号就继续沿用了。左边就是以财经热点的形式去展现，右边就是教你“怎么把财经案例融入答题”，让你直观感受到案例复试法可以拿到更高的分数。

当然封面起号法可能会涨粉快，但变现很难。我的解决方式是增加更多个人元素，让这个号更加像是一个真人老师。比如用真人头像，后面我们也给他打造了一个独家动漫 IP 形象，并且我们在简介以及置顶笔记里面也会突出一些个人介绍以及成就。而且我们变现是用另一个号来承担的，所以变现难这个问题就被解决了。

在小红书上打造了爆款账号之后，我们还做了一件事——出财经案例的书籍和课程。（相比复式班）实体书的门槛比较低，我们现在销量还可以，有挺多人直接买这个。

我们为什么要去做这样一本实体书籍，而不是单纯做引流资料呢？我们是这样思考的：

首先一个新老师是没有什么知名度的，通过实体书可以让名师人设更加有价值沉淀；

其次做一本书的话，后来者比较难抄袭。前面提到了，我希望一提到财经案例，大家就想到我们这位老师，所以一定要把自己的门槛提高。我们打造出爆款之后，其实有挺多抄袭者，但是都没有办法去超越我们，因为实体书的制作难度还是有点大的。

另外，我们是把试读版的 PDF 作为引流品到处分发的。我觉得试读 PDF 这种电子版资料其实比免费公开课的门槛会更低一点，尤其是一个老师知名度还没有打开的时候，学生更愿意看一下你的书或者领一份资料；一个课程至少需要花几分钟时间去听，学生可能也会觉得麻烦，不太利于我们的理念传播；而实体书的话，即使没有报你的班，他也会很愿意要一本，我们用它搞一些私域裂变，效果是很好的。

基于以上这些原因，我们去做了低价版的实体书籍。大家也可以看到我们的目录，我们会尽量把目录跟前言部分写得很有趣，以此显示我们一本书的语言都是比较生动活泼的，跟那种严肃的专业书籍相比，它的可读性非常高，也就是刻意把它定义为考研的浅读物。

这样他们拿到了试读版PDF 后，首先会认可我们的理念；其次对他的吸引力也很高；并且，我们会在书中埋藏一些复试押题，但是没有答案，答案会和我们配套的财经案例课程、高价复试班捆绑售卖。

打造完书籍和课程之后，就需要快速的传播了。

我们大概在 8- 10 月进行（小红书）起号和引流；之后就开始进行私域的快速裂变，将实体书籍发售出去，进行预热种草，这个时候刚好也是他们考前的焦虑期，会到处看各种东西；然后就到了他们考完之后考虑报复试班的期间，大概就是 12 到 1 月份，我们将书籍发货，并且弄一些打卡活动、铺一些密集种草帖，这个期间就会产生比较好的爆发效果。

## 03 迭代：学员深度种草自循环体系

接下来分享跟名师 IP 有关系的学员深度种草循环体系。

首先给大家看一下我们小红书矩阵号的功能。

前面讲到了我们有一些名师账号，主号是为了宣扬核心理念，小号就是宣扬次核心理念。因为当时起号的时候就测试过这两个版本，跑得都还可以，我就继续把它保留下来了。我觉得有实力的小伙伴也可以继续多做几个号去分发。当名师有了一些名气之后，可以弄一个生活号，打造他的立体人设，比如去玩一些梗，或者拍一些视频，这也是我目前在摸索的事情。总而言之，名师账号主要承担提升大家对理念的认知功能。

接下来就是种草和购买。关于种草，后面我也会跟大家分享我们如何跟学员进行共创做种草。我定义的种草可能包括：

第一，有人设的深度种草，例如说上岸学长学姐、正在备考的学生这种深度种草帖子；

第二，在高频曝光阶段需要去铺的帖子，例如我刚好有产品发售，或者有活动需要推，我们可以快速地找一些号去发。

第三，我们还会合作一些 KOL 和 KOC。因为我们这个垂直领域还是比较小的，没有特别大的博主，所以我们这边一般把 KOC 定义为正在备考的博主， KOL 定义为已经上岸的学长、学姐，可以让他们去进行一些深度共创。

机构的官号我觉得也是非常重要的。我们将它跟名师账号进行关联，负责开店铺，接一些销售咨询以及引流到私域。刚刚提到封面起号法可能会面临变现难的问题，可以用这个来解决。我们用这样的矩阵号去完成在小红书上的动作，并且我们也会把小红书作为内容输出的起点，将内容分发到其他的平台。

下面聊一下我们是如何进行“老用户”长期价值维护的。毕竟你想要让学员进行深度共创，最重要的还是互动，以及长期价值维护。我们针对学长学姐和学员有不同的措施，标蓝的院校合伙人制度是我们比较特殊的地方，后面跟大家详细展开说。

之所以要去做长期价值维护，是因为我们的考生其实都是小红书重度用户了，他们很聪明，很懂打广告的套路，所以我们要用真实的学长、学姐的号去发，这样子可信度高一些。因此在做这些内容的时候，我们也会刻意营造一种素人的感觉；做社群、做内容，我们也会尽量淡薄机构感。

某种程度上说，现在的学生对机构好感没有那么高，所以不管是简介，还是其他什么地方，我们都尽量改造得真实，告诉大家我们是可以一起打怪升级的，可以为你提供情绪价值。同时我们也会针对不同的群体开展一些公益活动，邀请一些优质的、正在备考的博主参加一些产品体验官活动。

下面就跟大家分享一下我们院校合伙人制度是怎么做的？

我们做这个首先是为我们的产品服务，就是刚才提到的院校班产品；其次是为我们的内容服务，因为他们输出的内容更可信、更有深度，产出量也更大，而且这一部分人其实有一定的自发性，某种程度上是可以自循环的，可以进行比较好的传播。

简单来说，院校合伙人制度就是邀请了 100 多家院校的上岸学长、学姐组成 100 个不同的项目小分队，然后他们要针对他们的学校进行重要种草资料的筹备、社群运营和授课服务等。

我们主要是用基础报酬加分成激励的方式，让他们快速形成宣传号召力。这样我们把院校名单放出来后，大家就可以看到我们这个机构基本上覆盖全部院校，复试班很有针对性，并且我们还会邀请这些学长、学姐来开分享会。

院校合伙人除了在我们的名师团队承担一部分专业课，在保证整体质量的基础上，我们还会再邀请他们上四节小班课，主要是为了满足学生针对自己报考院校的需求，比如梳理复试流程，讲复试真题。

那我们是怎么招募？怎么激励？怎么管理的呢？

首先我们基本上没有公开招募，因为对于还没有上岸的学生来说，这件事情还是有点敏感的。所以我们就是直接从上岸学员中招募，或者从公私域里挖人，主动私聊招募。聊的时候，我们会明确地用较高的课时费作为吸引，因为刚开始你跟他说有项目提成，他可能觉得是骗人的。而且我们发现有很多机构可能会用比较冷漠的、寻找兼职的态度去聊，其实研究生们还是有一点傲气的，最好就是夸夸他，问他要不要合作，以一种比较平等的姿态去聊。

在做激励的时候，我们是把各个环节明确列出来，给他单独的报酬，采用现结的方式，这样他们会更有及时激励的感觉，也会更乐意去干。当然，我们前期会先约“经验帖”、“收集真题”，看看他的积极程度，然后再决定要不要跟他签院校合伙人。并且我们会把他拉到群里面，院校合伙人之间可以互相交朋友，互相发帖子、互相评论，这其实也是蛮有利的。

关于院校合伙人制度，我觉得很重要的一个点就是标准化。因为人数较多，沟通工作比较大，所以不管是私聊话术，还是分享 PPT 、真题，甚至经验帖都可以进行一定程度的标准化。我们要先完成再完美，起码要保证他们能达到 60 分的状态。

此外，我们要给很明确的DDL，定期去 push 他们。在这个过程中还需要注意抓大放小，比如经验贴和真题是最重要的宣传手段，也是最基础的要求。即使不跟他们签院校合伙人也没有关系，他把帖子写了，然后我给他一些基础的报酬也可以。对于热门院校，我们可以多花心思去打磨他的内容，这样招生的时候就比较有利。

我们会弄一个共享表格，运营主要负责沟通、管理以及定期 push 院校合伙人；教务负责课时统计；客服主要承担社群运营的协助管理。客服也会拉一些群，院校合伙人可以在群里面跟学生进行沟通，这样建立初步的信任后，学生才会考虑报班。

不管是我们从私域里面挖掘 KOC、KOL，还是我们的院校合伙人，其实都可以给到我们内容种草方面的支持。

院校合伙人可以打造某某学校上岸的人设，做一些深度人设种草，帮我们把一些关键词抢下来。像学校下面的精准关键词，他们可以很容易抓到；而且他们的上岸经验帖也是一个很强的背书。我们也可以从院校合伙人里面找一些本来就比较擅长写帖子的兼职，邀请他写铺量的种草帖。在关键时间点将小红书热梗与自己的产品结合起来，去产一些爆文。

除此之外还有控评作用。现在小红书上有很多“大家报班了没有，报什么班”这种提问，这个时候评论区维护是非常重要的。刚刚提到了院校合伙人是有群的，同时他们又是有深度人设的账号，那他们去帮我回复这些评论，可以让学生觉得真实性很高，达到一个比较好的宣传效果。

这一部分就是我们简单的种草打法，其实只要我们把长期价值维护好，跟院校合伙人的关系维护好，并且有激励制度，他们会有挺强的自发性。比如我们群里面有些小伙伴刷到了一些推荐贴，他主动地回复评论，我们就可以进行红包奖励，其他人看到之后也会继续去做。

这里分享一下大家可能会感兴趣的内容：

第一个问题是怎么做 KOC 和 KOL 的挖掘。一方面是通过我们自己的私域力量，以及在上岸的院校合伙人里面挖掘；另一方面我们也会定期去留意小红书上面我们这个领域、最近比较火的博主，聊了之后，把ta登记下来约合作。在垂直领域里，这种自然的 KOC、 KOL 某种程度上来说是比较稀缺的资源，如果你不跟他合作，他可能就跟其他的机构合作了，所以我们还是比较注重这方面的管理的；

第二个问题是铺量种草关键节点是什么？怎么做控评？我认为关键节点就是有比较重大的活动或者产品发布的高峰期。以及根据学生在不同阶段的感兴趣内容来做针对性的内容，比如说冲刺期，他喜欢看押题，这个时候你做押题相关的铺量种草，效果是比较好的。

怎么做控评的话，前面也提了。假如我或者别人刷到了相关帖子，可以让一些有深度人设的小伙伴帮忙回复。有红包激励的话，他们其实还是比较乐意的。

第三个问题是种草之后，流量怎么收割？前面我们提到了许多经验帖发完之后，学生可能会去私聊问学长、学姐怎么报班。我们就会用学长、学姐优惠暗号的形式解决，比如报学长、学姐暗号，我们会另外给几十块钱优惠。这样的话，学生会愿意报暗号购买，我们这边也可以核查到是哪一位合伙人的，可以给他加个小鸡腿。博主业绩追踪跟这个差不多。

最后一个问题是怎么防止学长、学姐自己搞线索做？我觉得这个问题也是很重要的，因为我们机构现在面临的一个问题就是很多学长、学姐自己带班，自己接单。

其实我们在产品层面上已经做了一些解决，我们的院校合伙人只需要上四节小班课，并且我们的课时费是比较高的，可能跟他自己私下带课所赚的钱差不多。但是我们这边不是让他去上专业课，是上他们院校的流程，讲真题，讲他们学校考什么题型，老师什么偏好，所以他们准备起来是很简单的。此外，我们这边还有配套课程、答疑书籍这些保质保量的服务。学长学姐会觉得，我在这里赚的钱和自己做也差不多，而且省时省力，还给我项目提成，会有一种确实是合伙人的感觉。

为什么要这样设置？因为有挺多机构会直接对接某个学校学长、学姐，让他们帮上 10 节课、20 节课，课时费压得很低，要上的课程很多，并且没有标准化的产品。这样其实产品质量不高，双方都觉得挺亏的，学长、学姐们就不是很乐意做。

我们是从产品层面上避免这个问题，我们还提供了很多额外的服务，比如告诉他经验帖大概怎么做，我也会帮他去做社群运营以及简单的销售沟通，提供各种书籍。

除了以上细节问题的解决，我们在做的时候发现最好的管理其实就是激发群体性善意。我们有超过500人的学长、学姐兼职储备，我们希望他们每个人都可以做我们潜在种草官。

## 04 展望：教培机构的MCN化趋势

我分享的内容大概就是这些，还有一个想跟大家一起探讨的问题。

我觉得现在教培机构好像有一种 MCN 化的趋势，特别是像我们这种比较偏名师工作室的，孵化自己的名师 IP，可能是未来生存下来的重要立足点。没有自己的名师，那你可能要合作名师，这样不管是价格、还是产品的自由度都会受到一些限制，这还是比较卡脖子的。

我自己的工作中也接触过一些名师，或者说其他机构的负责人。我们发现这两三年，比较有名的老师都是新生代的，哪怕是考研这种很需要沉淀的赛道，都可以出来新老师。因此，运营思维对老师来说还是蛮重要的，不管是打造产品，还是做自媒体的维护。

比如前面我们讲到有的名师可能小有名气，但还是二三线的状态，因为他其实没有找到自己在细分点上的第一。没有哪个老师是非常全能的，全能是很难被人记住的。但做出一个比较爆款的课程或产品是很重要的，对现在考研的学生来说，他们深知英语的写作会看哪个老师，阅读要看哪个老师。在某个版块里面找到自己的准确定位，对于老师来说是非常重要的点。

以上就是我今天的分享，下面看一下大家的疑问。挺多都是教育行业的运营小伙伴，我们可以进行简单的沟通交流。

## Q&A

Q：一个笔记多少钱？

A：其实我们有不同的标准，可能得看他自己的号大概是什么状态，以及他是我们的院校合伙人还是外面找的。一般来说外部合作的价格比较高一点，但是其实我们这个行业的笔记没有很贵，可能就一两百块钱，两三百块钱，爆文大概可以给到 500 或者 1, 000 这样。

Q：课程销售会交给学长学姐做吗？

A：大部分的销售还是由我们来承担，但他们在社交平台上的推荐对销售非常有用。我们会跟他们讲，你在一个学校里面招五个人跟招两个人，拿到的钱肯定不一样，所以他们其实也会愿意跟一些学生聊。当然肯定没有办法保证每一个学长、学姐都非常主动，这个时候我们的销售也会主抓一些比较热门的、招生人数比较多的学校去进行销售。前面我们提到我们会邀请学长、学姐开分享会，我也会挑比较优质的学校，这些学长比较好沟通。分享会其实也是可以带货的，分享完了说一下我们复试班哪里好，怎么样，这个还是不错的。

Q：全国班和院校班是分开卖还是绑定一起卖？

A：其实它是两个不同的班型，是分开卖的。院校班包含了所有全国班的内容，再匹配上学长、学姐的部分，全国班就只有我们名师的部分，学生其实是可以选择的。而且全国班有一个优势，就是万一这个学校我们没有学长、学姐，或者是今年刚开始招生的学校，没有学长、学姐的，学生可以上全国班。不过我们 100 多家院校其实已经很覆盖了，全国也就大概 200 所，当然有很多很冷门的院校。

Q：中高考辅导的目标群体，在小红书上有市场吗？

A：您这边的产品主要是怎样的？是不是家长买单的？家长买单的话可能在小红书上没有这么多。其实现在小红书用户也很年轻，像这种中高考的学生，他们也会刷小红书，但是他们可能没有那么多支付能力，我觉得还是要影响他们的家长。

Q：你们初试和复试都做吧？

A：对，我们初试主要是做服务类的产品，像批改、督学这种的，课程产品的话，我们目前也是合作形式。因为初试实在太卷了，我们没有像复试那么细分地去做。

Q：初试课单价高吗？

A：初试客单价不太高。我们复试班的定价大概是 5, 000- 7, 000。协议班的话就贵一点，大概可八九千、一万左右。初试单价就比较低了，大概就是几百块钱不到一千，当然我们也有全套的课程，也有几千上万的，但是这个销量没有那么高。

Q：现在很多学生都是看几十元的盗版课程，这个怎么看待？

A：这个确实存在。但是复试班其实还是挺刚需的，他们一方面很需要院校合伙人，因为学长、学姐的话每一年都会更新今年考察什么真题、什么流程；而且他们通过初试了就会担心复试被刷，尤其是分数不太高的同学，所以他们愿意去购买复试课程。我们的班也不只是上课这么简单，还提供专业课的答疑，模拟面试服务，这种都是他们比较需要的。而且复试班没有那么容易去搞盗版，这也是我们觉得初试比较难做的原因。因为考研初试，特别是像我们会计的管理联考基本上属于公共课，盗版非常泛滥的。

Q：在精力有限的情况下如何运营？

A：这个确实也是我刚开始面临的问题，我觉得最重要的是抓住一个渠道。一开始做的时候，运营就我一个人，你包括现在，我精力也是有限的，而且我不希望把团队一下子扩得太大。这个时候我们就选择 all in 到小红书，你可以分析一下目标群体主要是在哪个地方，并且哪里有红利。像小红书的话， 22- 23 年还没有那么商业化，还是有挺多免费流量可以薅的，起号也是挺快的。那就可以先抓小红书，然后其他平台可以做分发。分发的话，我觉得很重要的就是进行标准化，比如标准化排版、标准化封面什么的。你可以请一些学生兼职去帮你做简单的动作。其实后面这个阶段，我也没有一开始就去招正职的运营，也是用实习生撑起来的。

Q：有些老师已经在抖音运营，如果小红书也一起推广的话有哪些坑？

A：我这边没有太多去做抖音，因为抖音的群体对我说来说没有这么精准，而且我精力有限，抖音还是需要花费一些成本的，视频输出对我们来说成本比较高，所以我还是先放弃。

Q：职业技能考证如何做小红书？

A：我觉得这个问题可能稍微的有一点泛。这位提问的小伙伴，你们考证主要是什么名师课程代销还是自己的？是否也可以考虑名师 IP 的路径去做？我发现现在有挺多考证的号，包括我们考研初试也是这样，可能是代销某些名师课程。我们初试阶段其实也做过这种名师课的代销，虽然我是代销，但是我希望我的品牌可以更好地贯彻理念，我会搭配一些我的周边，或者答疑、其他服务类的产品进行售卖，这样的话我品牌更加容易被大家记住。其实也可以采用我们前面讲到的铺量种草和深度人设种草，种草这个东西在我们教育领域里还是非常重要的。精力有限的情况下，学生肯定是先看一下别人在看什么东西，然后也会跟着去看，所以种草是得去做的。我不知道您的单价是怎么样，如果单价比较高的话，也可以考虑引入私域里，我们也是这样子，转化路径较长。

Q：考研复试班，出成绩前，学生报名多吗？还是基本都是出成绩后再报名复试？

A：其实还可以，因为他们会估分，基本上一半报名吧。出成绩之后，我们会出冲刺班型，还有什么“海底捞”、“救命班”这种，让学生觉得可以被捞。其实我们的群体基本上都是那种想要靠复试逆袭的，如果你这边可以给他内容，他还是比较乐意报这个班的。另外在出成绩前，我们进行产品设计的时候就想到他们担心过不了初试，会给他比较高的退费机制，比如他没过，我给他退70%，这样他觉得花的钱不会很多，会乐意先报。

Q：团队的构成包括几个运营、几个销售？

A：我现在是三个正职运营，销售目前有两个。其实我们还是比较乐意用研究生兼职的，销售其实也可以用研究生兼职来承担。他们本来就很了解这个产品，或者是报过我们的班，我们可以一代一代地传下去。

Q：目前报名的发起者，是学生为主，还是父母？

A：父母也有一些，但大部分都是学生。这些学生有个特点，他初试不一定报了班，或者没有花特别多钱，但复试愿意报班，因为他觉得已经那么辛苦地过了初试了，万一复试被刷了怎么办？所以他其实还是比较乐意的报班的。

Q：怎么去构建合伙人制度的权责利？

A：他们毕竟是兼职，所以责任这一方面，我们是靠对接人定期地去设定一些任务，定期 push 他，提醒他该做什么事情；然后“利”的话其实就以积极程度去判断了。我们通过他们的积极度去判定是否要给他项目提成，前期像经验帖、做真题、提供真题其实是比较简单，我可以通过这些去检验他的积极程度怎么样。当然我们这边目前给的激励其实也是行业内比较高的，钱到位了，他们才会比较乐意去做。每个学校多招人，我的边际成本就低，激励多给一点是 OK 的。我们是一个合作关系，就比如说经验帖，他可能没有像我们这种运营思维去写，那么我们去帮他修改，稍微指导一下排版大概怎么排，标题怎么起，标签怎么加，可以让他觉得你们机构也是带给我一些东西，我们是来合作的。做院校合伙人还是需要一点时间去筹备的，比如 12 月份是我的爆发期，可能 9、10月的时候就要开始招募，并且开始做了。

Q：学生提供的真题是初试真题还是复试真题呢？

A：真题是复试的，就是他们学校的，这个东西是很刚需的，因为每个学校考的都不一样。初试真题是全国统一的，所以就不需要了。

Q：从一个校园到 n 个校园最大的挑战是什么？

A：院校合伙人制度其实是需要一定时间去沟通、去寻找的，或者说我们也是进行了一定的积累。一开始的话，我们先从广东地区开，到后面的话就从北京地区扩展起来了。如果跟他们维持比较良好的关系的话，我们可以了解到更多学生的情况，并把他们拉拢过来。一开始肯定会面临信任问题，他们会觉得你这个项目分成是不是真的，一般合作模式都是直接给钱。我们这其实就是先从一个区域进行试点，因为我自己本身就是这个专业的研究生，所以我可以先发动一些自己身边的资源。

Q：往届学生和外部学生的比例是多少？

A：往届学生可能一半。我们的院校合伙人，只要跟我们合作得好，他第二年是可以继续做的。因为他在这个学校，已然了解学校流程，并且有经验了，只是说可能没有当年考察的真题。但他只要愿意做，他就会去找考过的学弟、学妹或者带过的学生问真题。刚开始跟你建立信任后，后面其实就 OK 了。

Q：怎么去看一个人能否被打造为名师？

A：这个问题确实是需要机缘和判断的。如果我现在孵化一个新生代的老师，他大概有什么特征？第一个就是专业方面没有太大问题，而且它最好在某个版块里面有一点自己的理念，能够拿出来打造的东西。因为现在不管是考研、考公，它基本上都是某个方法下哪个老师讲得好；第二个就是看他是否有一些能够被你放大的个人差异点，因为我们这个专业女生比较多，我自己感觉长的比较帅的年轻男老师，再加上专业知识 OK 的话，其实还是比较容易立起来的。他可能擅长玩一些梗，是一个比较搞笑可爱的人设，有一些记忆点。现在挺多老师，特别是那种传统的、有资历的老师，他们可能会有一些距离感，我们可以给他打造一些比较接地气的点。除了自身的点，我们给他做种草也是非常重要的。我觉得现在考研圈有点像小粉圈似的，给学生洗脑，这个老师就是很牛，很多人都说他很牛，那他们也会相信他很牛了。

Q：会把合作的上岸学长学姐打造成院校IP吗？

A：这个确实是我在思考的点，但是目前会面临一个困难，因为他们都是在读的学生，如果去给他打造一个 IP ，一方面是隐私的泄露，另一方面就是顾虑学校要求不要去做考研辅导。但是我也很想去尝试的，后面可以考虑打造已经毕业的学生的 IP，当然我们也会从里面挖掘比较优秀的，跟我们自己的产品进行捆绑，围绕着他们去做一些产品的挖掘。就像刚刚提到的，现在考研机构或者说教培机构其实有一种 MCN 化趋势，孵化名师 IP 可能是未来机构的生存要领。上岸学长、学姐 IP 也是孵化的一部分，还是挺有空间尝试的。

并且我发现挺多比较大的机构也会去签一些比较优秀的博主来帮他们去代课。我们之前会找一些做得比较好的备考博主，把我们的产品用免费或者低价形式跟他签约。让他帮我做一些打卡，我这边提供一些更加私人化的答疑、批改服务。这样的话也可以影响到我们学生的购买，它其实跟单纯的约稿是不太一样的，它是合作形式有种代言人的感觉。

Q：封面起号法，有什么需要注意的地方和“防止限流”的技巧吗？

A：我这边的主要理念就是打造名师 IP 的话，我需要把我财经案例复试法的理念放进封面，做比较重要的标识。但是防止限流，我现在暂时没有想到什么，因为可能也没有什么限流，我没有提什么敏感词。只是说这个内容是否真的能够对人群有比较好的启发，可能得看你内容的优质程度，我们也打磨了好几个版本。

Q：两个封面的流量精准度有差异吗？

A：在我看来左边跑得好就是它有财经热点的标识。谈到瑞幸咖啡，其实一些比较泛的人群，或者对商科类感兴趣的人群也是会点进来看的，我们会发现这个号会吸引一些泛商科的人，人群会更大一点，流量池更大一点，所以它也会更快地涨粉。右边这个就更加直接，就是会计复试，除了会吸引会计考研群体以外，也会吸引很多会计或者商科类，甚至财经新闻相关的学生。因为他们读研的时候也是需要做案例分析的，所以我们这个号也会不定期地给进行案例大赛的指导、公益分享，这样更加有利于博取他们的好感，拓展到很多学校的院校合伙人。

Q：和上岸博主的合作可以详细介绍一下吗？

A：我最需要上岸博主做的事情就是写经验帖，我现在有 100 多个院校，肯定是需要他写针对某个院校的上岸经验帖。这个时候我们就设定一个标准，比如说我让他成绩单晒上来，还要把跟我们产品、课程、答疑有关的东西放进去。并且他需要写更多的干货，比如他们的复试流程是什么样的？导师偏好怎么样？他的备考历程是怎么样？我给到他们一个比较标准化的模板，他写出来东西后，我们再根据基础的报酬加点赞数去跟他核算就可以了。

在这个过程中，我们也会不定期地去看小红书上面一些新发出来的帖子，他不一定是我们的学生，但账号数据还不错。那也可以邀请合作，毕竟我们约稿的方式是统一的，操作起来还是比较方便的，只要有一个对接人负责就可以了。

Q：区分主号和小号两个号的原因是什么？

A：其实我们当时做的时候就是赛马机制做测试，然后发现两个都还不错。刚刚提到主号其实流量是更泛的，他吸引的是泛商科的人，可能是大二、大三的学生，可能是已经上岸的学长学姐，可以有比较好的背书。小号的话，定义很明确，吸引的就是很精准的人群了。简单来说，就是主号人比较多，小号少一点，更新频率的话主号会更高一点，小号更偏向于在复试阶段更得多一点。

Q：综合 ROI 哪个号更高？

A：其实我们这两个号并不承担转化功能。小号在复试高峰期的时候会挂商品卖书，基本每天还是挺多人去买书的，大号目前没有关联店铺。因为名师号最重要的就是塑造理念，所以 ROI 的话没有直接地统计过。我们还有一个机构号，数据也还不错，而且是长期维护的，粉丝量会高一点，主要承担一些销售对接。
