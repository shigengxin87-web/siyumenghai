# 01 通过新媒体做流量的底层逻辑

我 14 年开始实习（做新媒体），到现在正好是第十年，一直在研究新媒体的底层逻辑是什么。因为只有搞清楚一件事情的底层，你才能知道框架，就像你知道你回家的路，才能选择过哪个红绿灯一样。

新媒体行业底层是什么？先看看 ToC 业务的底层是什么？

举个例子，卖煎饼的怎么算业务规模呢？比如他在地铁口，地铁口每天 1 万人，有 10% 的人买，就 是 1, 000 人，平均客单价 10 块，一天赚 1 万块钱。生意是能计算的，这个很重要。

我们的业务收入等于流量*转化率*客单价\*复购率。比如婚纱领域是没有复购率的，拍完婚纱照，不论是否满意，都不太可能复购，所以这就是一个复购率为 1 的生意。

流量*转化率就是你的付费用户数，客单价*复购率就是用户的 LTV。

我们业内一般就三个常见问题：

第一是流量；

第二是你的转化率高不高？比如同样做教培，同样的老师，有的老师低转高转化率 10%，有的老师低转高转化率 2%。尽管流量一样，但是转化率不一样，它的产品、营销链路设计是完全不一样的；

第三是你的复购率高不高？因为客单价一般是由品类决定的，比如车的客单价基本上几万、几十万，不可能有几千的；卖课的话，什么价格都有；卖书，客单价也就几百。

我们一定要搞清楚这几个环节，然后去各自优化。

首先流量上，我们肯定要找更便宜的流量，之前是短视频平台。当然短视频平台现在流量也不便宜了，只有大 IP 才能有便宜的流量。我们之前合作的一个老师，一个月播放量有一亿，涨了几百万粉。很多同行都来问我们为什么这么高，其实就是这个老师特别厉害，我们把他的特点发挥出来了。但是短视频平台上这种品类老师很多，所以现在不是选短视频平台，而是短视频平台里选人的问题。

第二就是转化率，从关注前端到后端，需要社群转化。

第三就是客单价，考虑做更高的客单价。现在这个行业是两极分化，要么你就做极致的性价比，就是价格很低，东西还不错；要么你就把东西搞好价格很贵，中间腰部的越来越难做。

第四就是复购率，我们一直叫私域。私域的本质就是从使用权到所有权，你可以更多次地去触达，但这个私域也不是绝对性的。

所以这里最核心的点是，我们需要先判断一下当前业务重点是流量问题，转化率问题，还是复购率问题。

告诉大家一个比较残酷的现实，我们看了非常多的项目，其中 80%- 90% 的项目问题不是出在流量，而是出在转化率上。转化率不高，导致采买流量的效率低，拍的视频没人看——东西不好是本质，核心是先优化产品。

简单一句话， To C 业务拆分成几个率：流量*转化率*客单价\*复购率，我们要定位清楚问题是什么。

# 02 如何持续踩中红利——以视频号为例

第二部分就是如何踩中红利，这里先说一下我们经历过的红利。最早是 2017 年公众号裂变，当时我还在公司； 19 年出来创业，经历了快手涨粉，当时我们凭借一己之力把快手教育的涨粉做起来；接下来是抖音自然流， 21 年我们做过 40 多万场观的直播；在 21 年我们同时发现了视频号， 7 月份就已经跑通，变现了 100 多万。

新媒体红利的本质是什么，为什么我们每次都能踩中红利，这是很多朋友一直问的问题。公众号红利、快手红利、抖音红利、视频号红利，我们都踩中过，这些红利的本质其实就一句话：供给和需求的不平衡。

我们就是擅长找供给的不平衡处，只要找到不平衡处，普通人也能做得非常好。回过头看，我对视频号怎么思考的呢？

首先，我认为视频号的本质是视频化的消费进程，这是一个社会消费进程。比如在拼多多刚出来的时候，我就认为它很牛逼，它上市的时候我也去买了它的股票。因为我发现拼多多早期 DAU 等于微信减去淘宝、京东。

什么意思呢？就是用微信但是不用淘宝和京东的人，就是用拼多多的人。微信有 10 亿日活，淘宝、京东当时也就 5 亿 DAU，相当于 5 亿的人用拼多多。

视频号早期的是一样的，微信有 10 亿的人，但抖音和快手一共就 7 个亿（现在可能 8 个亿），还有 3 亿人不用。这 3 亿肯定是家里的老年人，他们下载 APP 太麻烦了。

第二个思考是罗格创意曲线。按照罗格的创新曲线，所有事情的发展不是直线的，它是弯曲的。以新能源车为例子， 15 年特斯拉刚出来的时候没有人买，只有 2.5% 的企业家会去买，后面 20 年开始慢慢有人开始用了，22 年开始大爆发，去年新能源车占了新车的36%，今年就更多了，事情的发展是有曲线的。

抖音、快手短视频是也不是所有人都会看，这批人就叫滞后者。整个互联网人群 10 亿左右，16% 的滞后者意味着最起码有 1.6 亿不看短视频 App，那他们最后就会看到视频号，因为微信等于移动互联网。

我有个朋友在双减前夕跳槽加入了某一家教培公司，运气太差了。我们选工作、做项目、选平台都是一样的，最大的遗憾永远不是做晚了，是做太早了。

基于我当时对视频号这两点本质的判断，我们当时喊了三个实习生，半年内不赚钱地去做这个事情，所以我们等到了视频号花开的时候。

那么视频号现在有哪些红利呢？

第一个是内容红利。我们 21 年做的一条剧情类的视频，1 亿的播放， 20 多万的成交。

现在视频号里最大的红利是故事会和知音又要崛起了，因为视频号的基本盘是中老年人，他们以前就是看故事会和知音的，现在是视频版的故事会、知音。22 年我跟一个朋友说了这个案例之后，他去做了自己点农产品，一年赚了 2, 000 多万，这套模式在今年依然有用。

第二是自然流的红利。很多人都说视频号没有自然流，但是我们 21 年的两场直播达到了 70 多万的场观，在当时就已经跑通了。

视频号的直播逻辑跟抖音是一样的，两个点：要么帮平台做娱乐，要么去搞带货。娱乐主播，核心做停留；带货主播，核心靠 GMV。

前两年我在自己的视频号直播，跟我的老粉说，只要是运营赶紧转行干直播运营，那会确实有红利。我们是 21 年全国第一个在视频号上做首播矩阵的， 当时自然流的红利还是很大的，现在自然流红利没有以前那么猛，当然要看具体类目，比如现在我们在做传统文化，自然流其实还是可以的。

第三个是视频号绑定公众号的红利，这个红利现在没有了，因为这个功能下掉了，但是以前帮我们涨了 1, 000 万的公众号粉。

当时只要关注视频号就能关注公众号，服务号可以群发直播间，当时我们也跟几个老师进行了合作，触达效率很高。

第四个是视频号的投流红利，微信豆现在不太稳定，但是有放大作用；电商行业可以试一试 ADQ ，教培可以先不用做大的尝试，当然也有一些人确实跑通了。

# 03 一个从0到千万老师在视频号的复盘

接下来讲一下今天的主题，一个老师在视频号 0 到千万的复盘。我们以前的商业模式是不签 IP 的，公司有 30 个素人主播，每个人每个月给我们赚 20 万。去年，我们才开始签IP，这个老师是我们签的第一个IP。

他是专门做专注力的老师，之前开过线下机构，在抖音最好的时候一个月大概卖了 30 万。之前主要靠抖音直播间自然流去拉盘，同时在线拉到 2, 000 人。到 23 年初就不行了，日销量掉到了 2, 000 元。

这里先说一下，为什么很多 IP 个体户没有办法拿到结果。大家可以看到，今年起的 IP 更少了，很多 IP 做一下，后面就没了，为什么？

第一是迭代速度太慢了，TA 没有办法拿到持续的信息，不知道哪个赛道牛逼；

第二是精力的问题，做 IP 需要管理、产品、交付，个人没有这么多精力。比如我们公司招运营，不会招 1 个人干 5 个人的活，干的东西太混杂了，会导致他什么东西都干不好；

第三是战略能力，他们不知道取舍。作为 MCN，我们最核心的能力是帮他定位流量，战略的核心是略。就像运营找工作一样，第一是找到一个好赛道，第二才是找到一家好公司，第三是找薪水不错的，很多人是倒着找的，所以他成长慢。

个体、老板、 IP 都是一样的，面临同样的情况，这也是为什么要做团队的原因。

### 1）冷启动期：找流量洼地

而我们帮他做的第一个事情就是找流量洼地。刚刚一直跟大家讲供需，我们永远要去找洼地，就像买股票要找低价但成长性高的。就像我们刚工作时候，很多人去互联网公司，因为这是洼地，估值没有那么高但成长很快。做 IP 要找流量洼地，要找供给少、需求大的地方。抖音有太多讲专注力老师了，他也不是拔尖的，所以我们决定换赛道，抖音不做了，直接做视频号。

实际上，这位老师还有一个大 bug ，他之前只干直播，没有短视频。刚刚我们也说过，视频号的第一个红利是短视频红利。我们认为这个老师的直播在视频号上是没有被验证的，但是短视频这块，我们公司做几千万粉了，所以我们先帮他做短视频，加强他的视频力，说白了就是拍短视频就行。因为在视频号，当时没有人做专注力的短视频，只要你做，就算拍得很差也还是有流量。

短视频具体怎么做？三件事：“钞——抄——超”：先“钞”，知道如何变现；再抄袭别人的框架；最后超越。结果这个老师当月就做到了 60 万+，当然他运气也比较好，我本来以为他一个月只能做到 20 万的。

### 2）上升期：稳定账号权重

第二步是稳定账号权重。大家都知道账号权重会掉，那我就要去做公众号的推送，去做私域的辅推。

为什么视频号不能跟抖音比，因为它是微信的组件，组件的核心是拆和组装。微信组件有公众号、有社群、有朋友圈、有小程序、有个人号、有视频号，它是生活空间的概念，所以私域可以用得很深。这也是为什么视频号的停留时间比抖音短的原因，你看视频号时很可能就会切换到跟别人聊天去了，但在抖音不太会。简单理解，视频号可以跟各种东西产生化学反应，这就需要私域去稳权重。

除此之外，还要调整直播话术，因为视频号上老年人比较多。比如在抖音直播语速很快，但在视频号语速得慢；一些难听懂的话，比如前庭觉、本体觉，大家都不懂，但你跟他说小孩左耳朵进、右耳朵出，他们能听懂，这个就叫适配话术。

知识付费直播间里面，很多主播“没讲人话”。为什么他们讲的是干货，但是大家听不懂，发生了鸡同鸭讲的情况？很简单，因为没有理解对面人的心思。为什么我一上来就问大家干运营干几年了？因为不同的人要有不同的讲法，做知识付费直播，这是一个非常重要的心法。

### 3）稳固期：稳定产出，增加用户粘性

接下来是稳固期，我们做的事情是上点投流，让他业绩平稳。如果一点投流都不上，账号权重就很容易掉，毕竟平台本身就不稳定。

我们主要投微信豆，就投 ROI 指标就行了；直播间的话，知识付费这个领域放量比较少，一般单场很难超过 3 万。因此投短视频进入直播间的方式可以尝试，但还是通过私域做大场，也就是找人联合直播。

老师卖课程的上限很低，因为只有一两门课，但用户是一波用户，很容易疲倦。这种时候我需要去把用户盘活，除了专注力，我们可以卖英语课。所以我们当时找了一个英语老师联合卖，1.5 万场观卖了 60 万，平均一个人买了 40 块钱。

### 4）全域期+变革期

接下来是全域期，也是变革期。在这个阶段，我们发现只干视频号不行了，得搞小红书，搞抖音，所以多平台开播。

这里需要注意，我们是做了五个月之后，才在多平台开播的，在之前并没有多平台开播。我们认为一开始要专注，只做一个平台。很多人签老师之后，三五个平台一起做，这样的逻辑是错的，没有发展重心。只有找到自己的重心，再去多开平台，才会有增量。

另外就是变革产品，产品不好，效果就不太好。所有的 IP 都是有起落的，我们运营的核心是干预流程，但并不能改变本质。老师没有流量，大部分是因为产品不够好，真正决定老师上限的其实是产品，因为他不知道用户是谁，用户需要什么。

以前我们签很多老师，现在我们舍九取一，只找最牛逼的老师，只找最牛逼的产品，能解决用户问题的产品才是好产品，才叫好 IP。

对于运营来说也是一样，产品是自己，我们应该想自己的价值是什么？怎么提升自己的价值？这是内生价值，价格会波动，价值是稳定的。

教培 IP 有个五环模型：短视频、直播间、投流、私域和产品。我们以前是先做短视频，再做直播间，再去做私域。但现在是反过来的——先看产品行不行，不行就别做了。

总而言之，做视频号首先要找到洼地，找到洼地直接拍短视频干就行了，然后稳定权重，稳定之后就要聚焦再聚焦，最后再去拓展。

就像运营这个职业，很多人说自己又做内容运营，又做短视频，又做直播，这样就错了，前期你只能做一件事情，比如只做内容，做两年后再去学习其它。所以我们做视频号前期先要稳号，然后再上投流、上私域、上全域。

# 04 下一波新的增长机会点和防坑指南

最后简单讲一下我们看到的新的机会增长点和防坑指南。

第一点就是长内容红利，我觉得做真实、干货输出的会变得越来越好，不同内容进程会不一样；

其次是老 IP，这也是我们最近的方向。如果你身边认识一些这种老 IP，欢迎来找我合作，类似于百家讲坛易中天，这种是我们比较喜欢的，我们也在找家庭教育、心理情感、国学领域特别好的老师。

今年是我创业第五年，也叫创业第一年，因为要开始做我们新方向的 IP。我们给自己的定位是猪八戒，在找唐僧帮我们一路取经，我们只做能长久的事情，做有意义的事情，所以我们现在是一家赚慢钱的公司。

我们筛选 IP 、筛选人也是一样的，需要的是一个追求长期、追求自我成长、有使命、追求有意义事情的人。一些老 IP 能影响人的价值观，帮助人更好地成长，这就是老 IP 新势能，我觉得这个行业趋势非常大。

第三是从 IP 做到品牌，就是刚刚说的具体玩法。比如去年东方甄董永辉火了之后，跟俞老师联合变成了一个品牌；

第四是全域加速运营，私域做利润，抖快做成交，因为抖快的投流成本太大了。

第五是小红书类目红利，小红书红利还是非常大的。去年我和一个朋友合作，他是做越野跑赛道的，没有什么人做，我把一个 20 多万粉丝的号给他去改造，他去年做到了行业第一名，现在每个月商单过 6 位数。

这也说明小红书细分类目非常好，如果你在小红书细分类目里面，或者你是小红书运营人才，一定来找我，我们有非常多的账号是空置的。

第六是数字人，这个就不多说了，现在整个行业，很多短视频都在用；

# Q&A

Q：地方性旅游的 IP 可以做吗？（比如一个镇的旅游宣传等，政府项目）

A：地方性旅游可以，旅游 IP 是个非常好的类目，可以看一下快手上张家界张导。其实什么行业都能做，只是你要看你是不是这个赛道顶尖的。

Q：任何行业的视频内容，都尽量靠拢知音和故事会体吗？

A：不是的，是视频号。因为视频号的人群是老年人比较多，针对于中老年，这类内容是最合适的。

Q：适配话术能再展开些吗？

A：适配话术的逻辑非常简单，其实就是找到这个人群的痛点，他们需要什么？你要理解他们的痛点，比如我去做个面向运营人的直播间，那我要找运营人的痛点是什么？第一，很多东西不会，视频号不会，抖音不会；第二不涨工资；第三，不知道下一份选择是什么。我就针对这 3 点来做，例如，怎么样让运营一年内涨 3 倍工资？你是不是会感兴趣？所以要找到他们的需求。

Q：如果我们的产品不是面向老年人的产品，视频号的视频内容方向怎么做？

A：现在视频上内容年轻人也起来了，你按照抖音内容做就行了。这里面我们有个九字箴言：见天地、见众生、见自己。你要看一下你的赛道什么情况，看看抖音上是怎么做的，视频号上有没有同行，或者是跨类目的。比如做女性护肤品的，你就不要去看护肤品，你可以看女性情感，因为都是一波人；最后你再分析自己就行了。当然更深层次的理解，其实应该是先见自己，再见众生，再见天地。

Q：我们是室内设计工作室的，最近才做小红书账号，数据不理想，有什么指点？

A：先看看别人做得好的长什么样，你就能找到自己不足了，师夷长技以制夷。

Q：视频号直播起号阶段如何圈精准人群？

A：这要看你的流量来源于哪块？自然流本身就不太精准，核心要关注你的话题，比如我们现在只讲运营人怎么涨薪，老板就不会来听，因此你要用话题把人群圈住；有私域的话，私域+自然流启动会更好。其实所谓精准，核心还是你的用户要什么东西。

Q：怎么判断一个 IP 有没有初心？

A：初心这个事情是没有办法短时间判断的，我们只能说叫日久见人心。但是可以判断一个人是怎么想问题的，看他人生的经历就行了，他是怎么做选择的？关键选择怎么做的？你可以通过他以前的经历，也可以通过我们的相处慢慢看

Q：1 个视频号的运营架构大概是几个人？

A：我们是按一个 IP 来做架构的，一个 IP 可能有几个视频号运营。我们会有会分成短视频组、直播组、私域组、产品组、客服组，交付组等 6 个组给他服务，一个 IP 大概有几十个人服务他。
