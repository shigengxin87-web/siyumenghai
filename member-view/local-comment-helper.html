本地助手安装与使用

从 GitHub 下载本地助手后，可以自己安装，也可以把安装包上传给你的 Agent，让它自主安装并指导你使用。

  1. 点击下方按钮进入 GitHub，在 Assets 中下载与你电脑系统匹配的安装包。
  2. 把下载好的安装包发送并上传给你的 Agent，告诉它：“请安装并启动这个本地助手，然后指导我使用。”
  3. 启动本地助手，并保持它在后台运行。
  4. 在微信电脑版打开任意视频号页面，再回到视频下载工具点击“提取并复制评论”。
