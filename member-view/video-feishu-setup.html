把视频文案保存到自己的飞书

首次完成接收流程配置后，在逐字稿下方点击「保存到飞书」，即可保存最新已确认的文案。每个使用者配置自己的素材库，不会写入其他人的表格。

1. 准备自己的素材库

打开视频号素材库模板，复制到自己的飞书空间。也可以下载字段模板导入多维表格，再按下面的流程配置。

使用自己的多维表格链接（https://…feishu.cn/base/…?table=…）。不要填写下载工具网址或飞书群机器人地址。

2. 配置接收流程

在飞书多维表格的工作流或自动化中，选择「接收到 webhook 时」，开启「凭证校验」，复制接收地址与校验凭证。复制模板后，两项内容会重新生成，需要复制自己那一份。

如果自行配置流程，先将下面示例粘贴到触发器的「输出设置」，定义收到的数据格式，然后按「素材ID」查找记录：已有记录就更新，没有就新增。

表格字段引用收到的数据
标题title
作者author
原视频链接source_url
逐字稿transcript
素材IDsource_id
更新时间updated_at
查看接收格式示例

仅用于定义字段类型，不要将示例当作实际入库请求。

{
  "schema_version": 1,
  "request_id": "request_example",
  "source_id": "source_example",
  "title": "示例视频",
  "author": "示例作者",
  "source_url": "https://weixin.qq.com/sph/example",
  "transcript": "第一段逐字稿。\n第二段。",
  "updated_at": "2026-11-22 14:00:00 +08:00",
  "callback_url": "https://siyumenghai.cn/api/feishu-sync/receipts",
  "callback_token": "callback_example"
}

写入成功后，发送回执

在新增和更新两条分支的末尾分别添加「发送 HTTP 请求」。方法为 POST，地址为 https://siyumenghai.cn/api/feishu-sync/receipts，Content-Type 为 application/json。

{
  "request_id": "引用触发器收到的 request_id",
  "callback_token": "引用触发器收到的 callback_token",
  "source_id": "引用触发器收到的 source_id",
  "status": "saved",
  "record_id": "引用前一步成功写入的记录 ID"
}

以上「引用」需要选择飞书的变量，不是把说明文字直接填入。回执必须放在写入成功之后；只有收到有效回执，工具才显示「已保存」。单条更新得到的记录 ID 如果是单元素数组，也可以直接传入。

3. 回到下载工具配置

点击「飞书配置」，填写自己的多维表格链接、Webhook 接收地址与校验凭证，保存配置。生成或修改文案后，先保存编辑，再点「保存到飞书」。

状态怎么看

  • 「已发送，待飞书确认」：请求已发出，尚未确认落表，可打开素材库检查。
  • 「已保存」：已收到写入成功回执，可打开该记录。重复保存同一视频会更新原记录。
  • 接收失败：检查流程是否启用、地址与凭证是否来自自己的副本。
  • 长期待确认：检查末尾的回执节点。修复后可手动重试；等待期间不会自动反复发送。

连接仅绑定当前浏览器；更换设备需要重新配置。自动化运行次数受你的飞书版本和额度影响。本功能为点击保存，不会双向同步飞书里的改动。
