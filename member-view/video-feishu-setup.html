把视频文案保存到自己的飞书

首次配置自己的应用和素材库后，点击「保存到飞书」即可入库。同一视频再次保存会更新原记录，保留最新已保存的文案。

1. 准备素材库

下载六字段模板，在自己的飞书空间新建多维表格并导入，或在现有数据表中添加以下六个字段。字段名称需要完全一致，类型均为「文本」。

字段保存内容
标题视频标题
作者视频号作者
原视频链接视频号分享链接
逐字稿最新已保存的文案，保留换行
素材ID工具生成的去重标识，请保留
更新时间本次保存时间

打开目标数据表，复制包含 ?table=tbl… 的完整地址；当前仅支持 https://…feishu.cn/base/… 形式的多维表格链接。知识库地址请先打开原始多维表格。

2. 创建专用应用并开通权限

进入飞书开发者后台，创建「企业自建应用」，例如命名为「视频素材入库」。在「权限管理」开通下列五项应用身份权限，随后在「版本管理与发布」创建版本并发布。

可以在「批量导入/导出权限」中粘贴以下配置，核对只包含这五项权限：

{
  "scopes": {
    "tenant": [
      "base:field:read",
      "base:record:retrieve",
      "base:record:read",
      "base:record:create",
      "base:record:update"
    ],
    "user": []
  }
}

分别用于检查字段、查找已有素材、核对保存结果、新增记录和更新记录。此功能不需要通讯录、消息或删除记录权限，也不需要配置自动化触发器。

3. 将应用加入目标表格

回到自己的多维表格，在右上角「…」菜单的「更多」中找到「添加文档应用」，选择刚创建的应用并授予可编辑权限。如素材库开启高级权限，还需授予应用该数据表的可管理权限，确保能查询已有记录。

开通 API 权限和添加文档应用是两个步骤。只开通前者，应用仍然无法访问你的素材库。请只授权需要保存视频文案的表格。

4. 回到下载工具保存配置

在应用的「凭证与基础信息」复制 App ID、App Secret。回到下载工具点击「飞书配置」，填写这两项和自己的数据表链接，点击「保存配置」。配置时会检查凭证、字段和查询权限；首次保存还会实际验证写入权限。

密钥加密保存在本站服务器；当前浏览器保留连接凭证，更换浏览器需要重新配置。请使用专用应用，避免填写同时授权其他重要文档的应用密钥。相同 App ID 的密钥留空可保留原配置，更换应用时需填写新的密钥。

日常怎么用

  • 生成逐字稿；需要修改时先点击「编辑」，完成后点「保存」。
  • 点击「保存到飞书」。待核对完成后显示「已保存」，可点击「查看记录」。
  • 重复保存同一视频会更新原记录；不会从飞书反向覆盖页面中的文案。
  • 连接中断时会保留待确认状态，稍后点击「重试发送」核对。请先完成上一版本的确认，再保存新的版本。
  • 表格中若已出现多条相同素材ID，工具会提示先合并记录，避免更新错误行。

本功能直接调用飞书 API。API 额度和应用发布规则以你的飞书账号当前设置为准。
